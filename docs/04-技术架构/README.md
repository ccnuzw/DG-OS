## 权威边界

- HTTP 字段级权威只有 OpenAPI；Markdown 契约负责公共语义（鉴权、错误包体），功能文档引用 operationId 并记录业务语义，不复制 schema。
- 数据物理事实以 migration 为准；数据模型文档负责解释约束、状态与演进。
- 设计系统规范为所有模块强制遵守，不得自定义样式覆盖。
