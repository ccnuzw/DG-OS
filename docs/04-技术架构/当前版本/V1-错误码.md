# V1 错误码

## 1. 文档目标

本文档汇总 DGOS V1 的所有错误码，确保全局唯一、语义清晰、易于维护。

**权威性**：
- ✅ 错误码的唯一权威来源
- ✅ 前端国际化的依据
- ✅ 日志分析和监控的基础

**更新原则**：
- 新增错误码：先分配编号，再编码
- 错误码一旦分配，永不修改、永不复用
- 废弃错误码：标记 `@deprecated`，保留在文档中

---

## 2. 错误码规范

### 2.1 编码规则

**格式**：7 位数字 `FFMMEEE`

- `FF`（2 位）：功能编号（01-10）
- `MM`（2 位）：模块编号（00-99）
- `EEE`（3 位）：错误序号（001-999）

**示例**：
- `1001001`：Provider 适配框架（01）的第 1 个错误
- `1008005`：用户管理（08）的第 5 个错误

## 7. 前端使用示例

### 7.1 错误处理

```typescript
// 错误码映射
const ERROR_MESSAGES: Record<string, string> = {
  '1001001': 'Provider 不存在',
  '1001002': '模型不存在',
  '1001003': 'API Key 无效',
  // ...
};

// 错误处理
try {
  const result = await invoke('call_provider', { ... });
} catch (error) {
  const errorCode = error.code;
  const message = ERROR_MESSAGES[errorCode] || '未知错误';
  
  // 显示错误提示
  toast.error(message);
  
  // 根据错误码处理
  if (errorCode === '1001003') {
    // 跳转到 Provider 配置页面
    navigate('/settings/providers');
  }
}
```

## 8. 后端使用示例

### 8.1 定义错误码

```rust
// server/crates/core/src/error.rs

#[derive(Debug, thiserror::Error)]
pub enum AppError {
    #[error("Provider not found")]
    ProviderNotFound, // 1001001
    
    #[error("Model not found")]
    ModelNotFound, // 1001002
    
    #[error("Invalid API key")]
    InvalidApiKey, // 1001003
    
    // ...
}

impl AppError {
    pub fn code(&self) -> String {
        match self {
            AppError::ProviderNotFound => "1001001".to_string(),
            AppError::ModelNotFound => "1001002".to_string(),
            AppError::InvalidApiKey => "1001003".to_string(),
            // ...
        }
    }
    
    pub fn http_status(&self) -> StatusCode {
        match self {
            AppError::ProviderNotFound => StatusCode::NOT_FOUND,
            AppError::ModelNotFound => StatusCode::NOT_FOUND,
            AppError::InvalidApiKey => StatusCode::UNAUTHORIZED,
            // ...
        }
    }
}
```

### 9.2 错误码统计

```sql
-- 统计错误码分布
SELECT 
    error_code,
    COUNT(*) as count,
    MIN(created_at) as first_seen,
    MAX(created_at) as last_seen
FROM error_logs
WHERE created_at > NOW() - INTERVAL '7 days'
GROUP BY error_code
ORDER BY count DESC
LIMIT 10;
```
