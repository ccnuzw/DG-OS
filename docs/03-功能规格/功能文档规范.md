# 功能文档规范

本文档定义 DGOS 项目功能规格文档的标准格式和编写规范，确保所有功能文档的一致性和完整性。

> 2026-10-28 说明：下文示例沿用早期 Skills 场景，只演示格式；Skills 当前定义见 [V1-FR-002](V1/01-底层能力/02-Skills管理系统.md)（D016）。示例路径已改为仓库实际布局（`crates/<crate>/...`）。

## 5. 第 4 章：数据模型

### 5.1 涉及的数据表

```markdown
### 4.1 涉及的数据表

**skills 表**（已安装的 Skills）：
\`\`\`sql
CREATE TABLE skills (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    version TEXT NOT NULL,
    enabled BOOLEAN DEFAULT TRUE,
    config JSON,
    created_at TIMESTAMP,
    user_id TEXT,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
\`\`\`
```

### 5.2 读写关系

```markdown
### 4.2 读写关系

**读操作**：
- 获取 Skills 列表：`SELECT * FROM skills WHERE user_id = ?`
- 获取 Skill 配置：`SELECT config FROM skills WHERE id = ?`

**写操作**：
- 安装 Skill：`INSERT INTO skills`
- 更新配置：`UPDATE skills SET config = ? WHERE id = ?`
- 卸载 Skill：`DELETE FROM skills WHERE id = ?`
```

## 6. 第 5 章：验收标准

### 6.1 AC 逐项测试设计表

**这是最重要的章节！**

```markdown
### 5.1 AC 逐项测试设计表

| AC | 验收重点 | Given | When | Then | 测试层级 | 目标资产 | 目标命令 | 初始资产状态 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| AC01 | 浏览官方技能 | 应用已登记官方内容包 | 打开技能中心 | 离线显示官方分类与技能 | 后端 + 前端 | `crates/dgos-skills/tests/bundled_catalog.rs` | `cargo test --offline -p dgos-skills --test bundled_catalog` | 规划中 |

```

### 6.2 字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| **AC** | 验收标准编号 | AC01 |
| **验收重点** | 这个 AC 测试什么 | 连接官方仓库 |
| **Given** | 前置条件 | 网络正常 |
| **When** | 触发动作 | 打开 Skills 浏览 |
| **Then** | 预期结果 | 成功获取列表 |
| **测试层级** | 单元/集成/E2E | 后端 API |
| **目标资产** | 测试文件路径 | `tests/registry.rs` |
| **目标命令** | 运行测试的命令 | `cargo test ...` |
| **初始资产状态** | 测试资产是否已建立（规划中 / 已有自动化资产），不是功能实现状态 | 规划中 |

### 6.3 编写要点

- ✅ 每个功能至少 5-10 个 AC
- ✅ AC 编号连续（AC01、AC02...）
- ✅ Given/When/Then 必须清晰
- ✅ 目标命令必须可执行
- ✅ 覆盖正常流程和异常流程

// B01-01: 获取 Skill 配置
FUNCTION install_skill(skill_id: String) -> Result<Skill>:
    // B01-02: 检查是否已安装
    IF skill_exists(skill_id):
        RETURN Err(AlreadyInstalled)

## 9. 第 8 章：错误码设计

```markdown
## 8. 错误码设计

| 错误码 | 错误信息 | 场景 | 用户操作建议 |
| --- | --- | --- | --- |
| 1002001 | skill_not_found | Skill 不存在 | 检查 Skill ID |
| 1002002 | skill_already_installed | Skill 已安装 | 询问是否重新安装 |
| 1002003 | dependency_not_satisfied | 依赖不满足 | 安装依赖（Python/Node.js） |
```

**错误码规则**：
- 格式：`10XXYYZ`
  - `10`：固定前缀
  - `XX`：模块编号（02=Skills）
  - `YY`：错误类型
  - `Z`：序号

## 10. 第 9 章：非功能需求

```markdown
## 9. 非功能需求

### 9.1 性能要求

- Skills 列表加载时间 < 2s
- Skill 安装时间 < 10s
- Skill 调用响应时间 < 5s

### 9.2 并发场景

**场景 1：多个用户同时调用同一 HTTP Skill**
- 冲突点：Skills 服务端负载
- 控制方式：无锁设计，Skills 服务自行处理并发
- 预期行为：所有请求转发到 Skills 服务
- 失败策略：Skills 超时或失败时记录错误

### 9.3 安全要求

- API Key 必须加密存储
- Skills 配置敏感信息加密
- Skills 调用需要权限检查
```
