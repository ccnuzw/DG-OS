## 4. 验证入口

仅列仓库当前定义的通用命令和已存在的测试入口，不将规划中的 E2E/覆盖率命令描述为已配置：

```bash
npm test
npm run build
npm run contracts:check
npm run skills:check
cargo test --workspace
cargo check --workspace --all-targets
```

需要定向验证时，以各主规格 AC 表中的目标命令为准。仓库当前没有本矩阵所称的 `server/`、`frontend/`、`pnpm` 测试命令或已配置的 V1 E2E 套件；不在此推定其存在。覆盖率数值与 E2E 完成度不在此推算，具体证据由实现状态文档维护。
