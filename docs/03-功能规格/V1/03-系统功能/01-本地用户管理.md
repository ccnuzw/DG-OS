## 2. 功能概述

### 2.1 一句话描述

提供本地用户的创建、登录、切换和删除功能，支持密码认证和数据隔离，让多个用户可以在同一台电脑上独立使用 DGOS。

### 2.2 详细说明

本地用户管理是 DGOS 的基础功能，让不同用户的数据完全隔离。V1 只实现本地用户（无需云端账号）；云端账号在 V3 提供，绑定本地用户和跨设备同步在 V4（D040）。

**核心价值**：
- 数据隔离：每个用户有独立的配置、历史、模块
- 隐私保护：用户之间看不到彼此的数据
- 多用户支持：同一台电脑多人使用
- 简单认证：用户名 + 密码

**用户价值**：
- 个人用户：隐私保护
- 家庭用户：多人共享一台电脑
- 企业用户：不同员工使用同一台设备

**与云端账号（V3 起）的区别**：
- V1 本地用户：数据只在本地，无需注册
- 云端账号：V3 用于应用市场；V4 绑定本地用户后数据云端同步，跨设备使用

### 2.3 功能边界

**包含**：
- 用户注册（用户名 + 密码）
- 用户登录（验证密码）
- 用户切换（切换到其他用户）
- 用户注销（退出登录）
- 用户删除（删除用户和所有数据）
- 修改密码
- 密码加密存储（bcrypt）
- 数据隔离（基于 user_id）
- 首次启动引导（创建第一个用户）
- 记住上次登录用户

**不包含**（明确说明原因）：
- ❌ 找回密码 → V1 无邮箱，无法找回
- 两步验证 → V2 安全增强
- 用户头像 → 后续版本（路线图未分配）
- ❌ 用户权限管理 → V1-FR-009 独立功能
- ❌ OAuth 登录 → 云端账号（V3 起，D040）
- ❌ 云端同步 → V4 跨设备同步

## 4. 数据模型

### 4.1 涉及的数据表

**users 表**（核心表）：
```sql
CREATE TABLE users (
    id TEXT PRIMARY KEY,              -- UUID
    username TEXT UNIQUE NOT NULL,    -- 用户名（唯一）
    password_hash TEXT NOT NULL,      -- 密码哈希（bcrypt）
    display_name TEXT,                -- 显示名称（可选，默认为 username）
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_login_at TIMESTAMP,          -- 最后登录时间
    is_active BOOLEAN DEFAULT TRUE    -- 是否激活
);

CREATE INDEX idx_users_username ON users(username);
```

**user_sessions 表**（会话管理）：
```sql
CREATE TABLE user_sessions (
    id TEXT PRIMARY KEY,              -- UUID
    user_id TEXT NOT NULL,
    token TEXT UNIQUE NOT NULL,       -- 会话 token
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    expires_at TIMESTAMP,             -- 过期时间（可选）
    device_info TEXT,                 -- 设备信息（可选）
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE INDEX idx_sessions_token ON user_sessions(token);
```

**app_config 表**（应用配置）：
```sql
CREATE TABLE app_config (
    key TEXT PRIMARY KEY,
    value TEXT
);

-- 存储"上次登录用户"
INSERT INTO app_config (key, value) VALUES ('last_login_user_id', '...');
```

### 4.2 数据隔离策略

**所有用户数据表都包含 user_id 字段**：
```sql
-- 示例：Provider 表
CREATE TABLE providers (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,            -- 关键：用户隔离
    name TEXT NOT NULL,
    ...
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

-- 查询时必须过滤
SELECT * FROM providers WHERE user_id = ?;
```

**级联删除**：用户删除时，所有关联数据自动删除（`ON DELETE CASCADE`）。

### 4.3 读写关系

**读操作**：
- 获取所有用户：`SELECT id, username, display_name, last_login_at FROM users WHERE is_active = TRUE`
- 查询用户：`SELECT * FROM users WHERE username = ?`
- 获取上次登录用户：`SELECT value FROM app_config WHERE key = 'last_login_user_id'`

**写操作**：
- 创建用户：`INSERT INTO users (id, username, password_hash) VALUES (?, ?, ?)`
- 更新密码：`UPDATE users SET password_hash = ? WHERE id = ?`
- 删除用户：`DELETE FROM users WHERE id = ?`（级联删除所有关联数据）
- 记录登录：`UPDATE users SET last_login_at = ? WHERE id = ?`
- 保存会话：`INSERT INTO user_sessions (id, user_id, token) VALUES (?, ?, ?)`

## 7. 技术设计

### 7.1 密码加密实现

```rust
// 规划 crate（未创建）：crates/dgos-auth/src/password.rs

use bcrypt::{hash, verify, DEFAULT_COST};

// B08-01: 密码加密
pub fn hash_password(password: &str) -> Result<String> {
    // 使用 bcrypt，默认 cost = 12
    let hashed = hash(password, DEFAULT_COST)?;
    Ok(hashed)
}

// B08-02: 密码验证
pub fn verify_password(password: &str, hash: &str) -> Result<bool> {
    let valid = verify(password, hash)?;
    Ok(valid)
}
```

### 7.2 用户注册实现

```rust
// 规划 crate（未创建）：crates/dgos-auth/src/service.rs

pub struct AuthService {
    db: DatabasePool,
}

impl AuthService {
    // B08-03: 创建用户
    pub async fn create_user(
        &self,
        username: String,
        password: String
    ) -> Result<User> {
        // B08-04: 验证用户名唯一性
        if self.db.user_exists(&username).await? {
            return Err(Error::UserAlreadyExists);
        }
        
        // B08-05: 验证密码强度
        if password.len() < 6 {
            return Err(Error::PasswordTooShort);
        }
        
        // B08-06: 密码加密
        let password_hash = hash_password(&password)?;
        
        // B08-07: 保存到数据库
        let user = User {
            id: Uuid::new_v4().to_string(),
            username: username.clone(),
            display_name: None,
            created_at: Utc::now().to_rfc3339(),
            last_login_at: None,
        };
        
        self.db.insert_user(&user, &password_hash).await?;
        
        Ok(user)
    }
    
    // B08-08: 用户登录
    pub async fn login(
        &self,
        username: String,
        password: String
    ) -> Result<Session> {
        // B08-09: 查询用户
        let user = self.db.get_user_by_username(&username).await?
            .ok_or(Error::UserNotFound)?;
        
        // B08-10: 验证密码
        let password_hash = self.db.get_password_hash(&user.id).await?;
        if !verify_password(&password, &password_hash)? {
            return Err(Error::InvalidPassword);
        }
        
        // B08-11: 创建会话
        let session = Session {
            token: Uuid::new_v4().to_string(),
            user: user.clone(),
            expires_at: None, // 草案；会话有效期须结合安全设计确认
        };
        
        self.db.insert_session(&session).await?;
        
        // B08-12: 更新最后登录时间
        self.db.update_last_login(&user.id).await?;
        
        // B08-13: 记录为上次登录用户
        self.db.set_config("last_login_user_id", &user.id).await?;
        
        Ok(session)
    }
    
    // B08-14: 删除用户
    pub async fn delete_user(
        &self,
        user_id: &str,
        password: String
    ) -> Result<()> {
        // B08-15: 验证密码（确认身份）
        let password_hash = self.db.get_password_hash(user_id).await?;
        if !verify_password(&password, &password_hash)? {
            return Err(Error::InvalidPassword);
        }
        
        // B08-16: 删除用户（级联删除所有数据）
        self.db.delete_user(user_id).await?;
        
        Ok(())
    }
}
```

### 7.3 数据隔离中间件

// 规划 crate（未创建）：crates/dgos-auth/src/middleware.rs

// B08-17: 从 session token 提取 user_id
pub async fn extract_user_id(token: &str, db: &DatabasePool) -> Result<String> {
    let session = db.get_session_by_token(token).await?
        .ok_or(Error::InvalidSession)?;
    
    Ok(session.user_id)
}

// B08-18: 验证数据访问权限
pub async fn check_data_access(
    user_id: &str,
    resource_user_id: &str
) -> Result<()> {
    if user_id != resource_user_id {
        return Err(Error::AccessDenied);
    }
    
    Ok(())
}
