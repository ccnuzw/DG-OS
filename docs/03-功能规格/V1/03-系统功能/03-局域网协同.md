## 2. 功能概述

### 2.1 一句话描述

在本地启动 HTTP 服务，让局域网内的其他设备（手机、平板、其他电脑）可以通过浏览器访问 DGOS，支持简单的 token 认证和设备管理。

### 2.2 详细说明

局域网协同让 DGOS 不仅是桌面应用，也是局域网内的服务。服务随桌面应用自动启动（D007/D039），用户可以在手机上打开浏览器访问 `http://192.168.1.100:3000`，认证后使用主机的能力；远程设备只能使用，不能修改配置（D007/D013）。

**核心价值**：
- ✅ 跨设备访问：手机、平板也能用
- ✅ 无需云端：数据不离开局域网
- ✅ 灵活场景：在沙发上用手机聊天
- ✅ 统一数据：所有设备共享同一份数据

**用户价值**：
- 个人用户：在家里任何设备都能用
- 团队用户：共享局域网内的 DGOS 实例
- 移动场景：不在电脑前也能使用

**V1 局域网 vs 云端**：
- V1 局域网：只能局域网访问，无需注册
- 云端：云端账号从 V3 起提供（D040），公网访问与跨设备同步在 V4

### 2.3 功能边界

**包含**（启动策略与远程范围已由 D039 确定；安全默认值仍按 §2.4 待技术设计冻结）：
- ✅ HTTP Server 随应用自动启动；系统设置中的开关可关闭，关闭状态持久化（D039）
- ✅ 自动选择端口（默认 3000，占用时自动递增）
- ✅ 局域网 IP 自动获取和显示
- ✅ 简单认证（token 或密码）
- ✅ 已连接设备列表
- ✅ 设备管理（踢出设备）
- HTTP API 白名单：只暴露使用类接口（对话、历史、使用已配置的 Provider/Skills/MCP），不暴露配置修改，不映射全部 Tauri commands；逐项白名单在技术设计中冻结（D039）
- ✅ 前端应用服务（Vite 构建的 SPA）
- ✅ WebSocket 支持（流式响应）
- ✅ 安全限制（只允许局域网 IP）
- ✅ 二维码分享（扫码连接）

**不包含**（明确说明原因）：
- ❌ HTTPS（自签名证书） → V2 安全增强
- ❌ 公网访问（端口转发） → V4 云端协同
- ❌ 细粒度权限（按设备） → V2 权限增强
- ❌ 设备同步（离线变更合并） → V4 云端协同
- ❌ 多实例集群 → 不在 V1 范围

### 2.4 决策与待决策

启动策略与远程范围已由 [D039](../../../06-决策记录/V1-冻结决策.md#d039-局域网服务随应用自动启动设置开关持久关闭) 确定；安全默认值仍未冻结，相关流程与接口示例在冻结前是草案，不代表已批准行为。

#### 已决：启动策略（D039）

以 D007 为准：开关默认开启，开启时应用启动即启动服务；启动失败只提示，不阻塞桌面应用。系统设置中的开关就是 D007 的“可在设置中关闭”：关闭立即停止服务并断开所有设备，状态持久化，之后启动不自动开启，直到用户重新打开。AC01/AC12 的“启动/停止”即该开关的开、关。退出应用时服务随之停止，不常驻后台。

#### 已决：远程范围（D039，沿用 D007/D013）

远程设备必须认证，只能使用主机能力：发起对话、查看历史、使用已配置的 Provider/Skills/MCP；不能修改 Provider 等配置。HTTP API 采用白名单，不映射全部 Tauri commands；§6.2 与 §7.1 草案中的 `POST /api/providers` 不得开放。逐项白名单在技术设计中列出并冻结。

#### 待决策：安全默认值

草案中的简单 token、LAN IP 限制、`0.0.0.0` 监听、宽松 CORS、会话有效期、设备身份和局域网共享用户数据等设置尚未形成一致的安全基线。默认开启与强制认证、随机初始凭据已由 D007/D039 确定；仍需冻结绑定地址与网络范围（D007 的 `0.0.0.0` 与“只监听局域网”需统一）、凭据生成/保存/轮换/撤销、会话期限、来源校验和远程认证方式（D013 写用户名/密码，本规格写 token），并评估同网段攻击风险。安全默认值未决前，不据草案宣称该服务具备可接受的安全保障。

## 3. 核心流程

### 3.1 启动 HTTP 服务流程

```
（D039）桌面应用启动
  ↓
读取局域网服务开关（默认开启）
  ↓
（开关关闭）不启动；用户在系统设置 → "局域网协同"打开开关后按下列步骤启动
  ↓
系统选择端口（默认 3000）
  ↓
（如果端口占用）尝试 3001、3002...
  ↓
启动 HTTP Server
  ↓
获取局域网 IP（192.168.1.100）
  ↓
生成访问 token（随机 UUID）
  ↓
显示访问信息：
  "服务已启动
   访问地址：http://192.168.1.100:3000
   Token：abc123-def456-..."
  ↓
生成二维码（包含地址 + token）
  ↓
用户可以分享给其他设备

（启动失败，如端口耗尽或无网络）提示原因并在设置页显示，桌面应用照常使用
```

> 系统设置的“局域网协同”标签尚未列入 [FR-007](../02-应用模块/02-系统设置.md) 的 6 个标签，修订 FR-007 时补充（D039）。

### 3.2 远程设备连接流程

```
用户在手机上
  ↓
打开浏览器
  ↓
输入地址：http://192.168.1.100:3000
  ↓
（或扫描二维码）
  ↓
打开 DGOS 登录页面
  ↓
输入 token（或自动填充）
  ↓
点击"连接"
  ↓
前端验证 token（调用 /api/auth/verify）
  ↓
服务端验证 token
  ↓
（如果有效）返回 session token
  ↓
保存 session token 到 localStorage
  ↓
显示用户选择页面
  ↓
选择用户（如果有多个）
  ↓
输入用户密码
  ↓
验证成功，进入主界面
  ↓
在桌面端显示："iPhone 已连接"
```

### 3.3 远程设备使用流程

```
手机上的 DGOS
  ↓
打开 AI 工作台
  ↓
输入 Prompt 并发送
  ↓
前端调用：POST /api/chat/send
  ↓
携带 session token（Authorization: Bearer xxx）
  ↓
服务端验证 token
  ↓
验证通过，调用后端逻辑
  ↓
（如果是流式）通过 WebSocket 返回
  ↓
前端逐字显示
  ↓
完成
  ↓
桌面端实时看到："iPhone 发送了消息"
```

### 3.4 踢出设备流程

```
用户在桌面端
  ↓
打开系统设置 → 局域网协同
  ↓
查看已连接设备列表：
  - iPhone (192.168.1.101) - 活跃
  - iPad (192.168.1.102) - 30分钟前
  ↓
点击 iPhone 的"断开"按钮
  ↓
确认提示："确定断开 iPhone？"
  ↓
用户确认
  ↓
服务端删除该设备的 session
  ↓
iPhone 上的 DGOS 自动退出登录
  ↓
显示："已被断开连接"
```

### 3.5 停止服务流程

```
用户在系统设置
  ↓
关闭"局域网协同"开关（D039）
  ↓
确认提示："停止后，所有设备将断开连接"
  ↓
用户确认
  ↓
断开所有设备连接
  ↓
停止 HTTP Server
  ↓
持久化开关为关闭（之后启动应用不再自动开启）
  ↓
显示状态："未启动"

退出应用时：断开设备并停止服务，开关状态不变
```

## 4. 数据模型

### 4.1 涉及的数据表（历史草案）

以下表结构仅为早期设计草案，不代表现行 migration 或已批准数据模型；物理结构以 migration 为准，产品决策冻结前不得据此承诺持久化 token 或远程用户会话。

**lan_sessions 表**（局域网会话）：
```sql
CREATE TABLE lan_sessions (
    id TEXT PRIMARY KEY,              -- UUID
    session_token TEXT UNIQUE NOT NULL, -- 会话 token
    device_name TEXT,                 -- 设备名称（从 User-Agent 提取）
    device_ip TEXT NOT NULL,          -- 设备 IP
    user_id TEXT,                     -- 登录的用户（可选）
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_active_at TIMESTAMP,         -- 最后活跃时间
    expires_at TIMESTAMP,             -- 过期时间（可选）
    FOREIGN KEY (user_id) REFERENCES users(id)
);

CREATE INDEX idx_lan_sessions_token ON lan_sessions(session_token);
CREATE INDEX idx_lan_sessions_ip ON lan_sessions(device_ip);
```

**lan_config 表**（局域网配置）：
```sql
CREATE TABLE lan_config (
    key TEXT PRIMARY KEY,
    value TEXT
);

-- 存储配置
INSERT INTO lan_config (key, value) VALUES ('enabled', 'true');  -- D039：默认开启
INSERT INTO lan_config (key, value) VALUES ('port', '3000');
INSERT INTO lan_config (key, value) VALUES ('access_token', 'xxx');
```

**lan_activity_logs 表**（活动日志）：
```sql
CREATE TABLE lan_activity_logs (
    id TEXT PRIMARY KEY,
    session_id TEXT,
    device_ip TEXT,
    action TEXT,                      -- 动作：connected, disconnected, request
    endpoint TEXT,                    -- 访问的端点（如 /api/chat/send）
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (session_id) REFERENCES lan_sessions(id)
);

CREATE INDEX idx_lan_logs_time ON lan_activity_logs(created_at);
```

### 4.2 读写关系

**读操作**：
- 验证 token：`SELECT * FROM lan_sessions WHERE session_token = ?`
- 获取已连接设备：`SELECT * FROM lan_sessions ORDER BY last_active_at DESC`
- 查询活动日志：`SELECT * FROM lan_activity_logs ORDER BY created_at DESC LIMIT 100`

**写操作**：
- 创建会话：`INSERT INTO lan_sessions (id, session_token, device_ip, ...) VALUES (...)`
- 更新活跃时间：`UPDATE lan_sessions SET last_active_at = ? WHERE id = ?`
- 删除会话：`DELETE FROM lan_sessions WHERE id = ?`
- 记录日志：`INSERT INTO lan_activity_logs (...) VALUES (...)`

### 6.3 数据结构

```rust
// 规划 crate（未创建）：crates/dgos-lan/src/types.rs

use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ServerInfo {
    pub enabled: bool,
    pub port: u16,
    pub lan_ip: String,
    pub access_url: String,         // http://192.168.1.100:3000
    pub access_token: String,
    pub qr_code: String,            // Base64 QR code

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ServerStatus {
    pub running: bool,
    pub port: Option<u16>,
    pub connected_devices: usize,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Device {
    pub id: String,
    pub name: String,
    pub ip: String,
    pub user_id: Option<String>,
    pub connected_at: String,
    pub last_active_at: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ActivityLog {
    pub id: String,
```

### 7.1 HTTP Server 实现

```rust
// 规划 crate（未创建）：crates/dgos-lan/src/server.rs；以下为未冻结的历史草案
// D039：start 由应用启动时按开关调用（B10-20）；草案中的 POST /api/providers 不得开放；CORS 宽松配置待安全默认值决策

use axum::{Router, routing::get, routing::post};
use tower_http::cors::CorsLayer;
use std::net::SocketAddr;

pub struct LANServer {
    router: Router,
    addr: SocketAddr,

impl LANServer {
    // B10-01: 启动服务
    pub async fn start(port: Option<u16>) -> Result<Self> {
        // B10-02: 选择端口
        let port = Self::select_available_port(port.unwrap_or(3000))?;
        
        // B10-03: 获取局域网 IP
        let lan_ip = Self::get_lan_ip()?;
        
        let addr = SocketAddr::from(([0, 0, 0, 0], port));
        
        // B10-04: 构建路由
        let router = Router::new()
            // 认证
            .route("/api/auth/verify", post(handlers::auth::verify))
            .route("/api/auth/login", post(handlers::auth::login))
            .route("/api/auth/logout", post(handlers::auth::logout))
            
            // Provider
            .route("/api/providers", get(handlers::provider::list))
            .route("/api/providers", post(handlers::provider::create))
            
            // Chat
            .route("/api/chat/sessions", get(handlers::chat::list_sessions))
            .route("/api/chat/send", post(handlers::chat::send))
            
            // WebSocket
            .route("/api/chat/stream", get(handlers::chat::stream_ws))
            
            // 静态文件（前端应用）
            .nest_service("/", ServeDir::new("<configured-frontend-build-output>")) // 占位示例；Vite 输出及打包/部署路径待技术设计确认
            
            // B10-05: 添加中间件
            .layer(CorsLayer::permissive())
            .layer(LANAuthMiddleware::new())
            .layer(IPRestrictionMiddleware::new());
        
        // B10-06: 启动服务器
        tokio::spawn(async move {
            axum::Server::bind(&addr)
                .serve(router.into_make_service())
                .await
                .unwrap();
        });
        
        Ok(Self { router, addr })
    }
    
    // B10-02: 选择可用端口
    fn select_available_port(start_port: u16) -> Result<u16> {
        for port in start_port..start_port + 100 {
            if Self::is_port_available(port) {
                return Ok(port);
            }
        }
        
        Err(Error::NoAvailablePort)
    }
    
    fn is_port_available(port: u16) -> bool {
        std::net::TcpListener::bind(("0.0.0.0", port)).is_ok()
    }
    
    // B10-03: 获取局域网 IP
    fn get_lan_ip() -> Result<String> {
        use local_ip_address::local_ip;
        
        let ip = local_ip()?;
        Ok(ip.to_string())
    }
}
```

### 7.2 认证中间件

```rust
// 规划 crate（未创建）：crates/dgos-lan/src/middleware/auth.rs

use axum::{
    extract::Request,
    middleware::Next,
    response::Response,
};

// B10-07: 认证中间件
pub async fn lan_auth_middleware(
    request: Request,
    next: Next
) -> Result<Response, StatusCode> {
    let path = request.uri().path();
    
    // B10-08: 公开路径（不需要认证）
    if path.starts_with("/api/auth/verify") || path == "/" {
        return Ok(next.run(request).await);
    }
    
    // B10-09: 提取 session token
    let session_token = request
        .headers()
        .get("Authorization")
        .and_then(|h| h.to_str().ok())
        .and_then(|s| s.strip_prefix("Bearer "));
    
    let Some(token) = session_token else {
        return Err(StatusCode::UNAUTHORIZED);
    };
    
    // B10-10: 验证 session token
    let db = request.extensions().get::<DatabasePool>().unwrap();
    let session = db.get_lan_session_by_token(token).await
        .map_err(|_| StatusCode::UNAUTHORIZED)?;
    
    // B10-11: 更新活跃时间
    db.update_session_active(&session.id).await
        .map_err(|_| StatusCode::INTERNAL_SERVER_ERROR)?;
    
    // B10-12: 将 user_id 注入到请求中
    request.extensions_mut().insert(session.user_id);
    
    Ok(next.run(request).await)
}
```

### 7.3 IP 限制中间件

```rust
// 规划 crate（未创建）：crates/dgos-lan/src/middleware/ip_restriction.rs

use axum::{
    extract::ConnectInfo,
    middleware::Next,
    response::Response,
};
use std::net::SocketAddr;

// B10-13: IP 限制中间件
pub async fn ip_restriction_middleware(
    ConnectInfo(addr): ConnectInfo<SocketAddr>,
    request: Request,
    next: Next
) -> Result<Response, StatusCode> {
    let client_ip = addr.ip();
    
    // B10-14: 检查是否为局域网 IP
    if !is_lan_ip(&client_ip) {
        tracing::warn!("拒绝公网 IP 访问：{}", client_ip);
        return Err(StatusCode::FORBIDDEN);
    }
    
    Ok(next.run(request).await)
}

// B10-14: 判断是否为局域网 IP
fn is_lan_ip(ip: &std::net::IpAddr) -> bool {
    use std::net::IpAddr;
    
    match ip {
        IpAddr::V4(ipv4) => {
            let octets = ipv4.octets();
            
            // 10.0.0.0/8
            octets[0] == 10
            // 172.16.0.0/12
            || (octets[0] == 172 && octets[1] >= 16 && octets[1] <= 31)
            // 192.168.0.0/16
            || (octets[0] == 192 && octets[1] == 168)
            // 127.0.0.1 (localhost)
            || octets[0] == 127
        }
        IpAddr::V6(_) => {
            // 简化处理，允许 IPv6
            true
        }
    }
}
```

### 7.4 WebSocket 流式处理

```rust
// 规划 crate（未创建）：crates/dgos-lan/src/handlers/chat.rs

use axum::{
    extract::ws::{WebSocket, WebSocketUpgrade},
    response::Response,
};

// B10-15: WebSocket 流式消息
pub async fn stream_ws(
    ws: WebSocketUpgrade,
    Extension(db): Extension<DatabasePool>,
) -> Response {
    ws.on_upgrade(|socket| handle_socket(socket, db))
}

async fn handle_socket(mut socket: WebSocket, db: DatabasePool) {
    // B10-16: 接收消息请求
    while let Some(msg) = socket.recv().await {
        let Ok(msg) = msg else { break };
        
        let text = msg.to_text().unwrap();
        let request: ChatRequest = serde_json::from_str(text).unwrap();
        
        // B10-17: 调用 Provider（流式）
        let stream = provider_manager
            .stream_call(&request.provider_id, request)
            .await
            .unwrap();
        
        // B10-18: 逐块发送
        while let Some(chunk) = stream.next().await {
            let json = serde_json::to_string(&chunk).unwrap();
            socket.send(Message::Text(json)).await.unwrap();
        }
        
        // B10-19: 发送结束标记
        socket.send(Message::Text("[DONE]".to_string())).await.unwrap();
    }
}
```
