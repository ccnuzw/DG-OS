## 风险与对策

| 风险 | 严重程度 | 对策 | 关联决策 |
| --- | --- | --- | --- |
| 模块身份由调用方声明 | 高 | 身份只能来自宿主发布器与宿主会话（D025/D032） | D025、D032 |
| 模块越权访问宿主能力 | 高 | manifest 是能力上限，授权 broker 只授予交集；能力调用唯一入口是 Host Capability API（D026/D029） | D026、D029 |
| 发布或热更新中途失败 | 高 | 可恢复的文件状态机与发布 lease；失败回滚并 fail-closed（D027/D031/D033） | D027、D031、D033 |
| 可信代码范围被误读为沙箱 | 高 | V1 只允许宿主固定清单内的受信任本地包；执行位置是同一 JS realm，不是沙箱（D028/D041/D042） | D028、D041、D042 |
| 取消或页面销毁使 runtime 状态丢失 | 中 | 操作脱离调用方后台执行，页面代次与回执幂等（D034/D044） | D034、D044 |
