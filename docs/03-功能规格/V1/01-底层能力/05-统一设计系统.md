## 2. 功能概述

### 2.1 一句话描述

建立完整的 Design Tokens 体系、主题系统、密度系统、基础组件库和错误通知规范，所有模块强制复用，确保 DGOS 全局视觉和交互的完全一致性。

### 2.2 详细说明

统一设计系统是 DGOS 的**视觉和交互基础设施**，定义了从原子级别（颜色、字号）到分子级别（组件）再到有机体级别（错误处理、通知）的完整规范。

**核心价值**：
- ✅ **原子化设计**：Design Tokens 定义所有视觉基础变量
- ✅ **主题系统**：支持亮色/暗色模式、自定义主题、跟随系统
- ✅ **密度系统**：支持 5 种密度级别（75%-175%），适应不同用户偏好
- ✅ **组件库**：10+ 基础组件，统一样式和交互
- ✅ **错误与通知**：统一的错误处理和通知样式
- ✅ **强制复用目标**：通过设计令牌与组件约束减少自定义样式（具体静态检查机制待定）

**用户价值**：
- 视觉一致：全局统一的外观
- 个性化：可调节主题、字号、密度
- 无障碍：符合 WCAG 2.1 AA 标准

**从老项目学到的教训**：
- ❌ 老项目：内联样式、重复组件、视觉不一致
- ✅ DGOS：Design Tokens、强制复用、全局一致

### 2.3 功能边界

**Design Tokens（设计令牌）**：

## 3. 核心流程

### 3.1 主题切换流程

```
用户打开系统设置
  ↓
点击"外观"标签
  ↓
选择主题：亮色 / 暗色 / 自动（跟随系统）
  ↓
前端调用：updateTheme('dark')
  ↓
更新 CSS 变量（--color-bg, --color-text, ...）
  ↓
所有组件自动响应新主题
  ↓
保存用户偏好到 app_config 表
  ↓
下次启动自动应用
```

### 3.2 密度调整流程

```
用户打开系统设置
  ↓
点击"系统缩放"
  ↓
选择密度：75% / 100% / 125% / 150% / 175%
  ↓
前端调用：updateDensity(125)
  ↓
更新根元素字号：font-size: calc(14px * 1.25)
  ↓
所有使用 rem 的尺寸自动缩放
  ↓
保存用户偏好到 app_config 表
```

### 3.3 错误通知流程

```
用户操作失败（如 Provider 调用失败）
  ↓
后端返回错误码：1001004
  ↓
前端捕获错误
  ↓
查找错误码映射：ERROR_MESSAGES['1001004'] = 'Provider 不存在'
  ↓
调用 Toast 组件：toast.error('Provider 不存在')
  ↓
显示 Toast：红色背景 + 错误图标 + 消息
  ↓
3 秒后自动消失（或用户手动关闭）
  ↓
（如果是严重错误）显示 Modal 对话框引导用户操作
```

### 3.4 开发者使用组件流程

```
开发者开发新模块
  ↓
需要按钮组件
  ↓
导入统一组件：import { Button } from '<待确定的组件包入口>'
  ↓
使用组件：<Button variant="primary">确定</Button>
  ↓
组件自动使用当前主题和密度
  ↓
（若后续配置相应静态检查）违反样式约束时由检查工具报告
```

## 5. 主题系统

### 5.1 主题类型

#### 5.1.1 亮色模式（Light）

**默认主题**，适合白天使用。

**特点**：
- 白色背景（`#FFFFFF`）
- 深色文本（`#111827`）
- 高对比度
- 明亮清爽

#### 5.1.2 暗色模式（Dark）

**护眼主题**，适合夜间使用。

**特点**：
- 深色背景（`#1F1F1F`）
- 浅色文本（`#F9FAFB`）
- 降低蓝光
- 省电（OLED 屏幕）

#### 5.1.3 跟随系统（Auto）

**智能切换**，根据系统设置自动切换。

**实现**：
```typescript
// 监听系统主题变化
window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', (e) => {
  if (userPreference === 'auto') {
    updateTheme(e.matches ? 'dark' : 'light');
  }
});
```

#### 5.1.4 自定义主题（V2）

**壁纸取色**，从用户壁纸提取主题色。

**实现**（V2）：
- 分析壁纸主色调
- 生成和谐的配色方案
- 应用到 Design Tokens

### 5.2 主题切换实现

#### 5.2.1 CSS 变量切换

```css
/* 亮色模式 */
:root {
  --color-bg-primary: #FFFFFF;
  --color-text-primary: #111827;
  /* ... */
}

/* 暗色模式 */
:root[data-theme="dark"] {
  --color-bg-primary: #1F1F1F;
  --color-text-primary: #F9FAFB;
  /* ... */
}
```

#### 5.2.2 组件响应主题

```tsx
// 组件自动使用 CSS 变量
const Button = styled.button`
  background-color: var(--color-primary);
  color: var(--color-bg-primary);
  
  &:hover {
    background-color: var(--color-primary-hover);
  }
`;
```

#### 5.2.3 主题持久化

**数据模型**：
```sql
-- app_config 表
INSERT INTO app_config (key, value) VALUES ('theme', '"light"');
-- 值：'light' | 'dark' | 'auto'
```

**读取逻辑**：
```typescript
// 启动时加载用户主题偏好
async function loadTheme() {
  const theme = await invoke('get_app_config', { key: 'theme' });
  updateTheme(theme || 'light');
}
```

## 6. 密度系统

### 6.1 密度级别

| 级别 | 缩放比例 | 根字号 | 用途 |
|------|---------|--------|------|
| **更紧凑** | 75% | 10.5px | 最大化内容密度 |
| **标准** | 100% | 14px | 推荐设置 |
| **较大文字** | 125% | 17.5px | 轻度视力障碍 |
| **大文字** | 150% | 21px | 中度视力障碍 |
| **更大文字** | 175% | 24.5px | 重度视力障碍 |

**UI 设计**（参考你提供的截图）：

```
系统缩放
调整菜单、窗口、桌面图标和应用内容的大小，
适配不同尺寸与分辨率的屏幕。

┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐
│ 更多   │  │ 标准   │  │ 较大   │  │ 大文字 │  │ 更大   │
│ 空间   │  │        │  │ 文字   │  │        │  │ 文字   │
│ [  ]   │  │ [✓]    │  │ [  ]   │  │ [  ]   │  │ [  ]   │
│ 75%    │  │ 100%   │  │ 125%   │  │ 150%   │  │ 175%   │
└────────┘  └────────┘  └────────┘  └────────┘  └────────┘
```

### 6.2 实现方式

#### 6.2.1 根字号缩放

```css
/* 标准密度（100%） */
html {
  font-size: 14px;
}

/* 较大密度（125%） */
html[data-density="125"] {
  font-size: calc(14px * 1.25); /* 17.5px */
}

/* 更紧凑密度（75%） */
html[data-density="75"] {
  font-size: calc(14px * 0.75); /* 10.5px */
}
```

#### 6.2.2 使用 rem 单位

**所有尺寸都使用 `rem`，自动跟随根字号缩放**：

```css
.button {
  font-size: 1rem;          /* 14px → 17.5px（125%） */
  padding: 0.571rem 1rem;   /* 8px 16px → 10px 20px */
  border-radius: 0.286rem;  /* 4px → 5px */
}
```

#### 6.2.3 组件自适应

**所有组件使用 `rem`，无需单独适配**：

```tsx
const Button = styled.button`
  font-size: var(--font-size-base); /* 1rem */
  padding: var(--spacing-2) var(--spacing-4); /* 0.571rem 1.143rem */
  border-radius: var(--radius-sm); /* 0.286rem */
`;
```

### 6.3 密度持久化

**数据模型**：
```sql
-- app_config 表
INSERT INTO app_config (key, value) VALUES ('density', '100');
-- 值：75 | 100 | 125 | 150 | 175
```

**读取逻辑**：
```typescript
async function loadDensity() {
  const density = await invoke('get_app_config', { key: 'density' });
  updateDensity(parseInt(density) || 100);
}

function updateDensity(density: number) {
  document.documentElement.setAttribute('data-density', density.toString());
  document.documentElement.style.fontSize = `${14 * (density / 100)}px`;
}
```

## 8. 错误处理与通知体系

### 8.1 通知类型

#### 8.1.1 Toast 通知（轻提示）

**用途**：短暂的、非阻塞的反馈

**使用场景**：
- ✅ 操作成功：保存成功、删除成功
- ✅ 操作失败：网络错误、参数错误
- ✅ 系统提示：正在同步、已断开连接

**设计规范**：
- 位置：右上角（距离顶部 80px，距离右侧 20px）
- 宽度：最小 300px，最大 400px
- 高度：自动（根据内容）
- 持续时间：3 秒（error 类型 5 秒）
- 最多显示：3 个（超过则队列等待）
- 动画：滑入（250ms）+ 淡出（250ms）

**结构**：
```
┌─────────────────────────────────┐
│ [图标] 消息内容                  │
│        （可选）详细描述           │  [×]
└─────────────────────────────────┘
```

**示例代码**：
```typescript
// 成功
toast.success('Provider 创建成功');

// 错误（显示错误码和用户建议）
toast.error('Provider 不存在（错误码：1001001）', {
  description: '请检查 Provider ID 是否正确',
  duration: 5000,
});

// 警告
toast.warning('连接不稳定，正在重试...');

// 信息
toast.info('正在同步模型列表');
```

### 8.2 错误码映射

**原则**：所有错误都显示用户友好的消息

```typescript
// errors.ts
export const ERROR_MESSAGES: Record<string, ErrorMessage> = {
  '1001001': {
    message: 'Provider 不存在',
    description: '请检查 Provider ID 是否正确',
    action: '查看 Provider 列表',
    actionLink: '/settings/providers',
  },
  '1001003': {
    message: 'API Key 无效',
    description: 'Provider 返回认证错误',
    action: '重新配置 API Key',
    actionLink: '/settings/providers/:id/edit',
  },
  '1008001': {
    message: '用户名已存在',
    description: '请使用其他用户名',
  },
  // ...
};

// 使用
function handleError(error: AppError) {
  const errorInfo = ERROR_MESSAGES[error.code];
  
  if (errorInfo) {
    toast.error(errorInfo.message, {
      description: errorInfo.description,
      action: errorInfo.action ? {
        label: errorInfo.action,
        onClick: () => navigate(errorInfo.actionLink),
      } : undefined,
    });
  } else {
    toast.error('未知错误');
  }
}
```

### 8.3 统一错误处理流程

```
操作失败
  ↓
捕获错误（try-catch）
  ↓
解析错误码
  ↓
查找错误消息映射
  ↓
判断严重程度
  ├─ 轻微错误 → Toast 通知（3 秒后消失）
  ├─ 中等错误 → Toast 通知 + 操作建议（5 秒）
  └─ 严重错误 → Modal 对话框（需要用户确认）
  ↓
记录错误日志（错误码、堆栈、上下文）
  ↓
（可选）上报错误到监控系统
```

## 13. 技术设计

### 13.1 主题切换实现

```typescript
// theme.ts

// B05-01: 主题类型定义
export type Theme = 'light' | 'dark' | 'auto';

// B05-02: 当前主题状态
let currentTheme: Theme = 'light';
let systemTheme: 'light' | 'dark' = 'light';

// B05-03: 初始化主题
export async function initTheme() {
  // 加载用户偏好
  const savedTheme = await invoke('get_app_config', { key: 'theme' });
  currentTheme = (savedTheme || 'light') as Theme;
  
  // 监听系统主题变化
  const mediaQuery = window.matchMedia('(prefers-color-scheme: dark)');
  systemTheme = mediaQuery.matches ? 'dark' : 'light';
  
  mediaQuery.addEventListener('change', (e) => {
    systemTheme = e.matches ? 'dark' : 'light';
    if (currentTheme === 'auto') {
      applyTheme(systemTheme);
    }
  });
  
  // 应用主题
  applyTheme(resolveTheme(currentTheme));
}

// B05-04: 解析主题（auto → light/dark）
function resolveTheme(theme: Theme): 'light' | 'dark' {
  if (theme === 'auto') {
    return systemTheme;
  }
  return theme;
}

// B05-05: 应用主题
function applyTheme(theme: 'light' | 'dark') {
  document.documentElement.setAttribute('data-theme', theme);
  document.documentElement.style.colorScheme = theme;
}

// B05-06: 切换主题
export async function updateTheme(theme: Theme) {
  currentTheme = theme;
  applyTheme(resolveTheme(theme));
  
  // 保存到数据库
  await invoke('set_app_config', { 
    key: 'theme', 
    value: theme 
  });
}
```

### 13.2 密度系统实现

```typescript
// density.ts

// B05-07: 密度类型定义
export type Density = 75 | 100 | 125 | 150 | 175;

// B05-08: 当前密度状态
let currentDensity: Density = 100;

// B05-09: 初始化密度
export async function initDensity() {
  const savedDensity = await invoke('get_app_config', { key: 'density' });
  currentDensity = parseInt(savedDensity || '100') as Density;
  applyDensity(currentDensity);
}

// B05-10: 应用密度
function applyDensity(density: Density) {
  const baseFontSize = 14; // px
  const scaledFontSize = baseFontSize * (density / 100);
  
  document.documentElement.setAttribute('data-density', density.toString());
  document.documentElement.style.fontSize = `${scaledFontSize}px`;
}

// B05-11: 更新密度
export async function updateDensity(density: Density) {
  currentDensity = density;
  applyDensity(density);
  
  // 保存到数据库
  await invoke('set_app_config', { 
    key: 'density', 
    value: density.toString() 
  });
}

// B05-12: 获取当前密度
export function getCurrentDensity(): Density {
  return currentDensity;
}
```

```typescript
interface ToastOptions {

// B05-14: Toast 队列

  message: string;
  options?: ToastOptions;

const MAX_VISIBLE_TOASTS = 3;
let visibleToastCount = 0;

// B05-15: 显示 Toast
function showToast(type: ToastType, message: string, options?: ToastOptions) {
  const id = `toast-${Date.now()}-${Math.random()}`;
  
  toastQueue.push({ id, type, message, options });
  processQueue();
}

// B05-16: 处理队列
function processQueue() {
  while (visibleToastCount < MAX_VISIBLE_TOASTS && toastQueue.length > 0) {
    const toast = toastQueue.shift()!;
    renderToast(toast);
  }
}

// B05-17: 渲染 Toast
function renderToast(toast: { id: string; type: ToastType; message: string; options?: ToastOptions }) {
  visibleToastCount++;
  
  const duration = toast.options?.duration || (toast.type === 'error' ? 5000 : 3000);
  
  // 创建 DOM 元素
  const element = document.createElement('div');
  element.id = toast.id;
  element.className = `toast toast-${toast.type}`;
  element.innerHTML = `
    <div class="toast-icon">${getIcon(toast.type)}</div>
    <div class="toast-content">
      <div class="toast-message">${toast.message}</div>
      ${toast.options?.description ? `<div class="toast-description">${toast.options.description}</div>` : ''}
    </div>
    <button class="toast-close" aria-label="关闭">×</button>
  `;
  
  // 添加到容器
  const container = getToastContainer();
  container.appendChild(element);
  
  // 动画：滑入
  setTimeout(() => element.classList.add('toast-visible'), 10);
  
  // 关闭按钮
  element.querySelector('.toast-close')!.addEventListener('click', () => {
    removeToast(toast.id);
  });
  
  // 自动消失
  setTimeout(() => {
    removeToast(toast.id);
  }, duration);
}

// B05-18: 移除 Toast
function removeToast(id: string) {
  const element = document.getElementById(id);
  if (!element) return;
  
  // 动画：淡出
  element.classList.remove('toast-visible');
  element.classList.add('toast-hiding');
  
  setTimeout(() => {
    element.remove();
    visibleToastCount--;
    processQueue();
  }, 250);
}

// B05-19: 获取容器
function getToastContainer(): HTMLElement {
  let container = document.getElementById('toast-container');
  if (!container) {
    container = document.createElement('div');
    container.id = 'toast-container';
    document.body.appendChild(container);
  }
  return container;
}

// B05-20: 辅助函数
function getIcon(type: ToastType): string {
  const icons = {
    success: '✓',
    error: '✕',
    warning: '⚠',
    info: 'ℹ',
  };
  return icons[type];
}

// B05-21: 导出 API
export const toast = {
  success: (message: string, options?: ToastOptions) => showToast('success', message, options),
  error: (message: string, options?: ToastOptions) => showToast('error', message, options),
  warning: (message: string, options?: ToastOptions) => showToast('warning', message, options),
  info: (message: string, options?: ToastOptions) => showToast('info', message, options),
};
```
