# V1 功能规格索引

V1 首发交付范围登记 10 项功能，分为底层能力、应用模块和系统功能。后续版本预留功能编号 FR-011 至 FR-015，详见[需求编号](00-V1需求编号.md)和[版本路线图](../../02-产品与版本/版本路线图.md)。实现状态与验证证据统一查看 [V1 实现状态](../../02-产品与版本/当前版本/V1-实现状态.md)。系统设计纳入各功能规格 §7 或当前版本技术设计文档，不另设与功能主规格并行的系统设计文档。

目标版本已按版本路线图的 V1–V8 编号更新（原登记为 V1.2、V1.3、V1.4、V1.5、V2.0）。这 5 个编号带 V1 前缀，是路线图“V2+ 进入门禁前不分配正式编号”规则确立前的早期登记；保留不复用，进入对应版本门禁时再决定是否映射为新版本编号。

这些编号用于后续版本规划，不代表功能已实现或属于 V1 首发范围。新的 V1 需求从 FR-016 开始分配。

## 依赖关系提示

依赖方向和 D023 说明以[追踪矩阵](00-V1需求追踪矩阵.md)及各主规格元信息为准。FR-001 至 FR-005 支撑应用层功能；FR-004 与 FR-008 分别是 FR-009 的上游依赖。D023 规定调用身份由宿主派生，因此 FR-008 不是 FR-001 至 FR-007 的当前实现前置条件。
