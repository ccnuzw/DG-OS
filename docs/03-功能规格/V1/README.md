## 依赖主链路

```text
核心能力链路：
FR-001 Provider 框架 -> FR-006 AI 工作台
FR-002 Skills 管理   -> FR-006 AI 工作台（可选增强）
FR-003 MCP 管理      -> FR-006 AI 工作台（可选增强）
FR-004 模块系统      -> FR-006, FR-007（模块加载）
FR-005 设计系统      -> FR-006, FR-007（UI 组件）

系统功能链路：
FR-008 本地用户 -> FR-009 权限管理 -> FR-010 局域网协同

画布演进链路（后续版本）：
V1.2: FR-011 画布核心
V1.3: FR-011 + FR-012 节点系统
V1.4: FR-011 + FR-012 + FR-013 执行引擎
```
