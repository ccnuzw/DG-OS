## 2. 功能概述

### 2.1 一句话描述

提供统一的系统设置界面，集中管理 Provider、Skills、MCP、模块、主题和用户偏好，让用户可以方便地配置和管理 DGOS。

### 2.2 详细说明

系统设置是 DGOS 的管理中心，所有配置都集中在这里。

**核心价值**：
- ✅ 集中管理：所有配置在一个地方
- ✅ 清晰分类：按功能分 tab（Provider、Skills、MCP、模块、外观、关于）
- ✅ 易于操作：直观的 CRUD 界面
- ✅ 实时生效：配置更改立即生效

**用户价值**：
- 最终用户：方便地管理所有配置
- 开发者：参考实现，学习如何构建管理界面

### 2.3 功能边界

**包含（6 个主要模块）**：

**1. Provider 管理**：
- ✅ Provider 列表（显示所有已配置的 Provider）
- ✅ 添加 Provider（表单输入）
- ✅ 编辑 Provider（修改配置）
- ✅ 删除 Provider（确认提示）
- ✅ 测试连接（验证配置）
- ✅ 刷新模型列表（手动刷新）
- ✅ 拖拽排序（调整优先级）
- ✅ 启用/禁用开关

**2. Skills 管理**：
- ✅ 浏览 Skills 仓库（分类、搜索）
- ✅ 安装 Skills（下载、配置）
- ✅ 已安装 Skills 列表
- ✅ Skills 配置（API Key 等）
- ✅ 卸载 Skills
- ✅ 更新 Skills（检查更新、手动更新）
- ✅ 启用/禁用开关

**3. MCP 管理**：
- ✅ MCP 服务器列表
- ✅ 添加 MCP 服务器（Stdio/HTTP）
- ✅ 编辑 MCP 服务器
- ✅ 删除 MCP 服务器
- ✅ 连接状态显示
- ✅ 工具列表查看
- ✅ 连接日志查看

**4. 模块管理**：
- ✅ 已安装模块列表
- ✅ 模块详情（名称、版本、权限）
- ✅ 启用/禁用模块
- ✅ 卸载模块
- ✅ 检查模块更新
- ✅ 更新模块
- ✅ 查看崩溃日志

**5. 外观设置**：
- ✅ 主题切换（亮色/暗色）
- ✅ 字体大小（小/中/大）
- ✅ 紧凑模式（减少间距）
- ✅ 主题预览

**6. 关于**：
- ✅ DGOS 版本信息
- ✅ 系统信息（OS、架构）

- ✅ 检查更新

## 3. 核心流程

### 3.1 添加 Provider 流程

```
用户打开系统设置
  ↓
点击"Provider"标签
  ↓
显示已配置的 Provider 列表
  ↓
点击"添加 Provider"按钮
  ↓
显示表单：
  - 名称：[我的 OpenAI]
  - 类型：[OpenAI 兼容] (下拉)
  - Base URL：[https://api.openai.com/v1]
  - API Key：[sk-xxx...] (密码输入)
  ↓
点击"测试连接"
  ↓
调用 Provider API 验证
  ↓
（如果成功）显示"连接成功 ✓"
  ↓
点击"保存"
  ↓
Provider 保存到数据库
  ↓
自动获取模型列表
  ↓
显示在 Provider 列表中
```

### 3.2 安装 Skills 流程

```
用户打开系统设置
  ↓
点击"Skills"标签
  ↓
显示两个子标签："浏览仓库" 和 "已安装"
  ↓
点击"浏览仓库"
  ↓
显示官方 Skills 列表（分类）
  ↓
搜索或浏览 Skills
  ↓
点击某个 Skill
  ↓
显示详情：
  - 名称、描述、作者、版本
  - 依赖：Python 3.10+
  - 配置：需要 Google Search API Key
  ↓
点击"安装"
  ↓
检查依赖（Python 版本）
  ↓
（如果依赖不满足）提示"需要 Python 3.10+"
  ↓
（如果满足）下载并安装
  ↓
（如果需要配置）显示配置表单
  ↓
用户输入 API Key
  ↓
保存配置
  ↓
安装完成，显示在"已安装"列表
```

### 3.3 主题切换流程

```
用户打开系统设置
  ↓
点击"外观"标签
  ↓
显示主题选项：
  ○ 亮色主题
  ● 暗色主题 (当前选中)
  ↓
点击"亮色主题"
  ↓
立即应用主题
  ↓
显示预览效果
  ↓
保存用户偏好到数据库
  ↓
（可选）显示"主题已更改"提示
```

### 3.4 模块更新流程

```
用户打开系统设置
  ↓
点击"模块"标签
  ↓
系统自动检查更新
  ↓
显示"AI 工作台有更新"标记
  ↓
点击"查看更新"
  ↓
显示更新日志：
  v1.0.1 → v1.0.2
  - 修复流式输出 bug
  - 优化性能
  ↓
点击"更新"
  ↓
下载新版本
  ↓
显示进度条
  ↓
更新完成（热重载，无需重启）
  ↓
显示"更新成功 ✓"
```

## 4. 数据模型

系统设置主要是对现有数据的管理界面，不新增数据表。

### 4.1 涉及的现有数据表

- `providers` - Provider 配置
- `models` - 模型列表缓存
- `skills` - 已安装的 Skills
- `mcp_servers` - MCP 服务器配置
- `installed_modules` - 已安装模块
- `module_permissions` - 模块权限
- `user_preferences` - 用户偏好（主题等）

### 4.2 读写关系

所有读写操作通过 Tauri Commands 调用对应的管理器：
- Provider 管理 → 调用 `V1-FR-001` 的接口
- Skills 管理 → 调用 `V1-FR-002` 的接口
- MCP 管理 → 调用 `V1-FR-003` 的接口
- 模块管理 → 调用 `V1-FR-004` 的接口
- 主题管理 → 调用 `V1-FR-005` 的接口

### 7.2 Provider 管理界面

```typescript
// apps/desktop/src/views/settings/ProviderSettings.tsx

import { invoke } from '@tauri-apps/api';
import { Button, Modal, Input } from '@dgos/ui';

export const ProviderSettings: React.FC = () => {
  const [providers, setProviders] = useState<Provider[]>([]);
  const [showAddModal, setShowAddModal] = useState(false);
  
  // B07-08: 加载 Provider 列表
  useEffect(() => {
    loadProviders();
  }, []);
  
  const loadProviders = async () => {
    const list = await invoke<Provider[]>('list_providers', {
      userId: getCurrentUserId(),
    });
    setProviders(list);
  };
  
  // B07-09: 添加 Provider
  const handleAddProvider = async (config: ProviderConfig) => {
    await invoke('create_provider', { config });
    await loadProviders();
    setShowAddModal(false);
  };
  
  // B07-10: 测试连接
  const handleTestConnection = async (config: ProviderConfig) => {
    try {
      const result = await invoke<boolean>('test_provider_connection', { config });
      if (result) {
        toast({ message: '连接成功 ✓', type: 'success' });
      }
    } catch (error) {
      toast({ message: '连接失败', type: 'error' });
    }
  };
  
  // B07-11: 删除 Provider
  const handleDeleteProvider = async (id: string) => {
    if (confirm('确定删除此 Provider？')) {
      await invoke('delete_provider', { id });
      await loadProviders();
    }
  };
  
  return (
    <div className="provider-settings">
      <div className="header">
        <h2>Provider 管理</h2>
        <Button onClick={() => setShowAddModal(true)}>添加 Provider</Button>
      </div>
      
      {/* Provider 列表 */}
      <div className="provider-list">
        {providers.map(provider => (
          <ProviderCard
            key={provider.id}
            provider={provider}
            onDelete={() => handleDeleteProvider(provider.id)}
            onTest={() => handleTestConnection(provider)}
          />
        ))}
      </div>
      
      {/* 添加 Provider 模态框 */}
      <Modal open={showAddModal} onClose={() => setShowAddModal(false)}>
        <ProviderForm
          onSubmit={handleAddProvider}
          onTest={handleTestConnection}
        />
      </Modal>
    </div>
  );
};
```

### 7.3 外观设置界面

```typescript
// apps/desktop/src/views/settings/AppearanceSettings.tsx

import { useTheme } from '@dgos/ui';
import { invoke } from '@tauri-apps/api';

export const AppearanceSettings: React.FC = () => {
  const { theme, setTheme } = useTheme();
  const [fontSize, setFontSize] = useState<'small' | 'medium' | 'large'>('medium');
  
  // B07-12: 切换主题
  const handleThemeChange = (newTheme: Theme) => {
    setTheme(newTheme);
    
    // 保存到数据库
    invoke('save_user_theme', { theme: newTheme });
  };
  
  // B07-13: 调整字体大小
  const handleFontSizeChange = (size: string) => {
    setFontSize(size as any);
    
    // 应用到 DOM
    document.documentElement.setAttribute('data-font-size', size);
    
    // 保存到数据库
    invoke('save_user_preferences', { fontSize: size });
  };
  
  return (
    <div className="appearance-settings">
      <h2>外观设置</h2>
      
      {/* 主题选择 */}
      <section>
        <h3>主题</h3>
        <div className="theme-options">
          <label>
            <input
              type="radio"
              value="light"
              checked={theme === 'light'}
              onChange={() => handleThemeChange('light')}
            />
            亮色主题
          </label>
          <label>
            <input
              type="radio"
              value="dark"
              checked={theme === 'dark'}
              onChange={() => handleThemeChange('dark')}
            />
            暗色主题
          </label>
        </div>
      </section>
      
      {/* 字体大小 */}
      <section>
        <h3>字体大小</h3>
        <select value={fontSize} onChange={(e) => handleFontSizeChange(e.target.value)}>
          <option value="small">小</option>
          <option value="medium">中</option>
          <option value="large">大</option>
        </select>
      </section>
      
      {/* 主题预览 */}
      <section>
        <h3>预览</h3>
        <div className="theme-preview">
          <Button variant="primary">主要按钮</Button>
          <Button variant="secondary">次要按钮</Button>
          <Input placeholder="输入框示例" />
        </div>
      </section>
    </div>
  );
};
```
