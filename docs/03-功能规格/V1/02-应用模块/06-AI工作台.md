## 2. 功能概述

### 2.1 一句话描述

提供简单易用的 AI 对话界面，支持 Provider 选择、流式响应、多轮对话、历史记录管理，可选启用 Skills/MCP 增强生成能力。

### 2.2 详细说明

AI 助手是 DGOS 的内置对话产品，面向直接使用 AI 的日常工作；它通过 DG-OS Provider、Skills、MCP 与宿主共享执行核心提供能力，不调用 Codex 或 Claude Code CLI 运行时。CLI Agent 是独立的编程代理入口，继续由对应 CLI 原生运行时负责执行。该命名变更按[D141](../../../06-决策记录/V7-冻结决策.md#d141-内置对话产品正式命名为-ai-助手)执行，不改变内部 Chat/会话实体及 IPC。

**核心价值**：
- ✅ 简单易用：类似 ChatGPT 的对话界面
- ✅ 灵活选择：可以选择不同的 Provider 和模型
- ✅ 工具增强：可选启用 Skills/MCP 增强生成能力
- ✅ 历史管理：保存所有对话历史，可搜索
- ✅ 流式体验：实时看到 AI 生成过程

**用户价值**：
- 最终用户：快速与 AI 对话，完成各种任务
- 开发者：参考实现，学习如何调用 Provider

### 2.3 功能边界

**包含**：
- ✅ 对话界面（输入框、消息列表）
- ✅ Provider 选择（下拉选择、模型选择）
- ✅ 流式响应（D140已扩展至工具轮次真实增量；仅完整合法参数可批准，见§2.7）
- ✅ 多轮对话（上下文保持，受预算约束，见 D075）
- ✅ 历史记录（会话管理、消息保存）
- ✅ Skills 增强（会话内固定版本，显式选择）
- ✅ MCP 增强（每次发送显式选择，逐次确认，见 D022）
- ✅ 中断生成（停止按钮）
- ✅ 复制消息（复制按钮）
- ✅ 重新生成（重试按钮；成功后替换，见 D076）
- ✅ Markdown 渲染（代码高亮；安全约束见 AC29）
- ✅ 会话搜索（按内容搜索）
- ✅ D133桌面聊天增量：账户受控文本附件、PNG/JPEG/WebP与显式选择服务的麦克风转写，见§2.6；画布多模态引擎仍归V2。

**不包含**（明确说明原因）：
- ❌ 代码执行 → V2 画布系统
- ❌ 插件系统（自定义对话增强） → V3 应用市场
- ❌ 协同对话（多人同时聊天） → V4 云端协同
- ❌ 语音输出及移动端语音体验 → V6 移动端；D133桌面采集转写不扩大该范围。
- ❌ 任意会话级 `system_prompt` → 仍不开放。D133迁移增量允许保存温度、推理、输出上限与用户指导，保持宿主system固定，详见下节。
- ❌ 多个重新生成版本的分支浏览 → 不做（D076，用户选择新回复成功后替换旧回复）
- ❌ 远程设备读取聊天历史 → 归 V1-FR-010 单独决策；V1 聊天命令只对桌面主窗口开放

桌面聊天与单任务采用[D133](../../../06-决策记录/V2-冻结决策.md#d133-迁移阶段6真实能力与账户资源边界)：用户选择并排列多个内容Skills，每项固定版本/哈希，发送时逐项重验，重复或不可用项明确拒绝，不静默降级或截断。顺序仅定义请求顺序，不自动裁决自然语言冲突，也不保证后项覆盖前项。技能正文与自定义指导均为用户角色内容，不能授予工具权限。

会话保存生成参数；单任务显式参数覆盖默认。长度短/中/长对应1024/4096/8192输出tokens，已知模型上限必须满足；温度留空使用服务默认值，思考参数复用FR-001画像映射。普通请求与工具每轮一致，不支持的参数显式拒绝。所有指导计入24 KiB上下文预算，任务审计不保存指导文本。已有AC10/AC20/AC21/AC23在本迁移切片按此增量验收；D074取消/终态不变。接口字段以[接口契约§10](../../../04-技术架构/当前版本/V1-接口契约.md#10-对话管理接口)为准。

### 2.6 D133迁移增量：附件、图片与语音

附件由桌面用户选择文件后导入账户受控资产。UTF-8文本每项≤1 MiB；PNG/JPEG/WebP每项≤8 MiB；每次最多4项、共24 MiB。导入、预览、移除、发送与历史读取均由宿主验证当前账户归属，不接收任意本机路径。预览文本按纯文本显示，图片按受控字节显示；无引用草稿可移除，已持久消息引用保护资产，移除草稿不删除消息资产。取消导入后晚到的资产不得回填，并清理该次未引用资产。发送失败保留草稿附件；仅收到宿主确认后转入消息展示。

文本附件计入24 KiB上下文预算，超限拒绝。图片只允许向明确标记`vision=supported`的模型发送，`unknown`与`unsupported`均明确拒绝；普通流式与工具轮次使用同一受控资产。历史与重新生成从持久引用读取，不猜测文件变化，不泄漏本机路径。

- 语音通过系统麦克风授权与`MediaRecorder`真实采集，最长60秒、音频≤25 MiB。用户显式选择当前账户已配置、启用且有凭据的OpenAI兼容服务及转写模型，点击转写后才外发。结果先追加到可编辑草稿，不自动发送；音频不进入聊天历史。取消、工作面销毁与账户结束释放采集、计时器、预览URL与转写租约；迟到的授权或结果不得回填旧会话。失败或结果未知不自动重发，用户可明确重试。无设备、系统拒绝或不支持录音格式时明确报错，不生成假转写。命令字段统一见[接口契约§10.1](../../../04-技术架构/当前版本/V1-接口契约.md#101-聊天命令d072d077及d140)。

### 2.7 D140持续完善增量

用户于2026-11-09授权实施CHAT-P1～P6，保守取舍见[D140](../../../06-决策记录/V7-冻结决策.md#d140-ai会话持续完善与受控能力增量)，实现方法见[持续完善技术设计](../../../04-技术架构/当前版本/AI会话持续完善技术设计.md)。本节定义目标行为，不代表验证已通过；与前文历史阶段口径冲突时，以本增量为准。

- **可靠性**：停止不触发发送；已派发、结果未知、usage缺失和审计异常分别保真。发送准备、模型调用、审批后工具执行均受原账户租约和能力重验约束，旧回执不能进入新账户。
- **上下文**：发送前可检查模型窗口、宿主预算、输出预留、历史、技能、附件和工具占用，估算不冒充实际tokens。用户明确确认后才调用当前Provider整理；摘要绑定来源范围及哈希，保留原文，来源变化失效，取消/失败不替换有效摘要。摘要和资料仍是用户级不可信内容。
- **技能**：默认空技能和显式绑定继续有效；增加候选建议及用户选择的固定授权集合内按需发现、正文加载和包内资源读取。每次读取验证账户、启用状态、版本/hash和路径边界，不自动安装或更新，不执行脚本，不授予工具权限。界面显示实际加载回执，不用候选列表假装消费证据。
- **工具**：支持真实增量协议和阶段事件；参数未完整结束且未通过schema校验前不得批准。可保留用户的工具选择偏好，但每轮重验可用性、每次仍精确审批。原始工具结果不进入普通审计；大结果必须明确省略并受控读取，unknown和审计异常阻止自动推进。
- **恢复**：有界批量保存可恢复正文及步骤回执，重启仅只读核实。明确继续创建新请求和原运行关联，重新准入，不恢复旧批准、不重放完成操作；未知副作用必须先核实，无法核实时阻断继续。
- **限制**：仍每账户一个活动生成，摘要与继续共享额度；无自动压缩、跨会话记忆、多Agent、并行工具、无人值守运行或任意本地执行。真实服务与本地替身证据分级。

### 2.8 ASST-FOUNDATION 运行基础增量

本批ASST-F1～F6由用户授权，具体保守行为以[AI助手运行基础技术设计](../../../04-技术架构/当前版本/AI助手运行基础技术设计.md)为依据；不新增决策ID、业务应用或隐藏聊天。不提升既有真实上游证据等级，也不授予CLI运行时、LAN工具或无人值守权限。

- **双入口共享**：AI助手与受信模块的`host.ai`使用同一基础资源/预算/输出后校验及现有执行循环，各自保留宿主身份和内容域。聊天不伪造模块任务；模块不借`chat_assets`或聊天会话取资料。聊天原有消息/检查点保留与显式摘要/继续命令保持有效，`foundation.retain_result`不关闭原聊天保留；模块正文则默认不保留，只有用户显式开启才进入独立限期内容域。
- **固定资料**：显式导入UTF-8纯文本/Markdown或PNG/JPEG/WebP，不接收路径/URL，不执行脚本。宿主固定账户及`module:<id>`/`chat:<session>`来源，随机ID、SHA-256和24小时不可续租资源；文本≤1 MiB、图片≤8 MiB、每账户/scope共≤24 MiB。每次≤16个不重复引用，固定hash及UTF-8字节范围，inline或on_demand；图片只整图inline发送至明确支持vision的模型。删除、过期、撤权后重验失败，不借历史片段继续读取。资源名与模型文本都不授予权限。
- **渐进与预算**：手动技能默认；显式按需技能只消费本次授权固定pins，资源工具只列/读固定资料子集。与MCP共用一个循环，本地只读不获得外部工具许可。检查与派发共用24 KiB文本上限、窗口/输出/图片/schema预留及编码预算，实际回执只证明提供的ID/hash/范围，不表示完整理解；详情见[接口契约§17.5](../../../04-技术架构/当前版本/V1-接口契约.md#175-d136-ai-公共服务与模块-ipc)。
- **输出与交付**：`text`默认；显式`json_schema`是生成后校验，非法/超限schema在外发前拒绝，不合规终答失败，不自动付费修复，不以JSON有效表示业务成功。模块正文/部分正文≤64 KiB、最长24小时、每scope最多32份；过期或淘汰只清正文，回读expired不表示从未执行。读取与幂等确认不派发、不续租、不代表应用保存成功；与通用无正文审计分离。
- **恢复边界**：继续必须用户新意图、新run与来源关联，只有保留的终态且无未决/unknown副作用和审计失败才可重新准入；继承规范化server/tool/args指纹，不能换模型call ID重放已执行副作用。旧批准无效，重启只读核实不自动派发。模块摘要须确认额外调用、固定选定来源并保留原文；聊天继续沿D140专用命令。模块独立2控制槽不扩大8执行槽；同realm不是文档安全沙箱，隐藏/切换与真正卸载的生命周期语义见FR-004。

共享DTO和聊天的具体字段约束只在[接口契约§10.1、§17.5](../../../04-技术架构/当前版本/V1-接口契约.md)维护；迁移与清理由[数据模型](../../../04-技术架构/当前版本/V1-数据模型.md)说明。

## 3. 核心流程

### 3.1 首次使用流程

```
用户首次打开 AI 助手
  ↓
没有可用 Provider 时：提示先到设置中配置 Provider（no_provider_configured）
  ↓
新建会话（可以先不选目标）
  ↓
选择 Provider 和模型（模型来自本地缓存，必须是 text-generation）
  ↓
显示输入框
  ↓
用户输入并发送（渲染进程生成 client_request_id）
  ↓
宿主校验、组装上下文、写入用户消息与占位的助手消息，立即返回确认
  ↓
通过 Channel 逐段显示助手回复
  ↓
结束事件携带落库后的消息快照，界面以快照为准
```

### 3.2 多轮对话流程

```
用户在现有会话中，输入新消息
  ↓
宿主读取该会话 completed 的历史轮次，按顺序构造上下文：
  宿主 system → 用户顺序的Skills与自定义指导（user消息）→ 历史轮次 → 当前消息
  ↓
超过预算时从最旧的整轮开始丢弃，不截断单条；返回被丢弃的轮数，界面提示
  ↓
调用 Provider 流式接口
  ↓
interrupted 与 failed 的轮次不进入上下文
```

渲染进程只提交用户文本，不提交角色。宿主 system 文本沿用 D018。

### 3.3 Skills 增强流程

```
会话默认不选技能；用户可按需显式选择并排列多个技能版本
  ↓
会话按顺序保存每项技能、版本和内容哈希
  ↓
每次发送前宿主重新校验启用状态、版本存在和哈希
  ↓
通过：按所选顺序将技能正文作为独立 user 消息计入预算；任务行记录每项确切版本和位置
失败：阻断为 skill_unavailable，不静默降级，不静默换版本
  ↓
用户显式重选后才更新会话绑定；有新版本可用时只提示
```

技能不具有工具权限，也不继承模块权限（D016/D018）。

2026-11-08取消聊天空技能门槛：旧会话`no_skill_confirmed=false`不阻断空技能发送；已选技能失效仍阻断。D140及ASST-FOUNDATION增量允许用户显式开启固定授权集合的按需发现/加载，不按关键词或模型文本自动扩大集合；技能选择器搜索本身不是实际加载回执。独立单任务显式无技能确认不变。

### 3.4 中断生成流程

```
AI 正在生成（助手消息为 generating）
  ↓
用户点击"停止"，或离开页面、重载、窗口销毁
  ↓
宿主先记录停止原因，再触发取消令牌，关闭上游连接
  ↓
终态事务：
  有已收到内容 → 助手消息 interrupted，保留内容
  无内容       → 助手消息 failed
  任务行 interrupted / task_cancelled
  ↓
上游已被调用但没有用量时，界面提示"结果未知，上游可能已计费"
```

网络错误、空闲超时、宿主总时长或大小上限走同一套终态事务，错误类别不同。映射表见 D074。

### 3.5 会话管理流程

2026-11-06 用户调整：打开的会话使用内层标签；右键标签提供重命名、关闭、删除会话，作用于该标签且不要求先切换。键盘聚焦标签后可用 Shift+F10 或菜单键打开菜单。重命名与删除使用弹窗，取消后焦点返回对应标签；关闭生成中的会话仍需确认并等待停止终态。正文上方不再保留这三个操作按钮。

按用户要求，消息列表不再显示“数据与隐私说明”及其六条说明；数据存储、删除、审计、上下文和工具轮次语义不变。删除确认仍说明应用内不可恢复及物理擦除边界，工具选择器保留工具上下文提示。

输入区按用户任务归位：左侧为添加材料、回答偏好、Skills和更多功能；右侧为Provider/模型、推理强度、上下文指示与发送或停止。工具选择与语音输入收在同一“更多功能”面板，不叠开选择弹层；已选附件、材料、技能和工具按实际状态显示，可移除。各选择器向上展开，Provider列表左对齐；点击模型立即保存该Provider/模型，成功关闭，失败保留弹层、旧目标与消息草稿，不提交其他面板未保存的生成参数。Skills支持搜索、真实分类及有序多选，固定技能与授权按需读取在同一入口分区管理，推荐不自动授权，关闭按需读取不删除可选集合；选择不等于已消费。内置分类与技能中心共用本地化映射，未知第三方分类保留原文。回答偏好以语言、详略、结构和风格要求为主，温度、最大输出token和JSON Schema收在高级区；最大输出token是截断上限，不冒充回答详略。附件限制、语音显式转写、工具逐次审批和生成中禁止修改目标保持不变。

2026-11-09输入区精修：移除目标更新成功提示及未应用目标常驻提示区，消息输入默认两行、最小56px（同时满足两行文字高度）。独立“推理强度”弹层仅提供默认/低/中/高四档选择，不显示预算、应用按钮或说明；点击后只保存推理配置，成功关闭，失败留在弹层显示错误。其他参数草稿保持未应用；目标成功不再占用输入区提示行，发送错误和已选上下文仍按实际状态展示。

2026-11-10产品化交互（沿用AC10、AC20～AC23、AC35～AC41）：

- **材料**：本条附件和托管参考材料共用“添加材料”。导入托管副本不自动引用；可明确选择全文或在只读预览中选中文字，宿主返回固定hash与UTF-8范围。预览沿用账户、会话、期限和hash校验，文本预览有界，截断明确披露；图片仅整图。移除引用保留副本，删除副本另行确认且不删除原文件；过期和不可用状态明确显示。字节范围/hash移到技术详情。
- **上下文与用量（D148）**：环形入口展开紧凑用量卡片，默认只展示上下文预估、本会话统计和压缩操作，算法、字节上限与摘要正文在二级详情。预估输入加输出预留，图片不重复相加，未知窗口不显示百分比，独立主机限制继续生效。会话统计以宿主逐调用持久事实聚合，不依赖消息分页；输入包含缓存、输出包含协议定义的推理子集，缓存不再次加到总计。明确回报零与未知分开，缺失覆盖标记为部分；Provider 删除不减少保留会话累计。压缩须确认额外模型请求及可能费用，原消息保留，成功以摘要安装为准；失败/未知不自动重试，预算和统计独立刷新。见 AC45～AC47。
- **执行与批准（D147）**：回复内保留生成中、完成和历史的同一执行摘要，正常步骤默认折叠，普通问答无空卡；诊断入口不再常驻为任务详情按钮，会话执行历史保留。MCP调用逐次展示服务、工具和完整参数后确认，审批与对应回复关联且只有一个固定可达操作区；结果未知先核实，用户报告不伪装成权威回执、不清除审计警告。继续回到主输入区，明确来源与新意图并确认新的可能计费请求，不恢复旧请求、不沿用旧批准、不重放原操作。

```
用户从会话标签或历史入口选择会话
  ↓
点击某个会话 → 加载最近一页消息，向上滚动加载更早的消息
  ↓
可以继续对话
---
用户点击"新建会话"→ 创建会话 → 切换到新会话
---
用户删除会话
  ↓
该会话有活动生成 → 拒绝（generation_in_progress），提示先停止
  ↓
确认提示："确定删除？应用内将无法恢复。已删除内容可能残留在数据库空闲页和备份中。"
  ↓
单事务删除会话与消息；对应任务审计行保留（不含内容），不再关联会话
```

### 3.6 MCP 工具轮次流程

```

  ↓
模型流式返回文字与结构化 tool_calls；完整参数验证后才提出一次调用
  ↓

  ↓
宿主用保存的参数申请单次 MCP 调用；结果作为不可信数据回传模型
  ↓
最终助手文本作为普通消息保存；有界步骤与结果回执保留于账户聊天运行域，不进入通用日志
```

会话可记住工具选择偏好，但不保存批准，下一次发送重新校验工具与schema。普通历史上下文以问答为主；显式继续按D140携带来源进度与防重放指纹，不恢复旧工具批准。其余未被D140取代的D022规则保持。

#### 3.6.1 受控联网与来源（D147）

输入区显式启用本次请求的搜索/网页读取，默认关闭、发送后不作为下一请求批准。搜索使用Brave官方API和独立OS凭据，未配置时说明配置入口；指定公开HTTPS网页读取可独立启用。启用不立即发网络，发送前披露查询/URL外发和费用；本次专用只读授权不扩大MCP、CLI、模块或LAN权限。

搜索、读取与来源展示沿同一执行核心；宿主校验公开地址、DNS、重定向及内容预算。来源ID只来自实际取得的记录，正文引用打开标题、域名、时间及有界片段；区分搜索摘要和网页正文，来源真实不等于模型结论正确。失败、截断、未知、过期与引用不可用不得伪装成功。次数上限为每请求3次搜索/5次读取且受总8次工具操作限制；不自动重试、不静默换服务。技术契约见[回复与联网技术设计](../../../04-技术架构/当前版本/AI助手回复与联网技术设计.md)。

### 3.7 重新生成流程

```
用户点击最后一条助手消息的"重新生成"
  ↓
宿主新建一条带 replaces_id 的助手占位消息和新的任务行（新的计费调用）
  ↓
成功 → 一个事务内删除旧回复，保留新回复
失败、取消、重启 → 保留旧回复，丢弃新半成品
```

只允许最后一条助手消息；历史上下文不含被替换的回复。

- 旧 `chat_sessions.user_id` 外键 `users(id)` 不可建立；改为 TEXT 无外键，由宿主派生。

### 4.2 读写关系

**读取**：
- 会话列表：当前用户，按 `(updated_at, id)` 倒序 keyset 分页。
- 消息：当前用户的会话，按 `seq` 倒序分页读取最近一页，不含 `replaces_id` 不为空的半成品。
- 搜索：见 AC28 与 D076。

**写入**：
- 发送与重新生成：开始事务写任务行、技能引用、用户消息和占位助手消息。
- 终态：单事务更新助手消息与任务行（条件更新）。
- 删除：单事务置空任务的 `session_id` 并删除会话（级联消息）。

所有读写同时按 `id` 与 `user_id` 过滤。完整事务边界见技术设计"事务边界"。

Given 普通问答、工具执行、待批准、失败或结果未知的回复及其持久运行记录

When 生成结束、重新打开历史、展开步骤或从回复继续处理

Then 普通问答无空执行卡，实时与历史摘要事实一致，展开偏好不被增量重置；审批参数完整且操作始终可达，未知显式阻断；新意图通过主输入区发送，技术诊断不成为日常必经路径

#### AC43 请求级联网与可信来源

Given 用户明确启用本次搜索/读取，存在已配置/未配置密钥或不可访问网页

When 助手调用专用联网工具并生成引用

Then 只调用所授权能力与指定后端，搜索未配置不外发，公开HTTPS读取受网络安全和预算约束；来源来自真实回执，引用不能越过当前运行来源集合；新请求不继承联网批准，MCP仍逐次确认，失败不生成假来源

#### AC44 事件分段、补读与凭据生命周期

Given 多轮模型/工具输出、重复/迟到事件、断线与账户切换，或搜索密钥配置/轮换/账户删除

When 分段更新、补读历史或提交凭据变更

Then 序号与归属防止状态回退/串写，终态只封口一次，中间说明与最终正文分开且有界；补读零派发；凭据只在vault，指针CAS和清理outbox与Provider互斥，失效租约/删除账户不能留下可用新指针，其他账户凭据不受影响

#### AC45 紧凑上下文与有效快照

Given 已知或未知模型窗口、草稿与材料变化、主机超限以及账户/会话切换

When 打开用量浮层、检查上下文或进入详情

Then 正常桌面首屏无需滚动可读核心信息，图片预算不重复相加、未知窗口无百分比，主机拒绝仍可见；过期响应不覆盖新目标，生成中快照明确为上次检查；键盘可进入详情、返回和关闭并恢复焦点

#### AC46 全会话逐调用计量

Given 普通回复、工具循环和摘要运行，包含明确零、未回报、部分回报及旧历史数据

When 查询当前会话、加载历史、重启或删除 Provider 配置

Then 全会话累计不受消息分页或最近日志上限影响，每次真实模型调用独立计量且重复终态不增加总数；缓存为输入子集，命中率分子分母同范围，生成耗时排除工具和审批等待；未知不计零，旧总量不与同源明细重复；保留会话累计不因 Provider 删除缩减，其他账户不可读，删除会话清理其统计

#### AC47 显式压缩与独立刷新

Given 可压缩的宿主历史、当前模型与草稿，或忙碌/未决结果/无历史状态

When 用户确认压缩并经历成功、取消、失败、结果未知或刷新失败

Then 资格由宿主判断且提交复验，确认前零模型派发，重放不重复调用；成功以摘要安装为准且保留原消息，预算和累计用量分别刷新；无有效同输入快照不比较下降，刷新失败不抹掉成功摘要，失败/未知不自动重试

## 6. 接口设计

### 6.1 Tauri Commands（桌面端）

**以下是 Ready 的命令契约，权威定义在[接口契约 §10.1](../../../04-技术架构/当前版本/V1-接口契约.md)。** 约定：身份由宿主派生，所有命令不接收 `user_id`；返回 `CommandResponse` 与数字错误码；输入拒绝未知字段；每个命令经宿主入口校验主窗口，使用 `Workbench` 调用方的 `TasksRun`；模块上下文一律拒绝。

字段名以[接口契约 §10.1](../../../04-技术架构/当前版本/V1-接口契约.md)为准：`input` 内的字段为 snake_case；顶层参数沿用 Tauri 2 默认命名（`onEvent`、`taskId`）。

| 命令 | 参数 | 返回 |
| --- | --- | --- |
| `create_chat_session` | 可选 `target`（`provider_id`、`model_id`、`skill_id`、`no_skill`） | 会话 |
| `list_chat_sessions` | `cursor?`、`limit?` | 会话页 |
| `rename_chat_session` | `session_id`、`title` | 会话 |
| `update_chat_session_target` | `session_id`，加 Provider/模型及可选技能；空技能默认可执行，`no_skill`仅保留旧请求兼容；字段同`target` | 会话 |
| `delete_chat_session` | `session_id` | 无 |
| `search_chat_sessions` | `query`、`cursor?`、`limit?` | 会话页（含片段与匹配数） |
| `list_chat_messages` | `session_id`、`before_seq?`、`limit?` | 消息页 |
| `send_chat_message` | `session_id`、`content`、`client_request_id`、`accept_destination?`、`tools?`（至多 8 个）；顶层 `onEvent`（Channel） | 确认：`task_id`、`user_message_id`、`assistant_message_id`、`dropped_turns`、`replayed` |
| `cancel_chat_generation` | 顶层 `taskId` | 布尔值 |
| `regenerate_chat_message` | `message_id`、`client_request_id`、`accept_destination?`；顶层 `onEvent`（Channel） | 同发送的确认 |
| `advance_chat_tool_turn` | `task_id`、`action`（批准或拒绝当前提案） | 无；进度走该轮发送时传入的 `onEvent` |

与原稿相比：移除 `get_session_config`/`update_session_config`（D073）；`stream_chat_message` 与 `send_chat_message` 合并，因为发送总是流式的；`interrupt_chat_stream` 改为按任务 ID 取消的 `cancel_chat_generation`；`get_chat_session` 暂不单列，由列表与消息接口覆盖；复制是纯前端行为，没有命令。

**流式事件**：每次生成由渲染进程传入 `Channel`，宿主不发全局事件。事件为 `started`、`delta`、`reasoning_delta`、`done`、`error`；`done` 与 `error` 之一恰好出现一次且携带落库后的助手消息快照。渲染进程以快照为准，不依赖累积的 `delta`。事件可能先于 `invoke` 的返回到达，需按助手消息 ID 缓存。推理文本只实时显示。

带MCP工具的轮次按D140提供真实增量事件；仅完整合法参数产生`tool_proposal`，仍由`advance_chat_tool_turn`逐次批准/拒绝。ASST-FOUNDATION共享资料导入、foundation配置及聊天专用摘要/继续限制见[接口契约§10.1](../../../04-技术架构/当前版本/V1-接口契约.md#101-聊天命令d072d077及d140)，不改变单任务六个命令。

错误码以 [V1-错误码 §3.6](../../../04-技术架构/当前版本/V1-错误码.md) 的登记为准；Provider 产生的错误原样透传其 1001xxx 编码，不包装（D073）。原稿本节的 1006001～1006006 已作废；1006003、1006004 标注未使用，不复用。

| 语义键 | 编码 | 场景 |
| --- | --- | --- |
| session_not_found | 1006001 | 会话不存在或不属于当前用户（两者不区分） |
| message_not_found | 1006002 | 消息不存在（已登记；聊天命令目前不发出，重新生成的不存在与他人消息返回 1006014） |
| session_creation_failed | 1006005 | 会话创建失败（存储错误） |
| session_deletion_failed | 1006006 | 会话删除失败（存储错误） |
| invalid_message_content | 1006007 | 空消息、超长消息、无效标题 |
| context_too_long | 1006008 | 单条消息或丢弃全部历史后仍超出预算 |
| no_provider_configured | 1006009 | 完全没有可用 Provider |
| generation_in_progress | 1006010 | 用户已有活动生成，或要删除有活动生成的会话 |
| request_id_conflict | 1006011 | 相同请求标识但内容不同 |
| destination_changed | 1006012 | Provider 目标指纹变化，需用户确认 |
| skill_unavailable | 1006013 | 会话固定的技能被禁用、缺失或哈希不符 |
| message_not_regenerable | 1006014 | 目标消息不存在、属于他人、不是最后一条助手消息，或正在生成（不区分） |
| provider_not_selected | 1006015 | 会话没有目标，或目标 Provider 已被删除 |
| invalid_search_query | 1006016 | 搜索串去空白后不在 1 到 128 字符，或游标无效 |
| tool_turn_invalid | 1006017 | 聊天工具轮次的动作与提案不匹配、已过期或不存在 |
| web_unavailable | 1006022 | D147专用联网授权、配置或调用失败；`detail.reason`固定原因，原始网络/凭据错误不外泄；不复用工具批准错误 |
| send_message_failed、stream_interrupted | 1006003、1006004 | 未使用；流中断透传 Provider 的 1001007 |

任务审计的 `error_code` 类别（如 `task_cancelled`、`process_interrupted`、`generation_limit`、`provider_<码>`）是固定字符串，不是 IPC 错误码。

## 9. 非功能需求

### 9.1 性能需求

下列目标值沿用原稿，除搜索与分页已有合成规模数据（§2.4“阶段 6 门禁”6-C）外，**尚未用真实 Provider 或规模数据校准**；"首字节"一项取决于上游，宿主只能保证不增加额外排队。

| 指标 | 目标 | 测量方式 |
| --- | --- | --- |
| 消息发送延迟 | < 500ms（首字节，不含上游排队） | Performance API |
| 流式响应延迟 | < 100ms（每块，宿主转发） | Performance API |
| 历史加载 | < 500ms（100 条消息） | Performance API |
| UI 渲染帧率 | > 60fps | React DevTools |
| 长列表 | 1000+ 消息分页加载并限制渲染节点数，不卡顿；不做虚拟化（D077） | 手动测试 |
| 搜索 | 1 万条消息的合成库上单次不超过 300 毫秒（D076 自选阈值） | 合成库计时 |

### 9.2 可用性需求

| 需求 | 实现方式 |
| --- | --- |
| 快捷键支持 | Enter 发送，Shift+Enter、Ctrl+Enter 或 Cmd+Enter 换行（`Composer.tsx` 的 `onKeyDown`）；输入法组合输入期间不触发发送（中文输入法回车选词） |
| 保存时机 | 用户消息在发送事务内保存；助手消息在终态事务保存（D074）。进程被强杀时本次生成内容可能丢失 |
| 错误恢复 | 发送失败可手动重试；重试是新请求 |
| 离线提示 | 网络断开时提示用户 |
| 删除说明 | 如实说明"应用内不可恢复"，不承诺物理擦除（D072） |
| 用量显示 | 未知用量显示为"未知"，不显示 0 |
