## 2. 目标

为桌面用户和局域网远程用户提供一致的简体中文 / English 界面，并允许用户在系统设置的“外观”页面选择固定语言或跟随系统语言；语言切换立即生效、重启后保持，且不因本地账户切换而改变。

## 3. 功能边界

### 3.1 包含

- 支持 `zh-CN`、`en-US` 和 `system` 三种语言偏好值。
- 默认偏好为 `zh-CN`；旧数据库没有语言记录时也使用 `zh-CN`。
- 语言偏好保存于主机级 `host_settings` 的 `ui.language`，不保存到用户级 `system_settings`。
- 在 `/settings/appearance` 与主题、界面缩放并列提供语言选择。
- 桌面端宿主页面、账户门禁页面、系统设置、错误提示、Toast、Modal、无障碍文本、日期时间和数字格式支持双语。
- 局域网远程 SPA 与桌面端使用同一个主机解析语言。
- 动态模块通过 `host.i18n` 获取当前解析语言并订阅变化；随包模块支持双语。
- 构建或测试阶段检查中英文资源 key 的完整性，禁止因缺少翻译静默显示另一种语言。

### 3.2 不包含

- 日语、韩语、繁体中文等第三种翻译语言（原因：本期只验证中英双语）。
- 用户自定义语言包、在线下载翻译包和翻译管理后台（原因：不属于 V1 本地优先闭环）。
- 每个本地账户独立的语言偏好（原因：已冻结为主机级设置）。
- 每个远程设备独立覆盖语言（原因：第一期要求与主机解析语言一致）。
- 翻译用户输入、Provider / 模型 / MCP Server / Skill 名称、Skill 正文、AI 输出和外部原始错误详情。
- 复杂复数规则、右到左布局和本地化内容管理。

## 5. 需求说明

### 5.1 用户故事

作为 DGOS 用户，我希望在外观设置中选择界面语言，以便在中文和英文工作环境中使用统一、完整且不混杂的界面。

### 5.2 语言模型

| 偏好值 | 界面标签 | 解析规则 |
| --- | --- | --- |
| `zh-CN` | 简体中文 | 始终解析为 `zh-CN` |
| `en-US` | English | 始终解析为 `en-US` |
| `system` | 跟随系统语言 | 系统语言为中文或简体中文变体时解析为 `zh-CN`，其他语言解析为 `en-US` |

`system` 是语言偏好模式，不是第三种翻译资源。当前解析结果只能是 `zh-CN` 或 `en-US`。

### 5.3 业务规则

1. 偏好值只能是 `zh-CN`、`en-US`、`system`；宿主和前端都必须拒绝其他值，不回显非法输入（D118）。
2. 缺失、不可读取或非法的主机语言偏好使用 `zh-CN`，并且不得阻塞应用启动。
3. `system` 的系统语言判断由宿主语言服务统一提供；桌面端和局域网远程端不能各自实现不同的判断规则。
4. 语言偏好写入失败时，界面回退到写入前的解析语言和偏好值，并以写入前语言显示错误提示。
5. 语言偏好不包含 `user_id`，本地账户登录、注销和切换不得修改它。
6. 所有用户可见宿主文案必须通过本地化资源读取；允许保留的动态内容仅限本规格“不包含”所列项目。
7. 缺少翻译 key 是开发/构建错误，不得在生产界面静默回退到另一种语言；运行时只允许回退到固定的开发错误提示，不得展示未登记的用户文案。
8. 语言切换不改变主题、界面缩放、路由、表单输入、会话、任务或业务数据。
9. 局域网远程端启动时获取主机当前解析语言；主机之后改变语言不强制推送给已打开的远程页面，远程页面重新加载或重新建立资源上下文时应用新语言。
10. 动态模块只能使用宿主提供的 `host.i18n` 当前语言和订阅能力；模块不得修改宿主语言偏好或注入全局翻译资源。

### 5.4 主流程

1. 应用启动时，宿主语言服务读取 `host_settings.ui.language`。
2. 若记录不存在或无效，返回 `zh-CN` 偏好；若偏好为 `system`，解析系统语言得到 `zh-CN` 或 `en-US`。
3. 前端首帧门控完成语言初始化，再渲染账户门禁或应用外壳。
4. 用户打开 `系统设置 → 外观`，选择简体中文、English 或跟随系统语言。
5. 前端先应用解析语言并刷新所有订阅者，再调用类型化宿主命令保存偏好。
6. 写入成功后保留新偏好；写入失败时恢复旧偏好和旧解析语言，并显示本地化错误提示。
7. 局域网远程 SPA 读取主机 bootstrap 的解析语言，渲染配对页和聊天页。

### 5.5 异常与边界

- 主机语言偏好缺失：使用 `zh-CN`，不显示错误。
- 系统语言无法读取：`system` 解析为 `en-US`，不阻塞应用；实现需记录脱敏诊断日志。
- 语言写入失败：回滚前端状态，不产生部分成功的 UI 状态。
- 多次快速切换：语言写入按单主机队列串行化；失败时丢弃该次之后仍未提交的批次并回退到最近确认值。
- 远程 bootstrap 不可用：远程端先使用 `zh-CN` 最小启动文案；取得主机语言后切换；不得把错误详情直接展示给远程用户。
- 翻译 key 参数缺失：开发测试失败；生产环境使用登记的通用错误文案，不拼接未转义的异常文本。
- 语言资源中存在用户内容：只翻译资源模板，不翻译或修改动态业务字段。

### 5.6 页面与交互

外观页增加第三组单选项：

```text
语言
  ○ 简体中文
  ○ English
  ○ 跟随系统语言
```

切换立即生效，无需刷新或重启。选择项标签始终使用稳定的自称名称“简体中文”“English”“跟随系统语言”，不随当前语言翻译为另一组易混淆名称。

## 6. 接口契约

公共响应、宿主身份和错误封装沿用 [V1 接口契约](../../../04-技术架构/当前版本/V1-接口契约.md)。本功能不开放通用设置键读写命令。

### 6.1 桌面 Tauri 命令

| 方法 | 路径 / 命令 | 鉴权 | 用途 |
| --- | --- | --- | --- |
| `GET` | `get_language_preferences` | 受信宿主主窗口 | 读取主机语言偏好、解析语言和资源版本 |
| `PATCH` | `set_language_preferences` | 受信宿主主窗口 | 校验并保存主机语言偏好，返回完整确认结果 |

建议响应数据：

```json
{
  "preference": "system",
  "locale": "en-US",
  "catalog_version": "v1"
}
```

请求只允许：

```json
{ "language": "zh-CN" }
```

前端不得提交 `user_id`、`setting_key` 或任意配置字段。

### 6.2 局域网 bootstrap

增加不包含敏感信息的 `GET /api/v1/lan/bootstrap`，响应只包含当前主机解析语言和资源版本：

```json
{
  "locale": "zh-CN",
  "catalog_version": "v1"
}
```

该接口不返回语言偏好原值、用户信息、文件路径、端口凭据或账户状态。它可以在配对前访问；其余聊天和会话接口继续遵循 FR-010 的认证边界。

### 6.3 动态模块接口

宿主向模块注入：

```ts
interface HostI18n {
  readonly locale: 'zh-CN' | 'en-US';
  subscribe(listener: (locale: 'zh-CN' | 'en-US') => void): () => void;
}
```

`host.i18n` 只提供解析语言和变化订阅，不提供修改主机偏好的能力。

### 6.4 错误矩阵

| 错误码 | 错误键 | 场景 | 用户提示 |
| --- | --- | --- | --- |
| 复用 `1000000` | `language_preferences_unavailable` | 读取或保存主机语言偏好失败 | 使用当前语言显示“无法保存语言设置，请重试” |
| 复用 `1005002` | `invalid_language_preference` | 请求包含未知语言值或额外字段 | 使用当前语言显示“语言设置无效” |
| 复用 `1000000` | `locale_bootstrap_unavailable` | 远程 bootstrap 读取失败 | 使用远程端当前后备语言继续，不显示内部详情 |

具体错误码仍以错误码登记处和实现时的接口契约变更为准；若新增错误码，必须先追加决策并同步登记处。

## 7. 数据与事务

### 7.1 读写数据

| 数据 | 操作 | 字段 |
| --- | --- | --- |
| `host_settings` | R/W | `setting_key = ui.language`、`setting_value`、`updated_at` |
| 本地化资源包 | R | `locale`、资源 key、资源版本 |

### 7.2 约束与事务

- `ui.language` 使用现有 `host_settings.setting_key` 唯一约束。
- 首次读取不写入默认值，避免启动时产生不必要的数据库写入；返回缺省值即可。
- 保存时只更新 `ui.language`，不能覆盖 `lan.port` 或最近登录用户等其他主机设置。
- 语言偏好保存是单行 upsert，失败不改变已确认偏好。
- 语言资源为随应用发布的静态资源，不进入 SQLite，不接受远程下载内容。

### 7.3 状态与生命周期

```text
未初始化
  → 已加载（preference + locale）
  → 应用中（新 locale 已应用，等待保存）
  → 已确认
  → 回滚（保存失败）
```

远程页面的 bootstrap 状态为：

```text
后备语言 → 请求主机语言 → 已应用主机语言 / 保持后备语言
```

## 8. 验收标准

#### AC01 默认语言

Given 旧数据库没有 `ui.language` 记录。

When 应用启动并完成语言初始化。

Then 偏好为 `zh-CN`，账户门禁和应用首屏使用简体中文，且不写入默认记录。

#### AC02 语言选项

Given 用户打开 `/settings/appearance`。

When 查看外观设置。

Then 显示简体中文、English、跟随系统语言三项，且主题和界面缩放仍完整存在。

#### AC03 固定中文

Given 当前语言偏好为 `en-US`。

When 用户选择简体中文并保存成功。

Then 整个桌面宿主界面立即使用 `zh-CN`，重启后仍使用 `zh-CN`。

#### AC04 固定英文

Given 当前语言偏好为 `zh-CN`。

When 用户选择 English 并保存成功。

Then 整个桌面宿主界面立即使用 `en-US`，重启后仍使用 `en-US`。

#### AC05 跟随系统

Given 用户选择跟随系统语言。

When 系统语言为中文、英文和其他语言时分别启动应用。

Then 中文系统解析为 `zh-CN`，英文和其他未支持语言解析为 `en-US`；偏好值仍保存为 `system`。

#### AC06 主机级范围

Given 主机存在两个本地账户。

When 用户切换账户、注销再登录或重新打开账户门禁。

Then 界面继续使用同一个主机语言，不因账户变化而切换。

#### AC07 立即切换

Given 用户正在任一桌面页面。

When 在外观页选择另一种语言。

Then 导航、页面标题、按钮、表单、Toast、Modal、无障碍文本和错误提示在无需刷新页面的情况下更新。

#### AC08 保存失败回滚

Given 宿主拒绝保存语言偏好。

When 用户选择另一种语言。

Then 界面回退到保存前的语言和偏好值，错误提示使用保存前语言显示，且不覆盖原有主机设置。

#### AC09 启动前语言

Given 应用处于首次启动、未登录、登录失败或数据库错误页。

When 页面显示欢迎页、登录页、账户状态错误或数据库打开失败。

Then 这些页面使用已解析语言，不先显示另一种语言再切换。

#### AC10 桌面宿主页面完整性

Given 分别使用 `zh-CN` 和 `en-US`。

When 浏览主导航、Provider、Skills、MCP、模块、Workbench、设置、账户和局域网设置页面。

Then 用户可见的宿主固定文案、状态、表单、空状态、错误、Toast、Modal、aria 文本和 placeholder 均使用当前语言，不出现未登记的中英混排。

#### AC11 动态内容边界

Given 页面包含 Provider 名称、模型 ID、Skill 正文、MCP 名称、用户输入或 AI 输出。

When 切换语言。

Then 这些动态内容原样保留，只翻译周围的固定标签和说明。

#### AC12 日期和数字格式

Given 当前语言分别为 `zh-CN` 和 `en-US`。

When 查看日期、时间、相对时间和数字。

Then 所有固定格式化入口使用当前语言的 `Intl` 规则，不再由页面自行硬编码 `zh-CN` 或浏览器默认值。

#### AC13 远程 bootstrap

Given 局域网服务运行且主机解析语言为 `zh-CN` 或 `en-US`。

When 远程浏览器打开或重新加载页面。

Then 配对页、连接状态、聊天页和会话错误使用主机解析语言；bootstrap 不泄露偏好原值或敏感信息。

#### AC14 远程离线后备

Given 远程端无法读取 bootstrap。

When 远程页面启动或重连。

Then 页面使用确定性的后备语言继续显示可操作的配对/重试界面，不展示内部异常详情。

#### AC15 动态模块语言上下文

Given 随包动态模块已加载。

When 宿主语言改变。

Then 模块可通过 `host.i18n` 收到新的解析语言并更新自身固定文案，且模块不能修改宿主偏好。

#### AC16 资源完整性

Given 中英文资源文件和所有调用 key。

When 执行本地化资源检查。

Then 两种语言的 key 集合完全一致，插值参数一致，重复 key 和未登记 key 失败。

#### AC17 语言与既有外观设置隔离

Given 用户快速切换主题、界面缩放和语言。

When 所有写入完成或其中一次写入失败。

Then 三种偏好各自保持正确值，不互相覆盖，主题控制器的回滚语义不改变。

#### AC18 英文布局与无障碍

Given 使用 English 并分别设置 75%、125%、175% 界面缩放。

When 浏览设置、管理页、错误提示和远程聊天页面。

Then 文案可读、按钮和表格不发生不可操作的溢出，焦点环、名称和状态仍可被键盘与辅助技术识别。
