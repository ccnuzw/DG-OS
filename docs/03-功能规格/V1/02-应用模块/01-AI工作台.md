## 2. 功能概述

### 2.1 一句话描述

提供简单易用的 AI 对话界面，支持 Provider 选择、流式响应、多轮对话、历史记录管理，可选启用 Skills/MCP 增强生成能力。

### 2.2 详细说明

AI 工作台是 DGOS 的核心应用模块，让用户可以直接与 AI 对话，完成各种文本生成任务。

**核心价值**：
- ✅ 简单易用：类似 ChatGPT 的对话界面
- ✅ 灵活选择：可以选择不同的 Provider 和模型
- ✅ 工具增强：可选启用 Skills/MCP 增强生成能力
- ✅ 历史管理：保存所有对话历史，可搜索
- ✅ 流式体验：实时看到 AI 生成过程

**用户价值**：
- 最终用户：快速与 AI 对话，完成各种任务
- 开发者：参考实现，学习如何调用 Provider

### 2.3 功能边界

**包含**：
- ✅ 对话界面（输入框、消息列表）
- ✅ Provider 选择（下拉选择、模型选择）
- ✅ 流式响应（SSE、打字机效果）
- ✅ 多轮对话（上下文保持）
- ✅ 历史记录（会话管理、消息保存）
- ✅ Skills 增强（可选启用）
- ✅ MCP 增强（可选启用）
- ✅ 中断生成（停止按钮）
- ✅ 复制消息（复制按钮）
- ✅ 重新生成（重试按钮）
- ✅ Markdown 渲染（代码高亮）
- ✅ 会话搜索（按内容搜索）

**不包含**（明确说明原因）：
- ❌ 多模态输入（图片、语音） → V2 画布系统
- ❌ 代码执行 → V2 画布系统
- ❌ 插件系统（自定义对话增强） → V3 应用市场
- ❌ 协同对话（多人同时聊天） → V4 云端协同
- ❌ 语音输入/输出 → V6 移动端

## 3. 核心流程

### 3.1 首次使用流程

```
用户首次打开 AI 工作台
  ↓
显示引导："选择一个 Provider 开始对话"
  ↓
用户点击 Provider 选择器
  ↓
显示已配置的 Provider 列表
  ↓
用户选择"我的 OpenAI"
  ↓
显示模型列表（从 Provider 获取）
  ↓
用户选择"gpt-4"
  ↓
创建新会话
  ↓
显示输入框："请输入消息..."
  ↓
用户输入："写一个 Python 函数"
  ↓
点击发送
  ↓
显示用户消息
  ↓
调用 Provider API（流式）
  ↓
逐字显示 AI 响应（打字机效果）
  ↓
响应完成，保存消息到数据库
```

### 3.2 多轮对话流程

```
用户在现有会话中
  ↓
查看历史消息（上下文）
  ↓
输入新消息："能不能加个单元测试？"
  ↓
系统构造请求：
  - messages: [
      {role: "user", content: "写一个 Python 函数"},
      {role: "assistant", content: "def add(a, b): ..."},
      {role: "user", content: "能不能加个单元测试？"}
    ]
  ↓
调用 Provider API（带上下文）
  ↓
AI 基于上下文生成回复
  ↓
显示响应
  ↓
保存消息
```

### 3.3 Skills 增强流程

```
用户启用 Skills
  ↓
选择"Web Search" Skill
  ↓
输入："最新的 Rust 新闻"
  ↓
系统构造 Prompt：
  "你可以使用 web_search 工具搜索网页。
   用户问题：最新的 Rust 新闻"
  ↓
调用 Provider API
  ↓
AI 返回："让我搜索一下..."（可能包含工具调用）
  ↓
系统检测到工具调用请求
  ↓
调用 Skills Manager
  ↓
执行 web_search("Rust 新闻")
  ↓
将结果注入回 AI
  ↓
AI 基于搜索结果生成最终回复
  ↓
显示响应
```

### 3.4 中断生成流程

```
AI 正在生成响应
  ↓
用户点击"停止生成"
  ↓
中断 SSE 流
  ↓
显示已生成的部分
  ↓
标记消息为"已中断"
  ↓
保存已生成部分到数据库
```

### 3.5 会话管理流程

```
用户在侧边栏查看会话列表
  ↓
显示所有会话（按时间排序）
  ↓
用户点击某个会话
  ↓
加载该会话的消息历史
  ↓
显示在对话区域
  ↓
用户可以继续对话
  ↓
---
用户点击"新建会话"
  ↓
创建新会话
  ↓
切换到新会话
  ↓
---
用户删除会话
  ↓
确认提示："确定删除？"
  ↓
删除会话和所有消息
```

## 4. 数据模型

### 4.1 涉及的数据表

**chat_sessions 表**（会话）：
```sql
CREATE TABLE chat_sessions (
    id TEXT PRIMARY KEY,              -- UUID
    title TEXT,                       -- 会话标题（自动生成或用户修改）
    provider_id TEXT,                 -- 使用的 Provider
    model_id TEXT,                    -- 使用的模型
    system_prompt TEXT,               -- 系统提示词（可选）
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    user_id TEXT,                     -- 所属用户
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (provider_id) REFERENCES providers(id)
);
```

**chat_messages 表**（消息）：
```sql
CREATE TABLE chat_messages (
    id TEXT PRIMARY KEY,              -- UUID
    session_id TEXT NOT NULL,         -- 所属会话
    role TEXT NOT NULL,               -- 角色：user, assistant, system
    content TEXT NOT NULL,            -- 消息内容
    metadata JSON,                    -- 元数据（token 数、延迟等）
    interrupted BOOLEAN DEFAULT FALSE,-- 是否中断
    created_at TIMESTAMP,
    FOREIGN KEY (session_id) REFERENCES chat_sessions(id) ON DELETE CASCADE
);
```

**chat_session_config 表**（会话配置）：
```sql
CREATE TABLE chat_session_config (
    id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL,
    enabled_skills JSON,              -- 启用的 Skills 列表
    enabled_mcp_servers JSON,         -- 启用的 MCP 服务器列表
    temperature REAL DEFAULT 0.7,     -- 温度参数
    max_tokens INTEGER,               -- 最大 token 数
    FOREIGN KEY (session_id) REFERENCES chat_sessions(id) ON DELETE CASCADE,
    UNIQUE(session_id)
);
```

### 4.2 读写关系

**读操作**：
- 获取会话列表：`SELECT * FROM chat_sessions WHERE user_id = ? ORDER BY updated_at DESC`
- 获取会话消息：`SELECT * FROM chat_messages WHERE session_id = ? ORDER BY created_at ASC`
- 获取会话配置：`SELECT * FROM chat_session_config WHERE session_id = ?`
- 搜索会话：`SELECT DISTINCT session_id FROM chat_messages WHERE content LIKE ?`

**写操作**：
- 创建会话：`INSERT INTO chat_sessions`
- 更新会话标题：`UPDATE chat_sessions SET title = ?, updated_at = ? WHERE id = ?`
- 删除会话：`DELETE FROM chat_sessions WHERE id = ?`（级联删除消息）
- 插入消息：`INSERT INTO chat_messages`
- 更新会话配置：`INSERT OR REPLACE INTO chat_session_config`

## 7. 技术设计

### 7.1 核心消息处理流程

```rust
// 以下 ChatService/SkillsManager 流程为 D016 前旧设计参考，不是当前 Rust crate 或实现方案。

pub struct ChatService {
    db: DatabasePool,
    provider_manager: Arc<ProviderManager>,
    skills_manager: Arc<SkillsManager>,
    mcp_manager: Arc<MCPManager>,
}

impl ChatService {
    // B06-01: 发送消息（流式）
    pub async fn stream_message(
        &self,
        session_id: &str,
        content: String
    ) -> Result<Stream<ChatChunk>> {
        // B06-02: 获取会话信息
        let session = self.db.get_chat_session(session_id).await?;
        
        // B06-03: 获取历史消息（上下文）
        let history = self.db.list_chat_messages(session_id).await?;
        
        // B06-04: 构造 messages 数组
        let mut messages = vec![];
        
        // 添加系统提示词（如果有）
        if let Some(system_prompt) = &session.system_prompt {
            messages.push(ChatMessage {
                role: "system".to_string(),
                content: system_prompt.clone(),
            });
        }
        
        // B06-05: 添加历史消息
        for msg in history {
            messages.push(ChatMessage {
                role: msg.role,
                content: msg.content,
            });
        }
        
        // B06-06: 添加当前消息
        messages.push(ChatMessage {
            role: "user".to_string(),
            content: content.clone(),
        });
        
        // 保存用户消息到数据库
        self.db.insert_chat_message(session_id, "user", &content).await?;
        
        // B06-07: 检查是否启用 Skills/MCP
        let config = self.db.get_session_config(session_id).await?;
        
        if let Some(skills) = config.enabled_skills {
            // B06-08: 注入 Skills 信息到系统提示词
            let skills_prompt = self.build_skills_prompt(&skills).await?;
            messages.insert(0, ChatMessage {
                role: "system".to_string(),
                content: skills_prompt,
            });
        }
        
        if let Some(mcp_servers) = config.enabled_mcp_servers {
            // B06-09: 注入 MCP 工具信息
            let mcp_prompt = self.build_mcp_prompt(&mcp_servers).await?;
            messages.insert(0, ChatMessage {
                role: "system".to_string(),
                content: mcp_prompt,
            });
        }
        
        // B06-10: 调用 Provider（流式）
        let stream = self.provider_manager
            .stream_call(&session.provider_id, &session.model_id, messages)
            .await?;
        
        // B06-11: 包装流，保存响应到数据库
        let db = self.db.clone();
        let session_id = session_id.to_string();
        
        let wrapped_stream = stream.map(move |chunk| {
            // 累积内容
            // 流结束时保存到数据库
            chunk
        });
        
        Ok(wrapped_stream)
    }
    
    // B06-08: 构造 Skills Prompt
    async fn build_skills_prompt(&self, skill_ids: &[String]) -> Result<String> {
        let mut prompt = "你可以使用以下工具：\n\n".to_string();
        
        for skill_id in skill_ids {
            let skill = self.skills_manager.get_skill(skill_id).await?;
            prompt.push_str(&format!(
                "- {}: {}\n",
                skill.name,
                skill.description
            ));
        }
        
        prompt.push_str("\n如果需要使用工具，请在回复中说明。");
        
        Ok(prompt)
    }
    
    // B06-09: 构造 MCP Prompt
```

### 7.2 前端流式处理

```typescript
// 规划中的 useChat；当前仓库尚无此完整聊天 hook。

import { invoke } from '@tauri-apps/api';
import { listen } from '@tauri-apps/api/event';

export const useChat = (sessionId: string) => {
  const [messages, setMessages] = useState<ChatMessage[]>([]);
  const [streaming, setStreaming] = useState(false);
  const [currentChunk, setCurrentChunk] = useState('');
  
  // B06-13: 发送消息（流式）
  const sendMessage = async (content: string) => {
    setStreaming(true);
    setCurrentChunk('');
    
    // 添加用户消息
    const userMessage: ChatMessage = {
      id: generateId(),
      role: 'user',
      content,
      createdAt: new Date(),
    };
    setMessages(prev => [...prev, userMessage]);
    
    // B06-14: 监听流式事件
    const unlisten = await listen<ChatChunk>('chat:stream', (event) => {
      const chunk = event.payload;
      
      // B06-15: 累积内容
      setCurrentChunk(prev => prev + chunk.content);
    });
    
    try {
      // 调用后端
      await invoke('stream_chat_message', {
        sessionId,
        content,
      });
      
      // B06-16: 流结束，保存 AI 消息
      const aiMessage: ChatMessage = {
        id: generateId(),
        role: 'assistant',
        content: currentChunk,
        createdAt: new Date(),
      };
      setMessages(prev => [...prev, aiMessage]);
      setCurrentChunk('');
    } catch (error) {
      console.error('发送消息失败', error);
    } finally {
      setStreaming(false);
      unlisten();
    }
  };
  
  // B06-17: 中断生成
  const interrupt = async () => {
    await invoke('interrupt_chat_stream', { sessionId });
    setStreaming(false);
  };
  
  return {
    messages,
    streaming,
    currentChunk,
    sendMessage,
    interrupt,
  };
};
```
