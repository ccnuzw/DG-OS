# V2 需求编号管理

本文登记 V2（画布系统）功能需求的稳定编号（[D100](../../06-决策记录/V2-冻结决策.md)、[D103](../../06-决策记录/V2-冻结决策.md)）。V2 处于门禁准备阶段：编号已生效，功能主文档以 Draft 起步，尚未通过[版本进入开发门禁](../../02-产品与版本/版本进入开发门禁.md)，没有实现状态。

## 1. 编号规则

### 1.1 功能需求

格式为 `V2-FR-XXX`，`XXX` 为三位数字。编号分配后不更改、不复用、不重排；取消的需求保留原编号并标注为已取消。V2 当前已分配 `V2-FR-001` 至 `V2-FR-010`。

### 1.2 非功能需求与 E2E 场景

格式分别为 `V2-NFR-XXX` 与 `V2-E2E-XX`，尚未分配。500 个节点的性能门槛预计登记为 NFR，测量条件在门禁时定义。

## 2. 编号稳定性

- 编号一经分配，功能改名、文档迁移或需求取消均不改变编号。
- 取消编号不复用；允许因取消而跳号。
- 文件序号与编号后两位一致：`V2-FR-010` 的主文档为 `10-*.md`，即使它在 `01-底层能力/` 下。
- 跨版本需求使用对应版本前缀，不把 V1 编号改作 V2 编号。
