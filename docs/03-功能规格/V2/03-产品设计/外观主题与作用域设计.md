# 外观主题与作用域设计

> 设计分篇，属于 [V2-FR-009 主规格](09-产品设计与UI改版.md)。主题快照、默认映射和受控出口按D126冻结；最终页面布局仍按迁移阶段安排。完整V2版本门禁不因阶段2实现自动通过，遵循D097、D100、D106。

## 1. 产品目标与入口

入口保持 `/settings/appearance`，在设置内按“主题与颜色 / 字体与排版 / 更多外观”组织。用户可以直接使用内置套装，也可以只修改其中几项；切换明暗、调整阅读字号或更换套装时，其他偏好保持可预测。

截图是能力参考；本设计用一套编辑器切换浅色与深色配置，避免将全部字段重复铺开。外观草稿即时预览于当前窗口，移除单独的缩略预览和整窗预览开关。设置壳的其他分类、语言入口和业务能力按主规格保留。

## 2. 分层模型

| 层 | 内容 | 生效边界 |
| --- | --- | --- |
| 模式 | 浅色、深色、跟随系统 | 决定当前解析哪份配色，不删除另一份 |
| 明暗配置 | 浅色套装、深色套装各自选择 | 允许浅色用暖纸、深色用石墨 |
| 套装 | 语义颜色、表面层次、边界和交互状态的完整配对 | 系统发布的内置资源，只读 |
| 用户颜色覆盖 | 当前明暗配置下，按操作界面、阅读、代码记录 | 字段缺省代表继承，不复制继承后的值 |
| 排版与体验 | 三类字体、三类字号、内容行高、密度、减少动效 | 独立于明暗配置与套装 |
| 运行时解析 | 派生表面、次要文字、on-accent、hover、focus | 由唯一主题内核生成，不允许页面自行调色 |

五套预设及三域控制均为本次整体切换必交付。D126冻结所有缺快照账户使用studio新安装默认；旧用户precision映射提案已取消，新系统不保留旧两键升级或兼容。

### 2.1 预设注册表

每个预设只声明三个种子色（强调色、背景、前景），浅色与深色各一组；其余语义色一律由内核派生。新增预设 = 增加一组种子并登记，不新增代码分支。

| 预设 ID | 名称 | 浅色种子（强调 / 背景 / 前景） | 深色种子（强调 / 背景 / 前景） |
| --- | --- | --- | --- |
| `precision` | 精密蓝 | `#1555d9` `#faf8f1` `#242831` | `#94b7ff` `#202321` `#eeeee7` |
| `studio` | 暖灰工作室（默认） | `#a46a24` `#f8f6ef` `#29323d` | `#ddb576` `#242521` `#eae9e2` |
| `paper` | 暖纸琥珀 | `#985b05` `#faf6ed` `#303129` | `#e9be76` `#26231e` `#f0e8da` |
| `forest` | 静谧松绿 | `#176748` `#f3f7f3` `#26382e` | `#89d8af` `#19251f` `#e0eee5` |
| `slate` | 石墨紫 | `#6942b5` `#f5f5fa` `#30313e` | `#c5abff` `#22212b` `#eeebf6` |

种子唯一声明于 `src/ui/tokens/presets.json`，运行时、构建脚本与宿主校验读取同一份种子；静态派生结果生成于 `presets.css`，不手工维护第二份色板。

状态色（成功、警告、失败、信息）不属于预设，只随明暗变化，避免品牌色替代系统语义。

套装仅替换当前明暗配色基线，不重置公共排版、阅读跟随、语言或密度。无覆盖显示主题名称，有覆盖显示“主题名称 · 已自定义（N）”，按显式覆盖字段计数。点击同一套装无操作；换其他套装时，无覆盖直接替换，有覆盖必须选择“使用新套装原色”（清空该模式全部区域覆盖）、“保留自定义”或“取消”。不影响另一模式。

## 3. 作用域与继承

| 设置对象 | 涵盖 | 不影响 |
| --- | --- | --- |
| 操作界面 | 主框架、桌面、导航、标题、表单、按钮、设置和浮层 | 正文/代码已明确覆盖的颜色与字号 |
| 阅读与输入 | 会话正文、消息输入、任务输入和结果正文 | 工具栏、导航、代码块、系统诊断标签 |
| 代码与技术值 | 代码块、Diff、日志正文、路径与技术标识 | 自然语言正文、代码块标题栏和复制按钮 |
| 界面密度 | 控件高度、图标、间距、分栏最小空间 | 内容/代码的显式字号，窗口外框、画布视口缩放 |
| 内容行高 | 阅读正文与多行自然语言输入 | 导航、按钮、代码固定行高 |

解析规则：内置默认 → 当前模式选中的套装 → 操作界面覆盖 → 阅读或代码覆盖 → 语义派生。阅读和代码中没有覆盖的颜色随操作界面走；代码的覆盖优先于包裹它的阅读区域。字号、字体按角色选取，不用根字号替代所有内容字号。

例如：浅色选择暖纸，界面强调色改蓝，阅读背景改米白，代码字号改 16px。切换深色时只换配色；代码仍为 16px。把浅色套装改为松绿时，蓝色强调和阅读米白覆盖保留；单击强调色的“自定义 · 恢复”后，它才重新继承松绿。

### 3.1 派生规则

表面与装饰用固定比例；凡是承担文字或控件边界职责的颜色，一律按**对比度目标**求解。固定比例只在个别预设上碰巧达标，新增预设就会失效。

| 输出 | 方式 | 目标 |
| --- | --- | --- |
| panel / rail / inset | 固定比例混合 | 表面层级，无对比度要求 |
| border | 固定比例 | 装饰分隔，已登记豁免 |
| control | 与 panel、rail、inset 均达标的最小混合量 | ≥3:1（WCAG 1.4.11） |
| muted | 与三种表面均达标的最小混合量 | ≥4.5:1 |
| on-accent | 白色与前景色中对比度更高者 | ≥4.5:1 |
| primary-hover / active | 强调色向前景混合 8% / 16%（深色反向） | 与 on-accent 保持可读 |

求解按 0.01 步长递增，结果确定、可静态测试。任一预设无法满足目标时，该预设在构建期即失败，不进入候选列表；运行时不做降级。

这里的“作用域”首先是视觉区域。**不在本次默认引入每会话、每项目或每节点独立主题**，以免同一套宿主控件出现不同规则。未来模块消费宿主语义角色；画布网格和节点分类色由画布规格单独定义，不可覆盖审批、错误等系统语义。

## 4. 字体、字号与尺寸

本节为用户确认的外观优化第一阶段口径；字体来源按D126的2026-11-07用户确认纠正，使用系统默认和本机已安装字体，取代随包字体要求。D126的事务、身份与配色边界继续适用。

| 项目 | 正式范围 | 说明 |
| --- | --- | --- |
| 界面字体 | 跟随系统（`system-ui`）、本机已安装字体族 | 阅读独立字体同此范围；默认系统字体，不下载或随包提供字体文件 |
| 代码字体 | 系统等宽（`system-mono`）、本机已安装且明确等宽的字体族 | 代码及技术值、编辑器、Diff、日志和真实终端；不将未知或比例字体列为代码候选 |
| 界面字号 | 12–20px，整数步长1 | 滑杆与可编辑px输入同步；默认12px，保留标题和辅助文字层级 |
| 代码字号 | 12–24px，整数步长1 | 默认12px；不改变导航、工具栏和复制按钮 |
| 阅读排版 | 始终展开，默认跟随界面；分段切换跟随/独立，可设置独立字体与12–24px字号 | 跟随是动态继承；切独立以当前有效界面值初始化；恢复跟随将独立字段重置为当时界面值，不保留隐藏历史 |
| 内容行高 | 1.5 / 1.75 / 2.0 | 默认1.75；代码固定1.5，默认禁用代码连字 |
| 布局缩放 | 60～150，每10一档，默认100（D138） | 单Slider及增减/恢复100；仅几何与留白，作用域、旧值转换、快捷键及局部预算见§4.1；不与三域字号相乘 |

默认展示“字体与字号”四个入口：界面字体、界面字号、代码字体、代码字号。阅读跟随覆盖对话正文、自然语言输入、任务输入与结果正文。字体与字号、阅读跟随均为跨明暗模式的公共偏好，切模式或配色不得重置。

字体目录由原生只读`list_local_fonts`提供，仅受信Settings/Appearance可调用；返回去重的`{family:string, monospace:boolean}[]`，family为可直接用于CSS的实际字体族名，不返回文件路径。成功结果按进程缓存，新安装字体在重启后发现；失败或无可用字体明确返回错误，不能把枚举失败伪装成空列表。前端共用一份目录，区分加载中、加载成功、加载失败，并提供失败提示及显式重试；系统默认选项始终可用。代码本地候选只取`monospace=true`，不凭名称猜测。下拉样张使用实际字体，界面包含“中文示例 Aa 0123”，代码包含“0 O 1 l I {} =>”。

持久化字体对象为`FontSelection = {kind:'system-ui'} | {kind:'system-mono'} | {kind:'local',family:string}`；界面/阅读只允许system-ui或local，代码只允许system-mono或local。family以精确族名为稳定标识，去首尾空白后为1～200个Unicode字符，拒绝控制字符；它始终按单个字体族名解释，不作为CSS栈、URL或文件路径执行；对象拒绝未知键。保存校验不依赖本机目录，避免缺失字体阻断其他偏好保存。

共享字体解析器统一供主题、预览、编辑器和终端使用；本地族名先安全转义为单个CSS字符串，再接角色的系统回退栈，不直接拼接原始输入。目录加载中/失败或保存的字体不在本机时，仅运行时使用系统回退，保留原选择，并分别显示“字体目录读取失败”与“已保存字体当前不可用”。修改配色等其他字段并应用时仍保存原本地选择，只有用户明确更换字体或恢复默认才改变它。中文回退使用平台已安装族（macOS PingFang SC、Windows Microsoft YaHei/UI与SimSun、Linux Noto Sans CJK SC/WenQuanYi，代码优先平台CJK等宽族后通用monospace），不依赖网络或承诺附带字库；比例字形不得冒充等宽目录项。

终端在原实例使用共享解析结果更新字体与字号，字体就绪后重新测量并沿现有尺寸同步路径更新PTY；不重建PTY、不重启会话、不清空输出、不重放输入。中英文宽度由真实渲染器处理，不用英文字符宽度推算中文。

新安装及恢复全部默认：mode=light、两模式studio、density=100，界面`{kind:'system-ui'}`/12px、代码`{kind:'system-mono'}`/12px、阅读跟随界面（保存阅读字体为system-ui、有效12px，替代旧默认13px）、lineHeight=1.75、sidebarTreatment=solid、reducedMotion=system。已有值不为统一默认而覆盖。

字体对象自schema4引入，现行快照schemaVersion=6，typography将旧uiFontId/readingFontId/codeFontId替换为uiFont/readingFont/codeFont对象，保留必填readingFollowUi布尔值；固定键appearance.snapshot.v2及已执行migration不变。schema2/3读取时按下表确定字体映射，不查目录、不探测安装状态；schema2阅读一律保守转独立（readingFollowUi=false，包括旧system/13px，无法区分是否主动保存），schema3～5保留readingFollowUi，schema4/5保留字体对象。所有有效字号、行高、配色、effects及其他偏好均保留；density直接映射规则见§4.1。只内存规范化，保留有效revision和原始行，显式完整快照CAS才写schema6；目录查询和运行时回退不触发保存。新写拒绝未知键、缺字段、旧ID字段和非法值，未来schema>6只读并拒绝恢复；旧程序不得降级覆盖不支持的schema。

| schema2/3旧ID（仅用于读取迁移） | schema4起的字体选择对象 |
| --- | --- |
| `system` | 按角色默认：界面/阅读system-ui，代码system-mono |
| `mono` | system-mono（代码角色） |
| `inter` | local `Inter` |
| `source-sans-3` | local `Source Sans 3` |
| `noto-sans-cjk-sc` | local `Noto Sans CJK SC` |

上述本地族即使当前缺失也保留其意图，不转换为系统选择；旧ID不进入schema6新写或运行时选择接口。

预览、保存、取消、失败、冲突、未确认核查与重启沿用§5/§8事务；恢复当前明暗只改配色，恢复全部默认恢复阅读跟随。账户由宿主派生，远程LAN不消费主机排版偏好。保留现有轻细聚焦，不引入双框、发光或粗轮廓。
### 4.1 第四阶段布局缩放与空间预算

D138取代D137三档：布局缩放十档为60/70/80/90/100/110/120/130/140/150，默认100。技术值除以100即既有100档的几何比例，100保持14px几何根基准，60为8.4px、150为21px；三域字号与文字行高仍由独立px/无单位排版令牌输出，不随根rem再次缩放。每档需经同页同字号实际截图审阅，不能仅凭数值推定可用性。

| 范围 | 最终规则 |
| --- | --- |
| 不跟随 | 界面/阅读/代码字体、字号及文字行高；1px边框/分隔/轻细聚焦线；持久分栏比例；窗口外框、系统比例、图片/视频内容及未来画布视口；LAN设备外观 |
| 跟随且容纳文字 | 控件padding/最小高度、图标/开关/复选框几何、工具栏/列表/卡片及页面留白；大字自然撑高，不以固定height裁字；圆角保持适度比例 |
| 有界预算 | 主栏改为竖向图文/纯图标双态，尺寸唯一见[FR-009尺寸基线](09-产品设计与UI改版.md#阶段1最终渲染基线与响应式推荐)；设置分类168px和Provider列表220px为100档基准，受上下限与文字需求约束；阅读最大宽按可读行长与剩余空间约束，不随几何无限增长；设置外框仍最大1000px×90dvh |
| 局部切换 | 主壳按假设展开后的内容预算决定自动收起，不以当前收起结果反馈判断；工作台/资源详情按自身容器和当前字/几何需求判断，保留挂载、选择、草稿、焦点及用户比例，不持久化自动收起或临时夹紧值 |

外观页只提供一个Slider（min=60、max=150、step=10），同步显示当前百分比，并提供减一档、增一档、恢复100；端点不越界，恢复100只预览，沿用整页保存/取消。不得保留旧三档按钮或增加第二份密度配置。macOS主窗口使用Command+-减一档，Command+=以及Command+Shift+=增一档；组件已消费（defaultPrevented）的事件不抢占，避免劫持编辑器或局部控件快捷键。

活动外观编辑器以beginEditing():()=>void在页面生命周期注册/释放，不能只按当前URL推断。存在活动编辑器时，adjustLayoutScale(-1|1)只改变draft及当前窗口预览，不自动写库；保存与取消仍按整页事务。无活动编辑器时以当前confirmed为基线仅改变density，完整快照按顺序自动CAS；连续按键在上一revision确认后提交后续意图，单一写入在途，不夹带未保存草稿，不并发覆盖其他字段。成功、端点和失败反馈使用同一个轻量气泡渠道，不额外叠加成功/错误Toast；组件已消费、无法接收或无变化时不伪造一次保存。

失败恢复confirmed显示并保留可恢复草稿，冲突保留draft且不重试覆盖；传输未确认时停止后续自动提交并沿§8.2核查，不假定写入失败。未完成加载、损坏/未来schema、编辑器保存中及结果未确认等既有禁改/禁提限制不放宽；外部连续意图只能按已确认revision依次提交。账户epoch、请求序号及销毁使旧回调与待执行意图失效，不回填新账户或恢复已销毁预览。外部快捷键自动保存属于用户显式操作，不是读取迁移自动落库。

偏好升级：schema6继续存appearance.snapshot.v2，仅新写十档枚举。schema2/3/4/5均直接使用原始density取最近十位、恰好居中向上，再夹紧60～150，等价clamp(floor(rawDensity/10+0.5)*10,60,150)；不得先映射到schema5三档。例：旧75→80、100→100、125→130、150→150、175→150；schema5的90→90、100→100、115→120。读取只内存升级，原行、updated_at及revision不变；字体/阅读按§4确定迁移，保留mode、两份variant、字号/行高/阅读关系、effects及缺失本机字体的原选择。仅值发生转换时以repairWarnings说明，显式完整快照CAS成功才写schema6并清除该次转换警告；取消不写原行。不新增存储源或修改已执行migration，语言、导航偏好和分栏比例也不随外观转换改写。

验收复用AC11～AC14及FR-005 AC04/21、FR-007 AC13：真实AI会话、Provider/MCP、外观、Agent工作台和宿主UI模块覆盖十档、默认及较大字、独立阅读/代码字号；正常/800×600及局部切换两侧连续伸缩，证明字体/行高/细线不变、几何有差异、操作可达及状态/比例保持。覆盖Slider/增减/恢复、活动编辑器草稿保存/取消、外部快捷键连续CAS、端点、失败/冲突/未确认核查、切账户/销毁及组件消费事件。必须取得真实macOS宿主Command+-、Command+=、Command+Shift+=键位与宿主读回证据，Chromium证据不得充作宿主证据；原生产模块与真实PTY身份/尺寸/输入缺口保留，只有真实链路能关闭。


## 5. 预览、应用与恢复

1. 打开外观页，从宿主已确认偏好创建编辑草稿，修改即时预览于当前窗口；不写宿主，也不广播给其他窗口。
2. 选择“浅色配置 / 深色配置”只改变编辑对象，不改变运行模式；选择“跟随系统”后，系统模式变化影响运行解析，不切走当前编辑对象。
3. 点击“应用外观”时校验整个浅色与深色配置，再一次性提交完整偏好。成功响应包含已确认值和新 revision，才成为持久偏好；失败恢复全局已确认值，保留草稿和字段错误供修改。
4. 非applying时，取消/Esc/关闭/切分类丢弃未应用草稿并恢复confirmed；applying等待结算，传输未确认按§8.2核查，不把关闭视图当取消宿主写。原型只内存保留，刷新重置。
5. 单项恢复删除该字段覆盖；恢复此区域删除当前明暗下当前区域全部覆盖；恢复当前明暗配置恢复默认套装并清除该模式覆盖，保留另一模式和排版；全部恢复默认将所有外观值恢复出厂默认，但仍需应用。

主规格原有“主题即时生效”仅描述 V1。V2 推荐将单纯切换模式也纳入本页草稿与应用边界，以免选主题、取消其他调整时含义不一致；需正式决策后替换 D071 的 V2 适用部分。语言是独立偏好，沿用其当前写入流程，不和主题事务混在一起。

### 5.1 状态机与失败语义

| 状态 | 触发 | 效果 | 离开条件 |
| --- | --- | --- | --- |
| `applied` | 页面打开、应用成功、取消恢复 | 窗口呈现宿主已确认偏好 | 任一编辑动作 |
| `drafting` | 改预设、颜色、字体、字号、行高、密度 | 只改草稿；窗口即时预览草稿 | 应用、取消/Esc/切分类/关闭设置 |
| `invalid` | 低对比度或非法字段 | 无效配对仅隔离样例，整窗保持最近合规预览，禁用应用并解释 | 修正回合规值 |
| `applying` | 点击应用 | 提交完整快照，禁编辑；关闭/Esc/切分类等待结算，账户结束由宿主优先处理 | 成功→applied；明确失败→failed；超时→unconfirmed |
| `failed` | 宿主明确拒绝 | 恢复confirmed，保留draft就地报错 | 修改后显式重试或取消 |
| `unconfirmed` | 传输超时/无响应 | 恢复confirmed显示并保留draft，只允许核查/退出预览，不再自动提交 | 重新读取按§8.2核查；不得把未确认保存说成失败未写入 |

- 预览只写当前窗口受控主题变量；不合规颜色只在编辑器的隔离样例内预览，整窗保持最近合规预览，始终保留可读的取消/恢复入口。不写库、不广播；崩溃或关闭后不残留。
- 并发写入用 `expectedRevision` 乐观锁；冲突不静默覆盖，提示后由用户重新应用。
- 任一异步响应回来先比对请求序号与 revision，过期即丢弃。

## 6. 控件与反馈

- 顶部三段模式控件与独立语言控件；浅/深配色各自成区，套装提供色板缩略图，选中态同时有文字与边界。

- 其他效果区直接展示布局缩放、减少动效、侧栏柔化候选。原型柔化只是半透明叠色，不宣称原生毛玻璃；宿主透明窗口需另行评估。

## 7. 可读性与受保护语义

用户输入颜色必须解析为规范化纯色，初期限定 `#RRGGBB`，不接受任意 CSS、URL、HTML、脚本或网络字体。背景纹理、壁纸取色和 JSON 主题导入导出不在本次原型；此前规划的壁纸取色仍留在 V2-FR-005 待补规格，不视为取消。

正文与主要表面至少4.5:1；操作强调/焦点和相关表面至少3:1；强调按钮前景至少4.5:1。主/次文字、面板、输入、选中态、hover、active、focus和Diff均需逐对校验。无效配对仅允许隔离样例预览，禁止覆盖整窗或应用；提供始终可达的取消/恢复路径。不得复制原型局部9px技术字号和低对比度控件边界。

成功、警告、失败、拒绝、结果未知及权限确认保留独立系统语义，不把品牌强调色复用为状态色。高级“对比度滑杆”不作为首轮入口：含义不稳定且难以保证每个状态可读；以明确的颜色覆盖、即时比值和生产语义配对校验替代。

### 8.3 受控主题变量写入（D126）

仅 `src/ui/theme/apply.ts` 可调用root.style.setProperty；输入为完整类型化外观与解析明暗，先经parseAppearance及kernel校验，不接受任意变量名称或CSS字符串。固定白名单覆盖表面/文字/强调/on-accent/状态派生角色、阅读/代码bg/fg、共享字体解析器输出的三字体栈、三字号、阅读/代码行高；效果与密度经封闭data属性表达。禁止写任意选择器、style标签、innerHTML、URL、模块局部样式和非主题变量。11px下限及视口上限由静态CSS保证。

命名只单向：种子 → 内核计算值 → 消费者语义角色 → Tailwind inline 入口；禁止 `--color-X → --X → --color-X`。颜色 Token 阶段1的职责、名称和模块兼容边界统一见 [FR-005 现行颜色约定](../../V1/01-底层能力/05-统一设计系统.md#颜色-token-阶段1消费者职责与命名)，本分篇不另设映射表。token字面色只在tokens，内核只接收解析种子；模块仍经host.ui和继承的公开token消费，不获得主题写入口。

`scripts/design-check/`及ESLint规则只对该精确文件的受控调用开放，其他文件的setProperty/style写入继续失败；不得删除design:check或增加目录级suppress。验收包含CSS注入、非有限数值、间接颜色环、构建后computedStyle及模块继承；这是工程静态约束，不宣称同realm隔离安全沙箱。
