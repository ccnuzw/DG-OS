# 外观主题与作用域设计

> 设计分篇，属于 [V2-FR-009 主规格](09-产品设计与UI改版.md)。主题快照、默认映射和受控出口按D126冻结；最终页面布局仍按迁移阶段安排。完整V2版本门禁不因阶段2实现自动通过，遵循D097、D100、D106。

## 1. 产品目标与入口

入口保持 `/settings/appearance`，在设置内按“主题与颜色 / 字体与排版 / 更多外观”组织。用户可以直接使用内置套装，也可以只修改其中几项；切换明暗、调整阅读字号或更换套装时，其他偏好保持可预测。

截图是能力参考；本设计用一套编辑器切换浅色与深色配置，避免将全部字段重复铺开。外观草稿即时预览于当前窗口，移除单独的缩略预览和整窗预览开关。设置壳的其他分类、语言入口和业务能力按主规格保留。

## 2. 分层模型

| 层 | 内容 | 生效边界 |
| --- | --- | --- |
| 模式 | 浅色、深色、跟随系统 | 决定当前解析哪份配色，不删除另一份 |
| 明暗配置 | 浅色套装、深色套装各自选择 | 允许浅色用暖纸、深色用石墨 |
| 套装 | 语义颜色、表面层次、边界和交互状态的完整配对 | 系统发布的内置资源，只读 |
| 用户颜色覆盖 | 当前明暗配置下，按操作界面、阅读、代码记录 | 字段缺省代表继承，不复制继承后的值 |
| 排版与体验 | 三类字体、三类字号、内容行高、密度、减少动效 | 独立于明暗配置与套装 |
| 运行时解析 | 派生表面、次要文字、on-accent、hover、focus | 由唯一主题内核生成，不允许页面自行调色 |

五套预设及三域控制均为本次整体切换必交付。D126冻结所有缺快照账户使用studio新安装默认；旧用户precision映射提案已取消，新系统不保留旧两键升级或兼容。

### 2.1 预设注册表

每个预设只声明三个种子色（强调色、背景、前景），浅色与深色各一组；其余语义色一律由内核派生。新增预设 = 增加一组种子并登记，不新增代码分支。

| 预设 ID | 名称 | 浅色种子（强调 / 背景 / 前景） | 深色种子（强调 / 背景 / 前景） |
| --- | --- | --- | --- |
| `precision` | 精密蓝 | `#1555d9` `#faf8f1` `#242831` | `#94b7ff` `#202321` `#eeeee7` |
| `studio` | 暖灰工作室（默认） | `#a46a24` `#f8f6ef` `#29323d` | `#ddb576` `#242521` `#eae9e2` |
| `paper` | 暖纸琥珀 | `#985b05` `#faf6ed` `#303129` | `#e9be76` `#26231e` `#f0e8da` |
| `forest` | 静谧松绿 | `#176748` `#f3f7f3` `#26382e` | `#89d8af` `#19251f` `#e0eee5` |
| `slate` | 石墨紫 | `#6942b5` `#f5f5fa` `#30313e` | `#c5abff` `#22212b` `#eeebf6` |

种子唯一声明于 `src/ui/tokens/presets.json`，运行时、构建脚本与宿主校验读取同一份种子；静态派生结果生成于 `presets.css`，不手工维护第二份色板。

状态色（成功、警告、失败、信息）不属于预设，只随明暗变化，避免品牌色替代系统语义。

套装仅替换配色基线，不重置字体、字号和密度；颜色覆盖默认保留，并显示“已选套装 + N 项自定义”。如需完全恢复套装，使用“恢复此区域”；不得隐式丢弃修改。

## 3. 作用域与继承

| 设置对象 | 涵盖 | 不影响 |
| --- | --- | --- |
| 操作界面 | 主框架、桌面、导航、标题、表单、按钮、设置和浮层 | 正文/代码已明确覆盖的颜色与字号 |
| 阅读与输入 | 会话正文、消息输入、任务输入和结果正文 | 工具栏、导航、代码块、系统诊断标签 |
| 代码与技术值 | 代码块、Diff、日志正文、路径与技术标识 | 自然语言正文、代码块标题栏和复制按钮 |
| 界面密度 | 控件高度、图标、间距、分栏最小空间 | 内容/代码的显式字号，窗口外框、画布视口缩放 |
| 内容行高 | 阅读正文与多行自然语言输入 | 导航、按钮、代码固定行高 |

解析规则：内置默认 → 当前模式选中的套装 → 操作界面覆盖 → 阅读或代码覆盖 → 语义派生。阅读和代码中没有覆盖的颜色随操作界面走；代码的覆盖优先于包裹它的阅读区域。字号、字体按角色选取，不用根字号替代所有内容字号。

例如：浅色选择暖纸，界面强调色改蓝，阅读背景改米白，代码字号改 16px。切换深色时只换配色；代码仍为 16px。把浅色套装改为松绿时，蓝色强调和阅读米白覆盖保留；单击强调色的“自定义 · 恢复”后，它才重新继承松绿。

### 3.1 派生规则

表面与装饰用固定比例；凡是承担文字或控件边界职责的颜色，一律按**对比度目标**求解。固定比例只在个别预设上碰巧达标，新增预设就会失效。

| 输出 | 方式 | 目标 |
| --- | --- | --- |
| panel / rail / inset | 固定比例混合 | 表面层级，无对比度要求 |
| border | 固定比例 | 装饰分隔，已登记豁免 |
| control | 与 panel、rail、inset 均达标的最小混合量 | ≥3:1（WCAG 1.4.11） |
| muted | 与三种表面均达标的最小混合量 | ≥4.5:1 |
| on-accent | 白色与前景色中对比度更高者 | ≥4.5:1 |
| primary-hover / active | 强调色向前景混合 8% / 16%（深色反向） | 与 on-accent 保持可读 |

求解按 0.01 步长递增，结果确定、可静态测试。任一预设无法满足目标时，该预设在构建期即失败，不进入候选列表；运行时不做降级。

这里的“作用域”首先是视觉区域。**不在本次默认引入每会话、每项目或每节点独立主题**，以免同一套宿主控件出现不同规则。未来模块消费宿主语义角色；画布网格和节点分类色由画布规格单独定义，不可覆盖审批、错误等系统语义。

## 4. 字体、字号与尺寸

| 项目 | 原型候选 | 说明 |
| --- | --- | --- |
| 界面字体 | 系统无衬线、人文无衬线 | 本机字体栈与中文回退，禁止运行时下载字体 |
| 内容字体 | 系统无衬线、人文无衬线、宋体/衬线 | 不改变代码排版 |
| 代码字体 | 系统等宽；系统无衬线比较项 | 正式可选列表需进一步验证对齐、中文与缺字 |
| 界面字号 | 12 / 13 / 14 / 16px | 推荐新安装角色基准12px，导航13px；14px是D064几何换算根基准，不代表每个角色必须14px；文字下限11px |
| 内容字号 | 13 / 14 / 16 / 18 / 20px | 默认13px |
| 代码字号 | 12 / 13 / 14 / 16 / 18px | 默认12px |
| 内容行高 | 1.5 / 1.75 / 2.0 | 默认1.75，代码独立固定行高1.5 |
| 界面密度 | 75 / 100 / 125 / 150 / 175（JSON整数） | 保留D064五档及100默认；原型1/1.12/1.25不写入生产快照 |

D126默认：mode=light、两模式studio、density=100、ui/reading字体system、code字体mono、字号12/13/12、sidebarTreatment=solid、reducedMotion=system。所有缺快照账户采用同一默认，不读取旧键；恢复当前明暗/全部外观使用该出厂映射。

界面字号可以使控件随文字自然增高，但不得连带放大阅读/代码内容。内容字号只改变阅读角色，代码字号独立生效。操作系统缩放、浏览器缩放、窗口大小与未来画布缩放保持各自语义。

字体选择器不能声称已安装未探测到的字体；正式实现若扩展为系统字体枚举，需宿主公开能力和平台验证。原型选择字体栈，缺失时回退，不保证实际使用某个具体字体。

## 5. 预览、应用与恢复

1. 打开外观页，从宿主已确认偏好创建编辑草稿，修改即时预览于当前窗口；不写宿主，也不广播给其他窗口。
2. 选择“浅色配置 / 深色配置”只改变编辑对象，不改变运行模式；选择“跟随系统”后，系统模式变化影响运行解析，不切走当前编辑对象。
3. 点击“应用外观”时校验整个浅色与深色配置，再一次性提交完整偏好。成功响应包含已确认值和新 revision，才成为持久偏好；失败恢复全局已确认值，保留草稿和字段错误供修改。
4. 非applying时，取消/Esc/关闭/切分类丢弃未应用草稿并恢复confirmed；applying等待结算，传输未确认按§8.2核查，不把关闭视图当取消宿主写。原型只内存保留，刷新重置。
5. 单项恢复删除该字段覆盖；恢复此区域删除当前明暗下当前区域全部覆盖；恢复当前明暗配置恢复默认套装并清除该模式覆盖，保留另一模式和排版；全部恢复默认将所有外观值恢复出厂默认，但仍需应用。

主规格原有“主题即时生效”仅描述 V1。V2 推荐将单纯切换模式也纳入本页草稿与应用边界，以免选主题、取消其他调整时含义不一致；需正式决策后替换 D071 的 V2 适用部分。语言是独立偏好，沿用其当前写入流程，不和主题事务混在一起。

### 5.1 状态机与失败语义

| 状态 | 触发 | 效果 | 离开条件 |
| --- | --- | --- | --- |
| `applied` | 页面打开、应用成功、取消恢复 | 窗口呈现宿主已确认偏好 | 任一编辑动作 |
| `drafting` | 改预设、颜色、字体、字号、行高、密度 | 只改草稿；窗口即时预览草稿 | 应用、取消/Esc/切分类/关闭设置 |
| `invalid` | 低对比度或非法字段 | 无效配对仅隔离样例，整窗保持最近合规预览，禁用应用并解释 | 修正回合规值 |
| `applying` | 点击应用 | 提交完整快照，禁编辑；关闭/Esc/切分类等待结算，账户结束由宿主优先处理 | 成功→applied；明确失败→failed；超时→unconfirmed |
| `failed` | 宿主明确拒绝 | 恢复confirmed，保留draft就地报错 | 修改后显式重试或取消 |
| `unconfirmed` | 传输超时/无响应 | 恢复confirmed显示并保留draft，只允许核查/退出预览，不再自动提交 | 重新读取按§8.2核查；不得把未确认保存说成失败未写入 |

- 预览只写当前窗口受控主题变量；不合规颜色只在编辑器的隔离样例内预览，整窗保持最近合规预览，始终保留可读的取消/恢复入口。不写库、不广播；崩溃或关闭后不残留。
- 并发写入用 `expectedRevision` 乐观锁；冲突不静默覆盖，提示后由用户重新应用。
- 任一异步响应回来先比对请求序号与 revision，过期即丢弃。

## 6. 控件与反馈

- 顶部三段模式控件；套装区提供浅/深编辑切换与色板缩略图，选中态同时有文字与边界。
- 颜色细节先选区域；颜色值提供取色器和 `#RRGGBB` 输入；旁边明确“继承”或“自定义 · 恢复”。阅读和代码不提供独立交互强调色。
- 字体与字号按界面/内容/代码配对排列；行高与密度独立。每组说明影响对象，不出现只能由开发者理解的 token 名称。
- 当前窗口直接呈现主题效果；提供当前区域文字对比度和全配置校验结果，不显示重复的模拟预览。
- 高级区提供减少动效、侧栏柔化候选。原型柔化只是半透明叠色，不宣称原生毛玻璃；宿主透明窗口需另行评估。
- 底部固定局部操作区显示取消预览、应用和恢复；它只属于外观编辑器，不使所有设置分类变成同一种提交模型。

### 6.1 页面结构

外观页是设置浮层内的一个分类，采用“分类—内容”两栏：左侧是设置分类，右侧外观页自上而下三个分区，底部固定操作栏。

| 分区 | 内容 | 交互 |
| --- | --- | --- |
| 模式与预设 | 顶部三段控件（浅色 / 深色 / 跟随系统）决定运行模式；其下“浅色配置 / 深色配置”决定正在编辑哪一份；预设卡片网格展示五套色板 | 切模式不改编辑对象；切预设只换基线，保留该模式的用户覆盖并显示“已选套装 + N 项自定义” |
| 区域 | 操作界面 / 阅读与输入 / 代码与技术值 三个页签；每页列出该区域可改的颜色项 | 每项显示“继承”或“自定义 · 恢复”，旁列实时对比度比值；阅读与代码不提供独立强调色 |
| 排版 | 界面 / 内容 / 代码 三类字体与字号、内容行高、密度 | 每项标注影响对象（控件增高、阅读正文、代码块），不出现 token 名称 |

预设卡片只显示色板缩略、名称与一句描述，不显示色值；卡片选中态同时用文字与边界表达，不只靠颜色。底部操作栏只属于外观编辑器，不使其他设置分类变成同一种提交模型。

## 7. 可读性与受保护语义

用户输入颜色必须解析为规范化纯色，初期限定 `#RRGGBB`，不接受任意 CSS、URL、HTML、脚本或网络字体。背景纹理、壁纸取色和 JSON 主题导入导出不在本次原型；此前规划的壁纸取色仍留在 V2-FR-005 待补规格，不视为取消。

正文与主要表面至少4.5:1；操作强调/焦点和相关表面至少3:1；强调按钮前景至少4.5:1。主/次文字、面板、输入、选中态、hover、active、focus和Diff均需逐对校验。无效配对仅允许隔离样例预览，禁止覆盖整窗或应用；提供始终可达的取消/恢复路径。不得复制原型局部9px技术字号和低对比度控件边界。

成功、警告、失败、拒绝、结果未知及权限确认保留独立系统语义，不把品牌强调色复用为状态色。高级“对比度滑杆”不作为首轮入口：含义不稳定且难以保证每个状态可读；以明确的颜色覆盖、即时比值和生产语义配对校验替代。

## 8. 偏好归属与工程接入提案

阶段2适用说明：以下阶段1推荐中的待准入与旧用户映射已由 [D126](../../../06-决策记录/V2-冻结决策.md#d126-v2主题快照事务默认映射与受控变量出口) 取代。全量快照/CAS、草稿提交与精确主题写口已冻结；用户明确新系统不要求旧两键升级或兼容，缺快照统一采用新安装默认。旧推荐仅保留其余未被取代的边界。

沿用 D065 的宿主派生用户归属：当前账户在本机的偏好，由宿主识别用户，前端不传用户 ID；账户切换后重新加载对应偏好，无账户模式按现行宿主规则处理。不写入工作流/会话文档，不通过局域网把主机外观强加给远程设备。未来远程外观是该设备本地偏好，与主机配置权限分离。原型只演示一份内存外观，不证明账户间偏好隔离。

完整快照形状（D126，IPC包装见接口契约§11.3）：

```text
schemaVersion: 2
revision: 宿主递增版本
mode: light | dark | auto
variants:
  light / dark:
    presetId: 内置稳定 ID
    overrides:
      interface: { accent?, background?, foreground? }
      reading:   { background?, foreground? }
      code:      { background?, foreground? }
typography: { uiFontId, readingFontId, codeFontId,
              uiSize, readingSize, codeSize, lineHeight }
density: 75 | 100 | 125 | 150 | 175
effects: { sidebarTreatment, reducedMotion }
```

`src/ui/appearance/` 管理confirmed/draft/preview与请求生命周期；`src/ui/theme/kernel.ts` 为唯一解析内核；`AppearanceSettings.tsx`消费控制器。§8.2/§8.3按D126冻结，前端不得传用户ID、配置键或SQL。

### 8.1 主题内核与产物

派生只实现一次，被三处消费，避免出现第二份手写调色板：

| 消费方 | 用途 |
| --- | --- |
| `src/ui/theme/kernel.ts` | 唯一实现：种子 → 语义 token 的纯函数（含 3.1 的对比度目标求解） |
| `scripts/tokens-build.mjs` | 生成 `tokens/presets.css` 的五套明暗静态块，作为首帧与无脚本兜底 |
| 运行时 store | 切换预设、应用用户覆盖与作用域，写入受控 CSS 变量 |
| `tests/design-tokens.test.tsx` | 遍历每个预设 × 明暗，复用语义对比度配对断言 |

种子唯一声明于 `src/ui/tokens/presets.json`；内核读取种子，`npm run tokens:build` 生成静态 CSS，`npm run tokens:check` 拒绝过期产物。新增预设需要种子与稳定 ID 登记，任一语义配对不达标应阻止构建。

必须覆盖的工程分支：

| 风险 | 推荐处理 | 准入前交付 |
| --- | --- | --- |
| 同设备多窗口并发修改 | `expectedRevision` 乐观锁；冲突不静默覆盖，读取新值后由用户重新应用 | FR-005 技术设计、宿主测试和稳定分支编号 |
| 单次保存写入一半 | 完整偏好单事务提交，响应完整快照；不逐字段多次落库 | 原子性与故障注入测试 |
| 延迟响应覆盖新编辑 | 请求序号与 revision；丢弃过期响应；预览与保存分离 | 控制器乱序测试 |
| 升级后偏好损坏 | 逐字段验证、安全默认；未知套装回退，保留兼容用户覆盖 | 损坏输入、未知版本测试 |
| 五档密度 | 新快照保留全部五档枚举，不提供旧两键迁移 | 五档几何与三域独立字号的渲染验证 |
| 崩溃/关闭残留预览 | 预览仅内存，不写库；重启只加载最近确认值 | 桌面关闭/重启与失败测试 |
| 样式规则冲突 | D126仅允许apply.ts受控写变量，其他消费者维持禁写 | 设计门禁与非法写入反向验证 |

实现证据与尚缺验证见唯一实现状态；本分篇不以设计资产代替宿主证据。

### 8.2 全量快照、保存和恢复（D126）

全量快照取代旧patch签名，所有消费者同步迁移，不保留旧两键兼容路径。

| 边界 | 具体契约 | 必须证明 |
| --- | --- | --- |
| 读取 | 推荐升级现有 `get_appearance_preferences` 返回schemaVersion=2完整快照；revision为宿主递增非负安全整数，renderer不生成；用户由会话派生 | 无账户/当前账户/切账户读取互不串值 |
| 保存 | 推荐 `set_appearance_preferences({snapshot, expectedRevision})` 替换patch签名，snapshot含§8全部可编辑字段而不含客户端revision；拒绝未知键/不完整对象，事务内CAS比较并递增一次，响应完整确认快照 | 两并发写只有一个提交；失败不部分写；所有调用者与smoke同步切换，不保留旧patch写兼容层 |
| 类型校验 | mode封闭light/dark/auto；presetId五个稳定ID；颜色只允许规范化HEX；字体ID ui=system/humanist、reading加serif、code=mono/system；字号/行高按§4枚举；density整数五档；sidebarTreatment=solid/soft、reducedMotion=system/reduce | 不接受CSS/url/网络字体/NaN/越界值；新写无效则整单拒绝；状态色不接受用户覆盖 |
| 单一权威 | system_settings每用户一个固定 `appearance.snapshot.v2` JSON键包含revision，不开放通用键接口；初始化与保存沿用事务及唯一(user_id,setting_key)约束，CAS使用数据库条件更新 | 冷启动初始化幂等；并发写不丢失；不改已执行migration |
| 缺少新键 | 按D126初始化新安装完整快照，初始revision=0；不读取旧两键，不提供升级映射 | 所有账户默认一致，首次事务失败可重试 |
| 损坏和未来数据 | schema2可解析且revision有效时逐字段回退，剔除无效覆盖并校验配对；未知preset回到升级基线保留合规覆盖。无法解析或revision损坏则显示安全出厂渲染并保留原始行，禁止常规保存；显式“恢复损坏偏好”经类型化宿主恢复操作，以宿主签发的不透明recoveryToken校验原始行未改变后事务重建revision=0；不是客户端提供配置键/哈希。schema>2拒绝写与恢复，提示升级 | 损坏读取不冒充确认保存；并发变化使恢复token失效，重新读取；未来数据不被旧程序破坏 |
| 回退 | 新系统不提供旧两字段偏好兼容或无损降级；不得修改已执行migration | 单一新快照读写，不保留双写或兼容别名 |
| 冲突 | revision不符不写，返回稳定的冲突类别及当前完整快照；更新confirmed并恢复其渲染，保留用户draft并显式选择重新应用，不自动重试覆盖 | 第二编辑者不能静默覆盖第一编辑者 |
| 超时/晚响应 | 保存期间禁编辑和离开；收到明确失败恢复confirmed保留draft；传输超时属于提交结果未确认，先重新读取比较revision与规范化内容，匹配才确认成功；不同则显示冲突，读取也失败则阻止再次提交直到核查完成 | 不因超时盲重试增revision；账户epoch/request序号过期响应不写新账户；离开只在保存已结算后执行 |

新冲突/未来schema等结果需在正式IPC和错误码权威文档登记后实现；本分篇不擅用未分配数字，也不把1005003～1005005静态检查码改为运行时码。当前D065错误码仍生效。保存不引入Provider等外部副作用，无自动重试；语言仍独立提交。

读取在CommandResponse.data内使用判别联合：`{kind:'ready',snapshot,repairWarnings:[]}` / `{kind:'corrupt',safeDefaults,recoveryToken}` / `{kind:'unsupported_schema',safeDefaults,schemaVersion}`。ready的schema2字段修复仅在内存规范化，不自动覆盖原行，保留有效revision供下次显式CAS；corrupt不伪造confirmed revision。`recover_appearance_preferences({recoveryToken})`只能恢复本用户固定外观对象，返回新完整快照；token绑定宿主会话/原行、一次性使用，账户结束失效。消费者必须处理每种kind，不能把safeDefaults报告为已保存。

### 8.3 受控主题变量写入（D126）

仅 `src/ui/theme/apply.ts` 可调用root.style.setProperty；输入为完整类型化外观与解析明暗，先经parseAppearance及kernel校验，不接受任意变量名称或CSS字符串。固定白名单覆盖表面/文字/强调/on-accent/状态派生角色、阅读/代码bg/fg、三字体栈ID映射、三字号、阅读/代码行高；效果与密度经封闭data属性表达。禁止写任意选择器、style标签、innerHTML、URL、模块局部样式和非主题变量。11px下限及视口上限由静态CSS保证。

命名只单向：种子 → resolved角色 →兼容现有消费者的Tailwind映射；禁止 `--color-X → --X → --color-X`。已有surface别名先列消费者后统一迁移，禁止既保留两套独立色板又增加第三套。token字面色只在tokens，内核只接收解析种子。模块仍经host.ui消费，不获得主题写入口。

`scripts/design-check/`及ESLint规则只对该精确文件的受控调用开放，其他文件的setProperty/style写入继续失败；不得删除design:check或增加目录级suppress。验收包含CSS注入、非有限数值、间接颜色环、构建后computedStyle及模块继承；这是工程静态约束，不宣称同realm隔离安全沙箱。
