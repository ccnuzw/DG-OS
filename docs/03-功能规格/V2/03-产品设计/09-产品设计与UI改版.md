## 目标

本地优先 AI 桌面用户打开 DGOS 后，能开始工作、找到可用技能与应用、配置所需能力，并在统一的工作区中打开、切换和最大化多个会话与应用，理解操作结果和恢复路径。

交付单位是完整改版：一个产品结构、一套视觉与交互规范、全部现有页面迁移、一次整体验收。工程可按依赖连续实现并逐项验证；面向用户的改版验收以全覆盖为准。

## 功能边界

包含：

- 全功能归属、主导航、页面与工作区布局、关键任务流程及统一文案。
- 工作台、技能、Provider、MCP、模块、设置、账户、局域网、登录和启动失败等现有界面。
- 亮暗五套主题、界面/阅读/代码颜色与排版覆盖、中英文、键盘与辅助技术、窄窗布局；保留现有五档密度，完整快照升级按外观分篇，不改成三档。
- V1 页面迁移、旧入口兼容、上下文返回、错误与空状态。
- 工作区层：外层工作区标签、AI 会话内多会话标签、应用启动台、应用宿主、最大化/专注、单实例多视图、标签切换与关闭语义。
- 应用启动台从已安装模块动态生成，以 OS 式图标网格呈现；只显示图标、名称与运行状态，不显示说明/版本/操作卡片；应用使用与设置在导航和生命周期上分离。
- 画布等 full-bleed 应用的全幅接入位置与宿主边界；画布应用入口的本地创作平台首页、项目切换和全屏编辑器返回关系（D125，原型设计）。
- 桌面首页对固定/最近应用、最近会话和运行中状态的展示入口。

不包含：

- 画布引擎、运行服务、资产服务和扩展注册表的实现（分别属于对应 V2 功能）。
- 云端账户、云市场等独立业务的实现不由UI重排自动授权；原型目标和缺失依赖逐项见整体方案§10，范围冲突待裁定，不能据此删掉布局与交互目标。
- 领域增量不由页面重排虚构：当前内容技能已有外部包用户引用卸载；更新仍不支持。保留真实卸载，不把旧原型缺按钮误写为生产缺能力。
- 自动修改宿主权限、任务后台运行或外部调用重试语义。若设计必须改变这些行为，先记录决策并补技术设计。
- V2 的独立 OS 应用窗口、分屏和一个应用多实例；这些需要窗口身份、模块宿主与状态同步的独立决策和技术设计（D120）。
- 应用安装/市场能力（沿用 V1 模块系统），以及为每个应用增加“应用标签 + 文档标签”双层结构；只有 AI 会话保留内层会话标签。
- 标签/工作区跨重启持久化的数据契约；首版只定义界面状态，持久化另立设计。

## 需求说明

### 用户故事

作为主要在桌面上使用模型、技能和工具的用户，我希望在工作区完成任务，需要配置时能直达相应设置并返回原位置，以便集中处理内容而无需理解后端模块结构。

### 业务规则

1. 每项能力有一个清晰的主归属；上下文快捷入口指向同一份界面和状态。使用入口与配置入口可以分别存在，重复的管理页退出主导航。
2. 主导航按工作目的组织；资源列表、会话记录、工具选择属于当前区域的局部导航或上下文区域。
3. 对外操作必须由用户明确发起；进入页面、选中资源、恢复界面不触发付费请求、安装或 MCP 执行。
4. 模型、技能和工具的选择必须使用当前模式实际支持的能力。现有单任务支持的流程不能直接宣称聊天也支持；设计时分别核对两个模式。
5. 所有产品数据来自当前账户和现有领域接口；无数据时给真实空状态，不用原型示例冒充真实内容。
6. 权限拒绝、任务取消、结果未知和失败分别表达；结果未知时不得把“重试”作为无条件主操作。
7. 新入口的调用者身份、窗口和路由仍由宿主核验。模块使用与管理入口的分离必须先验证宿主准入，不靠前端隐藏或改名获得权限。
8. 登录与无账户模式沿用 V1：没有本地账户时不强迫创建账户；账户切换的会话结束、取消和隔离语义由宿主保持。
9. 工作区分两层：外层工作区标签切换 AI 会话、应用实例/画布文档、单任务、技能中心和 MCP 管理；AI 会话内层标签切换多个会话。桌面总览、应用启动台和设置是特殊面，不进入标签；账户/登录/错误/远程访问属于系统状态，也不进入标签。不设永久左侧会话列表（D120、D124）。
10. 应用启动台是应用使用的唯一发现入口，以 OS 式图标网格呈现在主工作区内的悬浮面板中，不占满右侧工作区：只显示图标、名称和运行状态点，不显示说明、版本、状态文字或打开/管理卡片；左侧导航保持可见，把可用应用图标拖到左侧即可固定，最多 3 个；未启用/无授权应用不可固定且降低饱和度。点击面板外空白或按 Esc 关闭，不显示右上角关闭按钮。应用管理仍在设置 → 应用与扩展（D121、D122）。
11. 一个应用/模块全局只允许一个实例；一个实例可承载多个视图或文档标签。再次打开同一应用时聚焦已有视图，不创建第二个实例。
12. 切换工作区或会话标签保留草稿、滚动和上下文；关闭应用标签只关闭视图，不停止宿主后台运行；关闭运行中的会话先确认停止；账户切换、权限撤销或应用停用清理相关状态。
13. 最大化是工作区专注模式，隐藏左导航、检查器和历史，保留细标签条与切换入口；V2 不引入独立 OS 应用窗口、分屏或多实例，后续再单独决策（D120）。
14. 单任务按D124作为单例工作区任务标签；AI会话不再保留第三层Workbench模式条。CLI Agent复用现有执行能力作为独立任务工作面，入口与关闭协议见技术设计；应用使用工作区宿主，full-bleed占满主区，document保留可读宽度。
15. 技能中心保留官方/旧版、浏览/我的、分类搜索、详情、添加、启停、受控URL/ZIP预览及外部内容卸载；旧版只读，更新不可假装可用。MCP资源页位于其下，设置只跳转。D123设计时的“未实现卸载”不覆盖当前代码已支持的外部包卸载。
16. 技能中心、MCP 管理和单任务以工作区标签打开：重复点击左侧入口只聚焦已有标签，不重复创建；关闭标签后可从左侧重新打开。桌面、启动台和设置是特殊面；账户/系统状态不进入标签。标签状态在切换到桌面或设置时保留（D124）。

### 页面与交互

**主框架**：左侧可折叠主导航 + 外层工作区标签 + 主工作区 + 可选检查器。桌面独立首页，启动台和设置为浮层；外层承载AI会话组、应用视图、单任务、技能中心、MCP，AI唯一拥有内层会话标签。去掉重复页面标题栏，几何统一引用下方尺寸基线；document/full-bleed与专注语义见技术设计。

**应用启动台**：主工作区内的居中悬浮面板，周围工作区可见，左侧导航保持可见；不是独立 OS 窗口、普通页面、整页图层或卡片列表。入口为左侧“应用”、桌面“打开应用”和 Cmd/Ctrl+K；标题、搜索和简短拖拽提示保留，不显示右上角关闭按钮。图标只显示名称与运行状态点，不显示说明、版本、元信息或打开/管理按钮。运行中的应用在图标下方显示状态点；未启用/待授权图标降低饱和度且不可固定。把可用图标拖到左侧导航出现落点高亮和“拖到这里固定”，放下后进入“应用”分组，最多 3 个；不设“固定应用”分区。点击可用应用打开/聚焦标签，未启用/无权限给出简短状态提示；管理仍在设置，不硬编码示例应用。点击面板外空白或按 Esc 关闭并恢复焦点（D121、D122）。

**应用宿主**：manifest/contribution 声明 `document` 或 `full-bleed`；宿主提供最小外框、应用标题、运行状态、最大化和管理入口；`full-bleed` 应用（画布）占满工作区，`document` 应用保留可读内容宽度。一个应用一个实例，可承载多个视图/文档标签；再次打开聚焦已有视图，不创建第二实例。

**画布创作平台（原型）**：点击画布应用先进入本地创作平台首页，不直接打开空白画布。首页有全部项目、最近使用、回收站、项目卡片和新建项目；项目是账户内的数据边界。打开项目后进入全屏无限画布，隐藏主导航和平台首页，只保留左上角“← 全部项目”返回；外层保留“无限画布”工作区标签。云端、共享和协作不在本次原型范围（D125）。

**最大化与专注**：由应用标签/宿主提供“最大化/还原”；隐藏左导航、检查器和历史，保留细标签条与应用切换入口；`Esc`/显式还原恢复之前的布局；OS 全屏另设。V2 不引入独立 OS 应用窗口、分屏或多实例。

**空间**：按下方最终渲染基线实施。D120的860–920px是明确标注非接口的早期空间方向，已与用户指定的当前原型冲突；本轮推荐采用最终720px阅读/输入列，不再同时保留两个施工数值。此细化不改变D120单实例/单窗口/标签方向，具体尺寸仍为待评审设计基线。

**AI 会话（AI 智能体 Workbench）**：桌面独立，外层一个AI工作面，内层多会话标签支持新建/切换/关闭/溢出/历史，不设永久左侧会话列表。切换保留草稿、滚动与生成；运行关闭先确认停止，外层关闭保留集合。单任务使用D124独立任务标签。输入贴底、阅读区独立滚动；所有选择器贴近输入，保留真实IME/发送/停止与审批语义。

**技能中心**：单例工作区标签，浏览/我的、来源/分类/搜索、网格和sticky详情。展示真实作者/许可/版本/哈希与旧版不可执行；官方添加、内容启停、受控URL/ZIP预览确认/取消、外部包卸载均保留。卸载只移除当前用户引用，不删其他账户包；更新仍无真实支持，不画空操作。添加后只导航单任务，不自动执行或伪造上下文预选。

**MCP 管理**：技能中心下方的单例资源标签，含列表/状态、stdio/HTTP新增编辑、连接/断开、启停/删除、工具/参数/超时/确认/取消/结果、凭据、最近使用与连接历史。设置只保留摘要/跳转。仅设计原型使用演示数据（D123）；生产必须接现有mcpStore及真实命令，保留未知结果，不能把“演示”写成产品限制。

**设置浮层**：按 D119 固定主窗口内悬浮，左分类、右内容，资源管理采用分类—列表—详情。应用使用在工作区，应用管理在设置；从设置“打开应用”打开/聚焦工作区标签并关闭浮层，不从应用宿主内重复管理页。打开不卸载工作页，关闭恢复焦点；未保存编辑先保存或放弃。不创建独立 OS/WebView/浏览器窗口。路由准入、账户变化和任务保持仍须技术验证。

**表单**：结构化配置使用明确的保存/取消、提交中与失败反馈；V1 已定义的主题/密度即时生效保持为现行行为，V2 外观编辑对当前窗口即时预览草稿并明确应用，详见[外观设计分篇](外观主题与作用域设计.md)。固定操作栏用于有提交步骤的表单。凭据不进入普通草稿持久化。

**视觉**：暖中性层次与轻量边界按当前原型；交互强调来自当前套装，不固定蓝色。分类图标与系统状态各有语义；本地字体回退、图标和新增控件沿用D096。五套明暗、三域及五档密度本次一起交付。

**外观主题**：五套、明暗独立、区域覆盖、三域字体字号、行高/密度、继承、恢复与可逆预览均属整体切换范围。默认推荐、完整快照/CAS/旧数据升级和D068受控写入口只在[外观分篇](外观主题与作用域设计.md)维护；内核归FR-005，不构成延期理由。

**原型交付清单**：主框架展开/收起；AI 会话内多会话标签；应用启动台；外层工作区标签；应用全幅宿主与最大化；对话空白/历史/流式/失败；单任务配置/审批/运行/结果；技能浏览/我的技能/来源筛选/详情/导入预览/启停；MCP 服务/工具/调用确认/记录；设置每个分类；模块使用与授权；账户/登录；局域网主机与远程访问；启动错误与通用反馈。每项采用真实业务文案和明确的样例数据标识，输出可点击原型及状态注释。当前可点击原型已覆盖 AI 会话内多标签、应用页面与设置，并已补外层工作区标签、启动台、最大化/专注和全幅应用宿主（2026-11-03，设计资产）；AC15～AC20 的产品测试资产仍未创建。设计资产见 [原型入口](../../../../prototypes/product-design/index.html) 与 [评审路线、覆盖和限制](../../../../prototypes/product-design/README.md)。这是模拟设计资产，不代表产品实现或验收通过。

用户明确选择主窗口悬浮，原型已移除独立窗口。D120 进一步把 D119 第 2 项的“会话左列表”改为 AI 会话内多标签，并新增工作区标签、应用启动台、单实例多视图、最大化和 V2 单主窗口边界；桌面/AI 分离和设置浮层不变。参考 11a/11b 的 `code.html`：11–12px 辅助字、28–32px 控件和浅标题栏；不据参考增加本地引擎、知识库和硬件指标。决定见 [D119](../../../06-决策记录/V2-冻结决策.md#d119-桌面与-ai-会话分离左右布局设置固定主窗口浮层) 与 [D120](../../../06-决策记录/V2-冻结决策.md#d120-工作区标签应用启动台ai-会话多标签与单窗口边界)。

### 尺寸与缩放作用范围（评估，非冻结接口）

**现行代码**：`src/ui/tokens/density.css` 将根字号设为10.5/14/17.5/21/24.5px，对应75/100/125/150/175%；`scale.css` 字号、间距、圆角使用 rem，字号 token 保底11px，按钮高度通过间距 token 跟随。`appearance/index.ts` 对当前文档根节点设置属性。同文档、使用这些 token 的界面和模块一起变化；固定 px、vw/vh、OS窗口和独立文档不自动同比变化。它是界面 token 缩放，不是浏览器整页 zoom。远程 SPA 独立启动，不能假设继承主机偏好。

| 控制 | 推荐作用范围 | 排除范围 | 偏好作用域建议 |
| --- | --- | --- | --- |
| 界面尺寸 | 导航、菜单、设置、表单、按钮、图标、列表及间距，按窗口重排 | 消息/代码正文、图片原始像素、画布坐标、OS窗口 | 当前本地账户的桌面UI，设置浮层同步；远程设备独立 |
| 内容字号 | 消息、自然语言输入与任务结果正文；按字号重新排版 | 代码、技术值、导航、工具栏、设置控件、浮层外框 | 当前本地账户阅读偏好，跨会话共享，不随会话导出 |
| 代码字号 | 代码块、日志正文、路径与技术值 | 消息正文、代码标题栏和操作按钮 | 当前本地账户技术内容偏好，与内容字号独立 |
| 画布缩放 | 未来画布视口的节点、连线及内容几何 | 全局导航、设置和画布工具栏 | 每张画布视口，由 V2-FR-006 定义 |
| 浏览器/系统缩放 | 用户在平台层选择的整体呈现 | 不由应用冒充前三项 | 尊重平台辅助缩放，不拦截浏览器缩放快捷键 |

**原型候选**：完整字号、字体和密度选项以[外观设计分篇](外观主题与作用域设计.md#4-字体字号与尺寸)为准。说明字不低于11px，细边线保持1px，阴影不同比加重，浮层最大尺寸仍受视口约束。侧栏宽度在大窗口跟随界面尺寸，窄窗口自适应，故不承诺所有像素同比缩放。

**迁移边界**：用户要求评估不等于批准替换 D064/D071。生产落地前须冻结旧五档兼容映射、字段/存储、默认值、模块内容区 opt-in、账户清理、远程设备偏好及大字号与平台缩放叠加的验收；此前保留 V1 五档值，不能静默重解释旧数据。原型测试只证明两类控制在原型中相互独立。

### 阶段1最终渲染基线与响应式推荐

此处是布局数值的唯一设计维护点；主题/字体只在外观分篇维护。基准是1440×900、100%几何密度，不将原型12px根rem原样复制到生产14px根。大字号使控件自然增高，边框1px不按密度放大。

| 对象 | 最终原型/推荐生产100%基线 | 密度、窄窗与验收 |
| --- | --- | --- |
| 左栏 | 展开188px，图标栏54px | 几何按Nrem/14；图标栏高密度不挤占主操作，必要时以可用内容宽度限制；用户折叠偏好与自动收起分离 |
| 外层/内层标签 | 外层33px；会话内层实际38px（不是旧32px最小值） | 75%保底26px且容纳至少11px文字；大字号自然增高；滚动/溢出菜单、完整标题、方向键/Home/End及关闭焦点 |
| 阅读/输入 | 均最大720px，宽窗居中 | 窄窗收缩为可用宽度；代码/表格内部横向滚动，不能撑宽文档；无重复页标题/永久左会话列表 |

### 主流程

| 旅程 | 步骤 | 结果与返回 |
| --- | --- | --- |
| 首次使用 | 账户门禁 → 桌面总览 → 配置模型或进入AI会话 → 明确测试/保存 → 选择模型 → 用户发送 | 默认先见桌面；会话显示真实响应或失败 |
| 技能使用 | 浏览 → 详情 → 添加到我的技能 → 前往单任务 → 选择技能与模型 → 输入 → 执行 | 显示实际任务结果与版本信息；不自动提交内容 |
| 工具使用 | 设置 MCP → 显式连接 → 查看工具 → 单任务选择 → 运行 → 用户确认具体调用 | 成功、拒绝、失败、未知结果均有明确表示 |
| 应用使用 | 应用启动台（导航/桌面/Cmd+K）→ 搜索/固定/最近 → 打开或聚焦已有视图 → 处理权限/崩溃 → 切换或最大化 | 不可用或缺权限时给到设置管理入口；同一应用只一个实例；使用在工作区、管理在设置 |
| AI 多会话 | AI 会话内 `+` 新建/切换会话 → 关闭/溢出/历史下拉 → 外层切到应用再返回 | 草稿与滚动保留；运行中关闭先确认；不恢复左侧列表；外层返回保留会话标签 |
| 工作区切换 | 外层标签切换 AI 会话/画布/应用 → 各表面保留状态 → 关闭应用标签或 AI 外层标签 | 应用标签关闭不停止后台运行；AI 外层关闭保留会话集合；账户变化清理相关状态 |
| 最大化/专注 | 应用标签/宿主最大化 → 隐藏导航、检查器和历史 → Esc 或显式还原 | 应用全幅、细标签条与切换入口保留；恢复之前的布局 |
| 工作中配置 | 从工作台直达具体设置 → 修改并提交/取消 → 返回 | 原工作位置可识别；草稿、选择与运行状态分别按生命周期规则处理；设置浮层不卸载工作区 |
| 局域网访问 | 主机开启 → 复制配对地址 → 远程配对 → 远程聊天 → 主机撤销 | 远程失效提示与重新配对入口；主机凭据不出现在普通反馈中 |
| 账户管理 | 打开账户入口 → 明确操作影响 → 认证/确认 → 宿主完成切换或删除 | 新账户无旧账户草稿与审批；失败不伪装为成功 |

### 异常与边界

- 没有模型、没有技能、没有应用、没有匹配结果分别给出可执行的空状态。
- 加载失败保留可识别的当前区域并提供重试；不要把加载失败显示成“没有内容”。
- 表单未保存离开需明确保留、放弃或阻止；跨标签/跨账户的保留范围在技术设计中固定；V2 不提供独立 OS 窗口。
- 长模型名、长路径、中英切换、大字号/高密度、800px 窗口均不得遮挡主要操作；标签溢出、长应用名和长会话名必须有可访问的完整名称；详细内容提供展开方式。
- 同一应用重复打开只聚焦已有视图；应用停用、权限撤销、崩溃或账户切换时清理过期标签/视图，不能继续呈现可执行的旧操作。
- 关闭运行中的会话先确认停止；关闭应用标签不停止宿主后台运行；应用启动失败/崩溃在标签内提供恢复和管理入口。
- 工作区标签、AI 会话内层标签和启动台的边界要可区分：外层不显示会话级关闭，内层不承担应用切换；模式与空状态不能互相伪装。
- V2 不实现独立 OS 应用窗口、分屏或多实例；用户请求这些能力时按后续版本处理，不在当前界面承诺窗口创建。
- 最大化/专注模式退出后恢复之前的侧栏、检查器和标签布局；专注模式中仍必须能调出应用切换器和启动台。

### 错误矩阵

| 来源 | 界面处理 | 约束 |
| --- | --- | --- |
| 字段校验失败 | 字段旁提示并关联可访问说明 | 保留可安全保留的输入 |
| Provider/MCP 连接失败 | 当前配置或任务内显示原因与处理入口 | 使用现行错误映射，不输出凭据或原始敏感异常 |

| 标签与宿主实例不一致 | 以宿主状态为准，刷新或关闭视图 | 前端不自行重建实例或另开第二实例 |
| 操作结果未知 | 明确结果未知与核查方式 | 不显示成功，不自动重试外部副作用 |
| 启动数据库失败 | 专用错误页 | 沿用既有失败语义，不承诺修复能力 |

错误码仍以 [V1 错误码](../../../04-技术架构/当前版本/V1-错误码.md) 为准；此处仅规定呈现职责。

## 数据与事务

### 读写数据

通过现有 store/hook 与公开宿主命令读取和修改所属领域数据。前端不访问数据库；本草案不新增 migration。工作区标签、AI 会话内层标签、启动台固定/最近和最大化布局是内存态界面状态；首版不承诺跨重启持久化，若需要应先明确作用域、清理与迁移设计。应用实例、视图归属和后台运行由宿主登记，前端不根据标签自行推断。

### 约束与事务

不适用：此规格不定义新的业务事务。组合页面不得把多次成功/失败混成一次“全部成功”；配置提交、授权、安装分别沿用领域原子性与恢复语义。一个应用/模块全局只允许一个实例；多个标签只能形成同一实例的视图/文档，不能形成第二实例。V2 不创建独立 OS 应用窗口或跨窗口状态。

### 状态与生命周期

现行 `Workbench.tsx` 按路由页面挂载，切换模式会卸载当前面板；`SingleTaskWorkbench.tsx` 的卸载清理会请求取消。D120 将工作区改为常驻工作表面，外层/内层标签切换不卸载已打开的工作表面，但关闭标签与离开工作区的语义必须显式定义，不能依赖路由副作用。

- 一个应用/模块全局一个实例；一个实例可以承载多个视图/文档标签。再次打开同一应用只聚焦已有视图，不创建第二实例。
- AI 会话内层标签保留每个会话的草稿、滚动和当前上下文；切换标签不取消正在生成的会话。关闭运行中的会话先确认停止。
- 关闭应用标签只关闭视图，不停止宿主后台运行；后台运行状态在标签和运行中心可见，显式停止才结束（D082）。
- 关闭 AI 会话外层标签保留会话标签集合与历史；运行中的会话先确认停止。账户切换、注销、权限撤销或应用停用清理相关标签/草稿/审批状态。
- 主窗口设置浮层不卸载主工作区；账户切换和注销仍按宿主会话结束流程取消。
- 标签/启动台/最大化布局首版为内存态；跨重启持久化、分屏和 OS 多窗口不在 V2 范围，另行决策。
- 宿主窗口关闭、崩溃、取消失败、审批过期等由原功能规则处理；需要改变时独立记录决策。

## 验收标准

#### AC01 全功能归位

Given 本文入口清单与当次代码中的全部用户可达界面。

When 逐项从新导航或上下文入口访问。

Then 默认进入桌面，AI会话独立可达；每项有主归属；桌面配置不触发任务；重复管理入口合并，无greet或假可用功能。

#### AC02 首次使用闭环

Given 无本地账户且未配置模型的受支持环境。

When 用户先进入桌面，再打开AI会话、配置模型服务并明确发送首条消息。

Then 不被强制创建账户，配置后可返回工作台；成功或失败有真实反馈，导航本身不发起模型调用。

#### AC03 技能与工具旅程

Given 已配置模型、可添加的本地技能与可连接的测试 MCP 服务。

When 用户在技能中心浏览/添加技能并在支持的单任务模式使用；随后在 MCP 管理查看服务与工具，执行需要确认的工具任务。

Then 技能选择对应真实资源；MCP 服务状态、工具和调用确认可见；工具审批保留明确允许/拒绝，失败和未知结果不被显示为成功。

#### AC04 导航与任务生命周期

Given 有未发送输入或正在运行的聊天/单任务。

When 用户打开配置、返回或尝试会卸载面板的导航。

Then 设置在主窗口悬浮、不创建独立窗口、不卸载工作区，保留草稿；会停止任务的离开先提示且可取消，宿主终态如实显示。

#### AC05 设置与模块准入

Given 管理入口、旧路由、已启用模块和无权限调用场景。

When 从新导航或旧链接进入并执行操作。

Then 兼容入口到达正确位置；宿主继续核验窗口/路由/调用者；被拒绝的操作不因新入口获得权限。

#### AC06 账户与全局状态

Given 登录失败、账户切换、数据库启动失败及未知路由场景。

When 用户按页面提供的入口操作。

Then 反馈与现有领域语义一致，账户切换后旧草稿和审批不可见，启动失败不进入正常工作区。

#### AC07 视觉与可访问性

Given 全部页面、亮暗主题、中英文、最终批准的尺寸/字号组合及800px窗口；旧五档迁移在方案冻结后纳入验证。

When 使用键盘、屏幕阅读器与真实鼠标完成关键操作并进行目视检查。

Then 操作可达、焦点可见、文案不遮挡控件、状态不只靠颜色，令牌对比度通过。分域方案需证明UI调整不改变正文、正文调整不改变工具栏高度、画布缩放不改变全局界面。

#### AC08 局域网体验

Given 主机允许局域网访问及一台真实远程设备。

When 配对、聊天、主机撤销后再次访问。

Then 远程可完成授权范围内流程，撤销及时反馈，远程没有桌面配置与模块操作入口。

#### AC09 表单与失败恢复

Given 有未保存配置、提交失败、空数据、加载失败及长文本场景。

When 保存、取消、离开、重试或改变窗口大小。

Then 不把关闭或加载失败当成功/空结果；安全输入按规则保留，敏感输入不进入普通草稿，错误有可执行恢复入口。

#### AC10 整体交付

Given 本文全页面清单和关键旅程均已实现。

When 进行一次完整改版验收。

Then 全部页面采用统一设计，相关前端与真实桌面回归有记录，遗留领域缺口明确登记，不以局部页面通过宣布整体完成。

#### AC11 主题套装与区域继承

Given 浅色和深色配置分别选择套装，且界面与阅读区域存在自定义颜色。

When 更换套装、切换模式、恢复单项或恢复某一区域。

Then 按外观设计分篇的继承顺序解析，覆盖保留且来源可识别；恢复只移除指定范围，另一明暗配置与排版不被重置。

#### AC12 排版与尺寸作用域

Given 导航、消息、输入、代码、技术值与任务结果，以及最大字号和800px窗口。

When 分别改变三类字体、字号、内容行高和界面密度。

Then 仅对应角色使用该排版，代码不随阅读字号改变，阅读字号不随密度改变；主要操作可达，无字体外部网络依赖。

#### AC13 预览应用与失败恢复

Given 宿主已确认偏好、未应用草稿、系统主题变化和另一窗口修改偏好的场景。

When 当前窗口实时预览、应用、取消、关闭、Esc，或发生保存失败与 revision 冲突。

Then 未应用预览可完整恢复，只有成功确认的完整快照成为持久偏好；失败保留草稿并恢复已确认全局值；并发冲突不静默覆盖。

#### AC14 主题校验与兼容

Given 无效颜色、低对比度、未知套装、损坏偏好及 V1 旧库。

When 编辑应用或启动升级后的应用。

Then 非法配色不能应用，状态语义保持独立；损坏数据按字段安全回退；旧库按冻结映射迁移且失败可恢复，不把未持久化值报告为成功。

#### AC15 工作区标签与应用切换

Given 主窗口中已打开 AI 会话（含多个会话标签）、技能中心、MCP 管理、单任务和一个应用视图；宿主已登记同一应用实例。

When 用户切换外层工作区标签、重复点击技能/MCP/单任务入口、关闭资源标签、从启动台再次打开同一应用，再返回 AI 会话。

Then 外层只显示一层工作区标签，AI 会话内层标签独立；技能/MCP/单任务是单例标签，重复打开只聚焦，关闭后可从左侧重新打开；切换保留草稿、滚动和视图状态；再次打开应用聚焦已有视图，不创建第二实例；关闭应用标签不停止后台运行；不创建独立 OS 窗口。

#### AC16 应用启动台与固定应用

Given 已安装的官方/第三方模块包含启用、停用、待授权和运行中状态；启动台可从左侧导航、桌面和 Cmd/Ctrl+K 打开，左侧导航保持可见。

When 用户搜索、打开可用应用、把可用图标拖到左侧、尝试拖动停用/无权限图标，或关闭启动台。

Then 启动台是主工作区内的居中悬浮面板，不占满右侧工作区，周围工作区可见，左侧导航仍可操作；没有右上角关闭按钮；点击面板外空白或按 Esc 关闭并恢复焦点。网格只显示图标、名称和运行状态点，没有说明、版本、状态文字、卡片或打开/管理按钮；搜索过滤图标；运行中显示图标下方状态点，停用/无权限降低饱和度且不可固定；拖拽出现落点高亮和固定提示，放下后进入“应用”分组且最多 3 个；打开聚焦已有视图或新建标签；未启用/无权限不产生可执行假界面；不创建独立 OS 窗口。

按[D133](../../../06-决策记录/V2-冻结决策.md#d133-迁移阶段6真实能力与账户资源边界)，固定项最多3个及其顺序、入口/最近显隐和主动侧栏折叠保存于本设备当前账户。初始化读取完成前不得回写默认值；并发保存用revision比较，冲突或结果未确认须读取恢复，不自动重放。卸载项移除，停用/失权项保留偏好但不能调用。账户切换失效旧读写响应；任务、标签、运行租约和临时专注不跨重启恢复。

#### AC17 最大化/专注与应用宿主

Given 一个 document 应用和一个 full-bleed 画布在工作区打开；左导航和检查器可见。

When 用户最大化、切换标签、按 Esc 或显式还原，并在 800px/高密度下操作。

Then 左导航、检查器和历史隐藏，细标签条与应用切换入口保留；画布占满工作区，document 应用保留可读内容宽度；退出恢复之前的布局；专注模式仍能打开启动台/切换器；OS 全屏不与此混淆。

#### AC18 AI 会话内多标签

Given AI 会话内有多个会话标签，其中一个会话正在生成且有草稿；界面没有永久左侧会话列表。

When 用户新建、切换、关闭空闲会话、关闭运行中会话、触发标签溢出/历史下拉，或外层切到应用再返回。

Then 会话标签支持新建/切换/关闭/溢出；每个会话的草稿和滚动位置隔离；切换标签不取消生成；关闭运行中会话先确认停止；外层切换保留会话标签集合；历史入口可用；不出现左侧会话列表。

#### AC19 单实例、多视图与生命周期

Given 同一应用已打开一个视图；不同应用各有标签；应用可被停用、权限撤销或崩溃；账户可切换。

When 用户再次打开同一应用、打开支持多视图应用的第二个文档、关闭/恢复标签或切换账户；画布项目仍按D125在同一画布标签内切换。

Then 同一应用仍只有一个实例；不同文档view共享该实例且DOM独立，同文档只聚焦已有view；关闭标签不停止宿主后台运行；停用/撤权/崩溃提供阻断与恢复入口；账户切换清理旧状态；不创建第二实例、独立OS窗口或额外画布标签层。

#### AC20 工作区空间与响应式

Given 1440/1280/800px、高密度/大字号下打开 AI 会话和 full-bleed 应用。

When 查看 AI 会话、应用、最大化状态并调整窗口大小。

Then 不出现重复页面标题栏；阅读和输入列按本规格最终渲染基线同宽、窄窗自适应，检查器可折叠；应用/画布全幅；无永久左侧会话列表；800px下主操作、标签溢出和设置纵列可达，无文档横向溢出；专注时可切换工作区并恢复布局。

## 技术设计

本节为工程约束，具体工作区/应用宿主方案批准前不作为可开发设计。生产实现涉及 L2；触及窗口身份、权限路由、模块实例、并发状态或凭据处理时为 L3，须有独立技术设计、稳定分支与安全回归。[工作区与应用宿主技术设计](09-产品设计与UI改版-技术设计.md) 已建立初稿，固定标签状态、实例归属、关闭/运行、布局记忆、启动台数据源和应用布局模式；V2 不创建独立 OS 窗口。

### 单元契约

- 导航定义集中维护，显示名称与内部 ID 分离；可访问入口由实际能力与宿主状态确定。
- 工作区外壳常驻，外层标签映射工作表面，AI 会话内层标签映射会话；切换标签不重建已打开的应用/会话视图。
- 应用实例、视图归属、后台运行和崩溃状态由宿主登记；前端只消费公开状态，不根据标签自行推断或创建第二实例。
- 应用启动台读取已安装模块清单；固定/最近/布局是界面状态，不绕过宿主权限与启用状态。
- 应用布局模式由 manifest/contribution 提供，宿主提供最小外框；设置浮层只管理，应用使用在工作区（D119/D120）。
- 业务请求和状态放在 store/hook，布局消费公开接口；视觉通过 `src/ui/` 与产品模式层统一实现。
- 旧路径兼容、返回位置、草稿清理与模块实例归属在详细技术设计中明确，不直接对受保护路径做字符串替换。
