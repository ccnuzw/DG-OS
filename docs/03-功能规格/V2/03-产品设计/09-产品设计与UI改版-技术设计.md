## 风险与对策

| 风险 | 严重程度 | 对策 | 关联决策 |
| --- | --- | --- | --- |
| 同一应用被打开多次，产生第二实例或重复视图 | 高 | 以 moduleId 为唯一实例键；以 viewId 去重；打开动作串行化并在 reducer 内判断 | D120 |
| 关闭应用标签被误当成停止运行 | 高 | 关闭视图只 detach，不调用 stop_module；运行状态由宿主显示；停止只走显式管理动作 | D082、D120 |
| 切换标签导致会话被卸载、生成被取消 | 高 | 工作区 shell 常驻；会话面板保持挂载，仅隐藏；只有关闭会话/账户切换才请求取消 | D120 |
| 工作区标签与 AI 会话标签层级混淆 | 中 | 外层只渲染工作表面；内层只在 AI 工作表面渲染；两层各自维护 active ID | D120 |
| 模块热更新期间视图指向旧 runtime | 高 | 视图只保存 moduleId/viewId；渲染时取该 moduleId 的最新实例；旧实例卸载不改变视图键 | D044、D055 |
| 权限撤销、模块停用、账户切换后仍显示可执行旧界面 | 高 | 监听模块摘要/账户 epoch；失效则把视图置为 blocked 并清空可执行内容 | D120 |
| 启动台目录未返回时重复打开或假空 | 中 | 独立loading/error/empty；等待catalog，不硬编码应用 | D120 |
| 拖拽在触控/键盘不可用 | 中 | 鼠标drop、P键、长按和固定菜单共用校验；最多3个 | D121 |
| 点击外部误关启动台或焦点丢失 | 中 | 面板内部点击不关闭；拖拽中不触发 dismiss；关闭后焦点回打开按钮 | D122 |
| 专注模式退出后丢失原布局 | 中 | 进入专注前快照 sidebar/inspector/history 可见性与宽度；退出恢复；只保存在当前会话 | D120 |
| V2 被误解为支持 OS 多窗口 | 高 | 不调用窗口创建命令；类型和路由中不出现 windowId 作为用户能力；保留内部 workspace 抽象 | D120 |
| 标签关闭与账户切换竞态导致旧会话复活 | 高 | 以 accountEpoch 标记异步结果；过期结果丢弃；切换时清空 reducer 与待处理队列 | D120 |

## 单元契约

| 函数 | 前置条件 | 返回 / 后置条件 | 副作用 | 幂等 |
| --- | --- | --- | --- | --- |
| `workspaceReducer(state, action) -> WorkspaceState` | state 已初始化 | 返回新状态；不修改入参 | 无 | 是：同一 action ID 重复应用结果一致 |
| `openApp(moduleId, documentId?) -> OpenResult` | 应用在 catalog 中且 enabled | 已有视图则激活；有实例则建视图；无实例返回 needsManagement；不自动 start_module | 写内存 workspace；可能触发视图挂载 | 是：按 moduleId + viewId 去重 |
| `closeView(surfaceId, reason) -> Promise<CloseResult>` | surface存在 | 按对象关闭协调；只有allowed才移除；应用不停止宿主 | 确认/保存/停止或detach，按对象区分 | 是：同对象关闭请求合并 |
| `closeAiWorkspace() -> CloseResult` | AI 工作表面存在 | 隐藏/关闭外层 AI 标签；保留会话标签与历史；运行中会话先确认 | 写内存 workspace | 是 |
| `openLauncher(source) -> LauncherState` | 主窗口已挂载 | 打开浮层；读最小应用目录；保留来源focus | 读拟建只读目录命令；写内存 | 是：重复打开只聚焦 |
| `pinApp(moduleId) -> PinResult` | 应用可用 | 固定应用；固定数不超过 3；已固定返回 alreadyPinned | 写内存 | 是 |
| `beginDrag(moduleId) -> DragState` | 启动台打开且应用可用 | 记录拖拽应用；显示左侧落点提示 | 写内存 | 是 |
| `dropToPin(moduleId, target) -> PinResult` | 拖拽中且 target 是左侧导航 | 调用 pinApp；清除拖拽态 | 写内存 | 是 |
| `dismissLauncher(source) -> void` | 启动台打开 | 面板内点击保持；外部/Esc 关闭并恢复焦点 | 写内存 | 是 |
| `toggleFocus(tabId) -> FocusState` | 视图存在 | 首次保存，切目标保留快照，退出应用恢复载荷 | 写内存，不建窗口 | 否：切换动作；按action ID去重 |
| `reconcileInstances(instances) -> void` | 收到 moduleRuntimeHost 快照 | 将视图绑定到最新 runtimeId；crashed/释放状态写入视图 | 更新内存视图状态 | 是：按快照重建派生状态 |
| `resetForAccount(epoch) -> void` | 账户切换已确认 | 清空标签、会话草稿、启动台和待处理动作；epoch 递增 | 取消当前生成；清空内存 | 是 |

## 状态模型

```ts
type WorkspaceSurface =
  | { kind: 'ai'; id: 'ai' }
  | { kind: 'resource'; id: 'skills' | 'mcp' }
  | { kind: 'task'; id: 'single-task' | 'cli-agent' }
  | { kind: 'app'; id: string; moduleId: string; viewId: string; documentId: string | null; title: string };

type AppInstanceState = {
  moduleId: string;
  runtimeId: string | null;
  status: 'not_loaded' | 'starting' | 'ready' | 'draining' | 'stopped' | 'failed';
  crashed: boolean;
  permissionBlocked: boolean;
  views: string[];
};

type WorkspaceState = {
  accountEpoch: number;
  surfaces: WorkspaceSurface[];
  activeSurfaceId: string | null;
  instances: Record<string, AppInstanceState>;
  pinnedModuleIds: string[];
  focusedSurfaceId: string | null;
  layoutSnapshot: { sidebar: boolean; sidebarWidth: number; inspector: boolean; inspectorWidth: number; history: boolean; historyWidth: number } | null;
  launcher: { open: boolean; query: string; status: 'idle' | 'loading' | 'ready' | 'error'; dragModuleId: string | null; dropTarget: 'none' | 'sidebar' };
  pending: Record<string, 'opening' | 'closing'>;
};
```

约束：

- AI 会话是唯一带内层会话标签的 surface；应用 surface 不默认再嵌套应用标签。
- 应用 surface 按 viewId 区分；同一 moduleId 的多个 view 共享 instances[moduleId]。
- 只有宿主返回的 runtimeId 可写入实例状态；前端不能生成或伪造 runtimeId。
- 关闭应用surface只移除视图，不删除instances；AI/资源/任务关闭先由下方协调协议处理，不能套用应用detach语义。实例状态是宿主快照投影，不是第二个运行状态机；会话集合仍在chatStore，不复制进surface。
- 标签、启动台、布局快照都是内存态；首版不写数据库，不跨重启恢复。
- 任何异步结果回写前检查 accountEpoch；epoch 不匹配则丢弃。

## 伪代码

分支 ID 取本功能号 09。

```text
ASYNC FUNCTION openApp(moduleId, documentId) -> OpenResult:
  IF accountEpoch changed OR module not in catalog: RETURN blocked       // B09-01
  IF catalog entry disabled OR permission denied: RETURN needsManagement // B09-02
  existing = documentId is null ? lastActiveView(moduleId) : surfaces.find(kind=app AND moduleId AND documentId)
  IF existing:
    activate(existing); RETURN focused                                 // B09-03
  IF moduleId in pending: RETURN waiting                               // B09-04
  pending[moduleId] = opening
  viewId = stableId(moduleId, documentId)                              // B09-05
  IF instances[moduleId].runtimeId exists:
    TRY surface = await openRuntimeView(moduleId, viewId, documentId)
        IF epoch changed OR view tombstoned: disposeView(surface); RETURN stale
        surfaces.push(surface); activate(surface); RETURN created      // B09-06
    CATCH error: RETURN viewError
    FINALLY pending.delete(moduleId)
  pending.delete(moduleId)
  RETURN needsManagement                                               // B09-07

ASYNC FUNCTION closeView(surfaceId, reason) -> CloseResult:
  surface = surfaces.find(surfaceId)
  IF surface missing: RETURN alreadyClosed                             // B09-08
  result = await closeCoordinator.prepare(surface, reason)             // B09-09
  IF result != allowed OR epoch changed: RETURN result
  restoreFocusLayoutIfNeeded(surfaceId)
  surfaces.remove(surface); tombstone(surfaceId)                        // B09-10
  IF surface.kind = app: detachRuntimeView(surface.viewId)              // B09-11
  IF activeSurfaceId = surfaceId: active = neighbor or desktop          // B09-12
  RETURN closed                                                        // B09-13

FUNCTION toggleFocus(surfaceId) -> FocusState:
  IF focusedSurfaceId = surfaceId:
    restore = layoutSnapshot; apply(restore); layoutSnapshot = null
    focusedSurfaceId = null; RETURN {kind: restored, layout: restore}    // B09-14
  IF focusedSurfaceId is null: layoutSnapshot = currentLayoutWithWidths() // B09-15
  focusedSurfaceId = surfaceId; hide sidebar/inspector/history           // B09-16
  RETURN focused

ASYNC FUNCTION openLauncher(source) -> LauncherState:
  launcher.open = true; launcher.status = loading
  TRY modules = await read_workspace_app_catalog()                    // B09-17
  CATCH error: launcher.status = error; RETURN retryableError
  IF accountEpoch changed: RETURN stale
  catalog = modules.entries                                            // B09-18
  launcher.status = ready; focus search                                // B09-19
  RETURN catalog

FUNCTION pinApp(moduleId) -> PinResult:
  IF moduleId not in catalog OR NOT usable: RETURN blocked             // B09-20
  IF moduleId pinned: RETURN alreadyPinned                             // B09-21
  IF pinned.count >= 3: RETURN limit                                   // B09-22
  pin(moduleId); RETURN pinned

FUNCTION reconcileInstances(instances) -> void:
  latest = newest instance per moduleId                                // B09-23
  FOR EACH app surface:
    surface.runtimeId = latest[moduleId]?.runtimeId                     // B09-24
    surface.blocked = latest missing OR crashed OR permission denied    // B09-25

FUNCTION resetForAccount(newEpoch) -> void:
  accountEpoch = newEpoch                                              // B09-26
  cancelConversationIfRunning()                                        // B09-27
  surfaces = []; instances = {}; launcher = closed; focus = null        // B09-28

FUNCTION beginDrag(moduleId) -> DragState:
  IF launcher closed OR NOT usable(moduleId): RETURN blocked           // B09-29
  launcher.dragModuleId = moduleId; launcher.dropTarget = sidebar      // B09-30
  RETURN dragging

FUNCTION dropToPin(moduleId, target) -> PinResult:
  IF launcher.dragModuleId != moduleId OR target != sidebar: RETURN noop // B09-31
  result = pinApp(moduleId)                                            // B09-32
  launcher.dragModuleId = null; launcher.dropTarget = none              // B09-32
  RETURN result

FUNCTION dismissLauncher(source) -> void:
  IF source = panel: RETURN noop                                       // B09-33
  launcher.open = false; restoreFocus()                                // B09-34
```

## 并发控制

| 场景 | 冲突点 | 控制方式 | 失败策略 |
| --- | --- | --- | --- |
| 双击/重复点击打开应用 | 两个 openApp 同时创建视图 | 以 moduleId + documentId 稳定 viewId；pending 去重；reducer 串行应用 | 第二次返回 waiting/focused，不建第二视图 |
| 打开应用时清单尚未返回 | 启动台假空或错误打开 | launcher loading；open 读取 catalog；无 catalog 时等待 | 显示加载/重试，不显示假应用 |
| 模块热更新旧/新实例并存 | 视图绑定旧 runtime | 渲染按 moduleId 取最新实例快照；旧实例卸载不改 viewId | 最新实例可用后重绑；旧实例只做清理 |
| 关闭标签与模块加载同时发生 | 关闭后加载完成又出现视图 | 视图先移除并记录 tombstone；加载完成只更新实例，不自动建视图 | 已关闭视图保持关闭；实例在启动台可见 |
| 账户切换与异步启动台返回 | 旧账户结果写入新账户 | accountEpoch 校验；切换时清空 pending | 丢弃过期结果，不提示成功 |
| 专注模式中切换标签/关闭当前应用 | 布局快照指向已关闭视图 | 关闭当前 focus 视图先 restore layout，再切换 | 恢复原布局，不留下隐藏侧栏 |

死锁预防：所有工作区状态转换在一个 reducer/命令队列中串行；宿主异步调用不持有 UI 锁；不在模块加载期间等待用户确认以外的宿主写操作。

## 事务边界

- 范围：工作区标签、视图、启动台、布局快照是内存状态，转换以单次 reducer 提交为边界。
- 隔离级别：不适用：没有数据库事务；以 accountEpoch 隔离账户切换前后的异步结果。
- 失败回滚：reducer 提交前的验证失败不改变状态；宿主调用失败只更新错误视图，不伪造成功。应用启动/停止/更新的宿主事务由模块生命周期保证，不在前端合并。

## 幂等与重试

- 幂等键：viewId = moduleId + documentId 的稳定映射；open/close 动作带 action ID；同一动作重复提交只应用一次。
- 存储与有效期：内存命令表，随窗口/账户结束；不写数据库。
- 重复请求：打开返回focused/waiting；关闭alreadyClosed；固定重复返回alreadyPinned，取消固定是独立动作，不把重复pin当toggle。
- 宿主调用：只读目录失败显示重试；不自动重试打开应用；不自动start/stop模块，打开成功必须先得到runtime视图确认。

## 外部调用与补偿

- 推荐只读目录命令见下方契约；现有list_modules仅Settings路由可读。读取失败显示加载错误，不能当空目录或展示原型假应用。
- 应用打开不调用 `start_module`：模块启用后由宿主启动；未运行的应用显示“需要管理/启动”，把 `start_module` 留给设置中的模块管理（需要 ModulesManage 能力）。
- 应用关闭视图不调用 `stop_module`；后台运行由宿主运行服务/D082 管理，显式停止在模块管理或后续运行中心完成。
- 当前聊天生成由聊天 store 管理；切换标签不取消，关闭运行中会话前确认，账户切换取消。没有外部网络重试补偿。

## 安全与日志

- 敏感字段：不记录凭据、会话正文、模块源码、完整模型响应；日志只记录 moduleId/viewId/action ID 和状态码。
- 权限校验：应用目录只供展示，模块每次调用仍以宿主admission/runtime/授权为准；前端blocker不是安全边界。
- 新增最小只读目录与公开视图桥须按下方增量评审；模块能力仍走D051绑定，不接受前端自报runtime/user/caller。设置浮层不改变host::context和module_session现行边界。
- 错误展示沿用模块 API 的固定消息，不把原始 stack 或路径放进界面。

### 最小只读应用目录

推荐拟建 `read_workspace_app_catalog()`，无renderer身份参数；可信主窗口 + SessionResolver派生用户 + 专用只读策略，独立于ModulesManage，不放宽list_modules/start/stop/授权/安装命令。V2冻结决策D120原“不新增业务命令”不代表允许绕过当前读取门禁；这一宿主增量在专项准入评审确认前不得编码。

响应推荐 `{catalogRevision, entries}`；每项只含 `moduleId, displayName, iconResourceId?, layout:document|full-bleed, viewCapability:single|multiple, enabled, permissionState:granted|pending|denied, runtimeState:not_loaded|starting|ready|draining|stopped|failed, crashed`。未声明/无效图标用宿主语义图标，iconResourceId必须解析到准入快照内验证资源，不收任意URL/SVG/HTML。不得返回凭据、包路径、源码、完整manifest或授予令牌；显示名不是标识。

宿主从当前账户安装目录与权限/运行状态生成；revision随安装/更新/启停/撤权/崩溃变化；前端在这些动作完成及启动台重开时刷新，账户epoch不符丢弃。没有现成推送时先用动作后失效+重读，不凭runtime已有实例列表猜完整目录。无目录为loading/error/empty独立状态。目录允许看不可用应用的简短状态；打开仍二次核验runtime/授权，状态变化时移除可执行内容、解除无效固定项，不能假定目录读取就是授权。

### 单实例多视图与随包模块

当前 `ModuleInstanceView` 只有一个container，`ModuleSlot` appendChild移动它；这只能保证单视图保活。推荐模块生命周期仍每runtime一次createModule/onLoad/onUnload；增量声明应用view贡献（layout、single/multiple），runtime持有view登记表，每项 `{viewId, documentId, container, root, dirty}`。viewId由宿主工作区稳定分配并绑定runtime/module/accountEpoch，模块不能借viewId换caller。

拟议公开view工厂 `openView({viewId,documentId}) -> {Component, beforeClose?, save?, dispose?}`，beforeClose只报告dirty/可保存/拒绝原因；save返回成功/失败，只有真实成功才清dirty。host协调确认；模块不获得停止其他任务的能力。same document重复open聚焦已有view；无document聚焦最近或默认view。多view各有独立container/root，共享一个runtime服务与能力租约；禁止同DOM双挂或为view再次createModule。未声明视图贡献的旧包视为single，只将稳定根接入一个工作面，不宣称多视图；provider-console本次改包，不保留第二套旧UI。

对声明multiple的新view，关闭成功先detach并解除局部订阅，再dispose该view根，不调stop_module/onUnload；对single稳定根仅detach保留，直到runtime卸载才销毁，保持D044。重开同runtime恢复single根或按工厂创建multiple view，文档由业务存储恢复；关闭不自动保存。热更新按现模块状态capture协议将documentId/view集合重建到新runtime，不执行旧租约；旧dispose只清旧runtime。失败、撤权、停用、崩溃保持阻断和管理入口；账户变化清空view并丢弃旧异步。

view贡献字段与包校验/摘要/host API版本需FR-003/004增量评审；同步digest、构建产物、BUILTIN_PINS及release gate。不能只改TypeScript接口绕过包准入。布局提示不是调用授权，ModuleCallRouter仍每次检查。画布按D125一个标签内平台→项目，项目协议由FR-006负责。

### 关闭协调和运行归属

单一 `requestClose(surfaceId, reason)` 去重同一关闭请求，捕获epoch与对象版本，先读live状态再确认，异步保存/取消返回后再次核验；只有allowed才提交移除。reason区分userClose/accountEnd/runtimeInvalidation，不让普通关闭伪造账户清理。关闭确认取消不触发任何cancel/remove。

| 资源 | 选择、筛选、滚动、非敏感draft保留 | dirty=保存/放弃/取消，保存成功才关闭；非dirty立即释放视图 | 保存失败保持draft；明文密钥只在安全局部内存，关闭/账户变化清除，不能为了保活写磁盘 |

## D138布局缩放增量

具体值、控件、直接迁移和作用域唯一见[外观分篇§4.1](外观主题与作用域设计.md#41-第四阶段布局缩放与空间预算)；不增加第二个偏好来源、patch命令或重试系统。沿用confirmed/draft、宿主revision、accountEpoch/request序号及完整快照CAS。

```text
FUNCTION beginEditing() -> release:
  register active editor; release removes this registration once        // B09-42

FUNCTION onLayoutScaleKey(event):
  IF event.defaultPrevented OR not macOS Command minus/equal/plus:
    RETURN untouched                                                    // B09-43
  IF controller not loaded OR blocked OR disposed: RETURN untouched
  IF active editor exists:
    step draft density within ten-step bounds; preview only              // B09-44
  ELSE:
    record bounded density intent based on confirmed/current pending density
    drain only after preceding CAS confirmation; full confirmed copy
    changes density only, preserving every other field                   // B09-45
  consume handled event; update one feedback bubble; no duplicate Toast

FUNCTION settleScaleWrite(result, epoch, request):
  IF disposed OR epoch/request stale: discard response and pending intent // B09-46
  IF saved: update confirmed/revision; drain next explicit density intent
  ELSE: clear pending intent; restore confirmed rendering; preserve draft
        conflict requires user reapply; unconfirmed requires readback
        never retry automatically                                       // B09-47

FUNCTION readOldAppearance(raw):
  preserve raw row/revision; apply prior font/reading mapping only
  derive density directly from raw density by §4.1; return schema6 memory
  no database write; only explicit complete CAS persists schema6           // B09-48
```
