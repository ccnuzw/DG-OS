# DGOS 功能演进矩阵

## 1. 文档职责

本文档以"能力主线"为单位，说明同一项产品能力如何从 V1 底座逐步演进到画布系统、应用市场、云端协同、企业化、移动端、AI Agent 和开发者生态。

本文档回答以下问题：

- 一项能力最早在哪个版本出现
- 后续版本具体增加了什么用户可感知行为
- 新阶段依赖哪些既有功能和发布门禁
- 达到什么结果才算完成该阶段
- 当前内容是现行功能、未来规划、历史迁移还是独立增强
- 详细需求、当前实现状态和验收证据应到哪里查看

本文档不替代其他权威来源：

- 产品愿景和完整范围以[产品蓝图](产品蓝图.md)为准
- 版本顺序和边界以[版本路线图](版本路线图.md)为准
- V1 功能行为以[V1 功能规格](../03-功能规格/V1/README.md)为准
- 当前实现状态以[V1 实现状态](当前版本/V1-实现状态.md)为准

## 3. Provider 能力演进

### 3.1 V1 基础适配（必须）

**用户价值**：能够配置和使用 AI 模型

**核心行为**：
- 配置 Provider（名称、类型、base_url、API Key）
- Provider 列表管理（增删改查）
- 获取模型列表
- 模型分类标签（text-generation、image-generation、video-generation、audio-generation）
- 调用模型（同步/流式）
- 使用记录
- 支持多个同类型 Provider
- 排序和默认选择机制

**技术边界**：
- 只实现 OpenAI 兼容适配器
- 模型分类标签内置维护
- 支持多个同类型 Provider 配置

**功能编号**：V1-FR-001

**验收标准**：
- 可配置至少 1 个 Provider
- 可获取模型列表并正确分类
- 可成功调用模型并返回结果
- 流式输出正常工作
- 多 Provider 排序和选择正确

### 3.2 V4 官方 Provider（云端增强）

**用户价值**：无需配置 API Key，直接使用官方提供的模型

**新增行为**：
- 登录云端账号
- 使用官方 Provider（消耗积分）
- 积分管理（查看余额、充值）
- 用量统计
- 多厂商适配器（Claude、通义千问、文心一言）

**技术边界**：
- 官方 Provider 和自配置 Provider 可并存
- 官方 Provider 排序优先级可调整
- 积分按 token/张/秒计费
- 支持 3+ 主流厂商

**依赖**：V4 账号系统

**验收标准**：
- 登录账号后可使用官方 Provider
- 积分实时扣除
- 用量记录准确
- 至少支持 3 个主流厂商

### 3.3 V5 企业 Provider（企业化）

**用户价值**：组织统一管理 Provider 配置

**新增行为**：
- 组织级 Provider 配置
- 成员共享 Provider
- 组织用量统计
- 组织账单

**依赖**：V5 组织管理

## 4. Skills 能力演进

### 4.1 V1 基础管理（必须）

**用户价值**：扩展 AI 能力，使用现有 Skills 生态

**核心行为**：
- 连接远程 Skills 仓库
- 浏览 Skills 列表（分类、搜索）
- 安装 Skills（下载、配置）
- 卸载 Skills
- 启用/禁用 Skills
- Skills 配置管理（API Key 等）
- 调用 Skills（HTTP/CLI）
- 使用记录

**技术边界**：
- 使用现有 Skills 标准（LangChain Tools）
- DGOS 只管理和调用，不执行
- Skills 自己运行，返回结果

**功能编号**：V1-FR-002

**验收标准**：
- 可连接至少 1 个 Skills 仓库
- 可安装至少 1 个 Skill
- 可成功调用 Skill 并返回结果

### 4.2 V2 画布集成（画布增强）

**用户价值**：在画布的 LLM 节点中使用 Skills 增强生成能力

**新增行为**：
- LLM 节点显示可用 Skills
- 用户可选择 Skills（可选）
- Skill 处理 Prompt 后再调用 LLM
- 或 LLM 结果通过 Skill 后处理

**技术边界**：
- Skills 是可选的，用户可以不选
- Skills 调用失败不阻塞 LLM 调用
- 显示 Skills 处理进度

**依赖**：V2 画布系统、V1 Skills 管理

**验收标准**：
- LLM 节点可选择 Skills
- Skills 增强生成效果可见

### 4.3 V4 云端 Skills（云端增强）

**用户价值**：使用官方提供的 Skills，无需本地安装

**新增行为**：
- 云端 Skills 仓库
- 在线调用 Skills（无需本地安装）
- Skills 用量统计

**依赖**：V4 账号系统

### 4.4 V7 Agent 集成（AI Agent）

**用户价值**：Agent 自动选择和调用 Skills

**新增行为**：
- Agent 自动发现可用 Skills
- Agent 根据任务自动选择 Skills
- Agent 链式调用多个 Skills

**依赖**：V7 AI Agent 系统

## 5. 模块系统演进

### 5.1 V1 热更新（必须）

**用户价值**：安装和更新模块无需重启应用

**核心行为**：
- 模块动态加载（Module Federation）
- 模块卸载
- 模块热更新（无需重启）
- 模块权限管理（粗粒度）
- 模块配置（manifest.json）

**技术边界**：
- 基于 Module Federation
- 共享依赖（React、Zustand）
- 独立构建

**功能编号**：V1-FR-004

**验收标准**：
- 可加载至少 2 个官方模块
- 模块更新无需重启
- 模块权限正确隔离

### 5.2 V3 应用市场（生态）

**用户价值**：从应用市场安装第三方模块

**新增行为**：
- 应用浏览（分类、搜索）
- 应用详情（截图、描述、评分）
- 应用安装（从市场下载）
- 应用更新（自动推送）
- 应用卸载
- 开发者提交
- 人工审核
- 版本管理

**技术边界**：
- 中心化市场
- 必须登录云端账号
- 人工审核

**依赖**：V1 模块系统稳定

**验收标准**：
- 可从市场安装至少 1 个第三方模块
- 模块更新自动推送
- 应用评分和评论系统正常

### 5.3 V4 云端分发（云端增强）

**用户价值**：跨设备同步已安装模块

**新增行为**：
- 已安装模块列表云端同步
- 新设备自动安装已同步模块
- 模块配置云端同步
- 付费应用支持

**依赖**：V4 云端同步、V3 应用市场

### 5.4 V6 移动端模块（移动端）

**用户价值**：移动端也可以使用应用模块

**新增行为**：
- 移动端模块适配
- 触摸手势优化
- 移动端 UI 适配

**依赖**：V6 移动端平台

### 5.5 V8 SDK 和模板（开发者生态）

**用户价值**：开发者更容易开发模块

**新增行为**：
- 官方 SDK（TypeScript/Rust）
- 模块开发模板
- CLI 工具（dgos-cli）
- 文档和示例
- 自动化测试工具

**依赖**：V3 应用市场稳定

## 6. 无限画布演进

### 6.1 V2 画布系统（核心价值）

**用户价值**：可视化编辑工作流

**核心行为**：
- 画布视口（缩放、拖拽、平移）
- 完整节点类型（10+ 种）：
  - ImageNode：图片输入
  - PromptNode：提示词编辑
  - LLMNode：LLM 调用（可选 Skills）
  - GeneratorNode：内容生成
  - LoopNode：循环执行
  - ConditionalNode：条件分支
  - TransformNode：数据转换
  - FunctionNode：自定义函数
  - OutputNode：结果输出
  - ConnectionNode：连接点
- 节点连线系统
- 实时执行（用户操作立即执行）
- 执行状态可视化
- 错误处理和重试
- 工作流 JSON 格式定义
- 工作流导入导出
- 布局算法（自动排版）
- 工作流模板库

**技术边界**：
- 画布作为独立模块
- 节点系统可扩展
- 每个节点文件 < 200 行
- 支持循环节点
- 实时执行，非批量

**功能编号**：V2-FR-001 到 V2-FR-010

**依赖**：V1 模块系统稳定

**验收标准**：
- 可创建至少 10 种节点
- 节点可以连线
- 循环节点正常工作
- 实时执行响应及时
- 画布可以保存和加载
- 工作流可导出为 JSON
- 导出的工作流可正确导入
- 至少 3 个内置模板
- 交互流畅（60fps）

**从老项目学习**：
- ✅ 保留交互体验（拖拽手感、连线交互）
- ✅ 保留节点类型设计
- ✅ 兼容老项目工作流格式（可选）
- ❌ 不复制单体架构
- ❌ 不复制耦合设计

### 6.2 V4 协同编辑（实时协同）

**用户价值**：多人实时协作编辑画布

**新增行为**：
- 实时同步节点移动
- 显示其他用户指针（带用户标记）
- 编辑节点时锁定
- 冲突自动合并（CRDT/OT）
- 操作历史和撤销
- 协同光标显示

**技术边界**：
- WebSocket 实时通信
- CRDT 或 OT 算法
- 锁机制防止冲突

**依赖**：V4 云端账号、V2 画布系统稳定

**验收标准**：
- A 用户移动节点，B 用户实时看到
- 指针显示正确
- 冲突自动解决或提示用户
- 协同编辑并发 > 100 人

### 6.3 V6 移动端画布（移动端）

**用户价值**：移动端也可以编辑画布

**新增行为**：
- 移动端画布 UI 适配
- 触摸手势（双指缩放、拖拽）
- 简化的节点编辑界面

**依赖**：V6 移动端平台、V2 画布稳定

### 6.4 V7 Agent 执行（AI Agent）

**用户价值**：Agent 自动生成和执行工作流

**新增行为**：
- Agent 根据任务自动生成工作流
- Agent 自动执行工作流
- Agent 自动调试和修复工作流

**依赖**：V7 AI Agent 系统、V2 画布稳定

## 9. 维护规则

1. 新增或调整跨版本能力时，先修改权威版本规划，再同步本文档的对应能力主线。
2. V1 功能使用既有编号和链接；不得在本文档复制或重写功能主文档中的详细行为。
3. V2+ 在通过版本进入开发门禁前只保持"规划"，不得提前创建正式功能编号或声明实现状态。
4. 版本范围迁移必须同时标注原位置、目标位置和历史材料角色，避免两个版本同时宣称同一范围。
5. 当前完成度只链接实现状态和执行证据，不用路线图、演进矩阵或页面可见性替代验证。
6. 新增 V1 功能或调整其主责能力时，必须同步[V1 功能规格索引](../03-功能规格/V1/README.md)。
