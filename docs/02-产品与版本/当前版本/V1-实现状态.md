## 11. 风险与阻塞

- 第三方来源：来源能力、许可、认证、限流和内容修订必须逐来源验证，官方本地库不能依赖远程 registry。
- MCP 安全：stdio 命令、工作目录、环境变量、HTTP 凭据、工具参数和输出都可能扩大宿主权限，必须在实现前冻结 allowlist、超时、取消和日志脱敏规则。
- 工具链：Rust 测试需在统一 arm64 工具链环境执行；Rosetta/x86_64 与 arm64 SDK 混用会造成链接失败，但不代表源码编译错误。

开发开始后，本节将追踪：
- 高风险项（可能影响发布）
- 阻塞项（需要外部依赖或决策）
