# V1.0 产品需求

## 1. 文档目标

本文档只定义 DGOS 第一版本（V1.0）功能。

本文档冻结 V1.0 交付范围。若 V1.0 子文档之间出现表述不一致，以 [V1 版本总览](V1-版本总览.md) 的范围口径为准；接口、数据表、架构和验收细节分别见同目录下的专项文档。

## 2. V1.0 定位

V1.0 建立本地优先的 AI 应用开发框架最小闭环：提供 Provider 适配、Skills/MCP 管理和模块系统基础能力，验证框架可扩展性。无限画布等核心价值功能分多版本完成，不阻塞 V1.0 交付。

### 2.1 核心目标

- ✅ 打通底层能力框架最小闭环
- ✅ 验证架构可扩展性
- ✅ 建立强制模块化规范
- ✅ 避免重蹈老项目覆辙
- ✅ 为后续版本打好底座

### 2.2 非目标

- ❌ 不求功能完整（画布、市场、协同延后）
- ❌ 不求用户规模（先验证架构正确）
- ❌ 不求商业变现（V2.0 才考虑）
- ❌ 不支持 Windows（V1.1 再做）

## 3. V1.0 功能分层

V1.0 建议拆成 5 层开发。每一层完成后都应该能独立验收。

### Layer 1：基础框架层（Week 1-2）

**目标**：让系统能跑起来

**包含**：
- Tauri 应用骨架
- Rust 后端骨架（Axum）
- SQLite 数据库初始化
- React 前端骨架（Vite）
- 基础路由系统
- 简单的本地用户管理

## 5. V1.0 核心流程

### 5.1 用户首次使用流程

```
1. 用户下载 DGOS-v1.0.dmg
2. 拖拽到应用程序文件夹
3. 双击启动 DGOS
4. 系统提示创建本地用户
5. 输入用户名、密码
6. 创建用户成功，进入主界面
7. 系统提示配置 Provider
8. 点击"去配置"，跳转到系统设置
9. 点击"添加 Provider"
10. 选择 OpenAI 兼容类型
11. 输入名称、base_url、API Key
12. 点击"测试连接"
13. 测试成功，保存 Provider
14. 回到主界面，打开 AI 工作台
15. 输入提示词："你好"
16. 选择模型：gpt-4
17. 点击发送
18. 查看流式响应结果
19. 查看历史记录
```

### 5.2 安装 Skill 流程

```
1. 打开系统设置
2. 点击"Skills 管理"
3. 点击"浏览 Skills 仓库"
4. 搜索或浏览 Skills 列表
5. 点击某个 Skill 查看详情
6. 点击"安装"
7. 输入配置（如 API Key）
8. 安装完成
9. Skills 出现在已安装列表
10. 回到 AI 工作台
11. 发起对话时，可选择该 Skill
12. Skill 增强生成效果
```

### 5.3 局域网协同流程

```
主机：
1. DGOS 启动时自动启动 HTTP 服务
2. 显示局域网地址：http://192.168.1.100:3000
3. 显示认证密码（随机生成或用户设置）

远程设备：
1. 打开浏览器
2. 访问 http://192.168.1.100:3000
3. 输入用户名、密码
4. 认证成功，进入 DGOS Web 端
5. 可以使用主机的 Provider、Skills、MCP
6. 可以发起对话
7. 可以查看历史记录
8. 不能修改 Provider 配置（只读模式）

主机显示：
1. 实时显示连接用户列表
2. 显示用户名、IP 地址、连接时间
3. 可以强制断开某个用户
```

## 7. V1.0 接口契约

详见 [V1 接口契约](../04-技术架构/当前版本/V1-接口契约.md)。

### 7.1 Tauri Commands

```rust
// Provider
list_providers() -> Vec<Provider>
get_provider(id: String) -> Provider
create_provider(config: ProviderConfig) -> Provider
update_provider(id: String, config: ProviderConfig) -> Provider
delete_provider(id: String) -> ()
list_models(provider_id: String) -> Vec<Model>
call_provider(provider_id: String, model_id: String, request: Request) -> Response
stream_provider(provider_id: String, model_id: String, request: Request) -> Stream<Chunk>

// Skills
fetch_skills_registry() -> Vec<SkillInfo>
install_skill(config: SkillConfig) -> ()
uninstall_skill(skill_id: String) -> ()
list_installed_skills() -> Vec<Skill>
call_skill(skill_id: String, params: Value) -> Value

// MCP
connect_mcp(config: MCPConfig) -> ()
disconnect_mcp(server_id: String) -> ()
list_mcp_servers() -> Vec<MCPServer>
list_mcp_tools(server_id: String) -> Vec<MCPTool>
call_mcp_tool(server_id: String, tool_name: String, params: Value) -> Value

// Module
load_module(manifest: Manifest) -> ()
unload_module(module_id: String) -> ()
reload_module(module_id: String) -> ()
list_installed_modules() -> Vec<Module>

// User
create_user(username: String, password: String) -> User
login(username: String, password: String) -> Session
logout() -> ()
list_users() -> Vec<User>
```

### 7.2 HTTP API（局域网）

```
POST /api/v1/auth/login          # 认证
GET  /api/v1/providers           # Provider 列表
POST /api/v1/providers/:id/call  # 调用 Provider
GET  /api/v1/skills              # Skills 列表
POST /api/v1/skills/:id/call     # 调用 Skill
GET  /api/v1/mcp/servers         # MCP 服务器列表
GET  /api/v1/mcp/tools           # MCP 工具列表
POST /api/v1/mcp/call            # 调用 MCP 工具
GET  /api/v1/modules             # 模块列表
```

## 10. V1.0 已知限制

以下是 V1.0 的已知限制，将在后续版本中改进：

| 限制 | 影响 | 计划版本 |
| --- | --- | --- |
| 只支持 macOS | Windows/Linux 用户无法使用 | V1.1/V1.2 |
| 只有 OpenAI 适配器 | 其他厂商模型无法使用 | V1.1 |
| 没有无限画布 | 核心价值功能缺失 | V1.1-V1.3 |
| 没有应用市场 | 第三方模块无法分发 | V1.4-V1.5 |
| 没有云端账号 | 无法跨设备同步 | V2.0 |
| 没有实时协同编辑 | 团队协作受限 | V2.0 |
| 权限模型粗粒度 | 无法细粒度控制 | V2.0 |
