# V4 云端与协同：版本规划

> 状态：规划中。尚未通过[版本进入开发门禁](../版本进入开发门禁.md)，不分配正式功能编号，不代表任何实现状态。版本顺序和边界以[版本路线图](../版本路线图.md)为准；跨版本能力增量以[功能演进矩阵](../功能演进矩阵.md)为准。

## 版本目标

提供云端增强和实时协同。云端功能为可选增强，不改变本地优先原则。

历史文档中的 V2.0 云端账号、官方 Provider、同步、实时协同和细粒度数据权限计划对应本版本。

## 交付范围

- 账号系统：注册、登录、个人资料。
- 官方 Provider（积分制，按 token/张/秒计费）。
- 选择性跨设备数据同步。
- 画布与工作流实时协同编辑，包括指针显示、编辑锁和 CRDT/OT 冲突解决。
- 充值支付、用量统计和账单。

## 依赖与进入条件

- V2 画布和 V3 应用市场必须稳定。
- 本地功能不稳定会导致同步冲突频繁。
