# V8 开发者生态：版本规划

> 状态：规划中。尚未通过[版本进入开发门禁](../版本进入开发门禁.md)，不分配正式功能编号，不代表任何实现状态。版本顺序和边界以[版本路线图](../版本路线图.md)为准；跨版本能力增量以[功能演进矩阵](../功能演进矩阵.md)为准。

## 版本目标

完善开发者生态。

## 交付范围

- 开发者门户、文档中心、API 市场、SDK 和示例库。

## 能力演进

| 能力主线 | 本版本增量 | 依赖 | 完成判定 |
| --- | --- | --- | --- |
| 模块系统 | 官方 TypeScript/Rust SDK、开发模板、CLI 工具（dgos-cli）、文档和示例、自动化测试工具 | V3 应用市场稳定 | 开发者可使用 SDK 快速开发模块 |
| 应用生态 | API 市场（开发者发布 API）、组件市场（UI 组件、节点类型）、SDK 市场（开发工具）、模板市场（项目模板） | V3 应用市场成熟 | API、组件、SDK、模板市场全部可用 |

## 依赖与进入条件

- V3 应用市场和 V4 云端必须稳定。
- 市场或云端不稳定会影响生态建设。

## 预计周期

V8（持续）（路线图估算，未排期）。
