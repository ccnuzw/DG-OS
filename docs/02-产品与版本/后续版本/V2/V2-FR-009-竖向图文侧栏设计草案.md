# V2-FR-009：竖向图文侧栏设计草案

> 状态：历史设计输入，2026-11-08用户已批准实施。下文保留评审时的方案与候选值；现行侧栏规则唯一见[FR-009主规格尺寸基线](../../../03-功能规格/V2/03-产品设计/09-产品设计与UI改版.md#阶段1最终渲染基线与响应式推荐)，实现与验证证据仅见[V1实现状态](../../当前版本/V1-实现状态.md#2026-11-08-竖向图文主侧栏)。本稿不再作为施工或实现状态依据。

## 1. 设计方向

将现有横向图文列表改成窄幅、居中、图标在上文字在下的主导航。沿用 DGOS 的中性表面、轻量边界、当前主题强调色、统一线性图标和用户界面字体。

从参考图采纳竖向图文、集中选中态、清晰留白和稳定品牌位置。参考中的荧光绿、Z 标识、项目/资产/社区等功能名称不作为本项目要求；不引入新业务入口。

范围仅为全局侧栏及其空间预算。工作区标签、页面内容、设置浮层、应用启动台和局部导航继续使用既有模型。

## 2. 现状与依据

- 当前主栏 100% 布局缩放基准为展开 188px、收起 54px，来自 `src/ui/tokens/geometry.css`；主壳空间预算也使用展开栏宽。
- 当前常驻导航为桌面总览、AI 会话、技能中心、MCP 管理、应用，底部为设置、账户和收起控制；固定应用最多 3 个。
- 默认外观为 Studio；五套明暗主题、用户颜色覆盖、界面字体/字号、60～150 的十档布局缩放都需要继续生效。
- 现有导航使用工作区标签与应用单实例模型；设置和启动台是特殊浮层，不能按普通页面处理。

## 3. 导航结构

按现有功能顺序组织，避免同时改变用户的空间记忆与功能归属。

| 区域 | 可见内容 | 设计处理 |
| --- | --- | --- |
| 顶部品牌 | 当前 D 品牌标识 | 居中，沿用品牌标识；去掉窄栏无法容纳的“我的工作空间”长标题，不给标识新增点击行为 |
| 常用入口 | 桌面、AI 会话 | 图标在上、短标签在下；“桌面”对应原“桌面总览”，完整名称用于辅助描述 |
| 资源入口 | 技能中心、MCP | 保持技能在 MCP 上方；MCP 完整名称仍为“MCP 管理” |
| 应用入口 | 应用、用户固定应用 | 应用仍打开启动台；固定项来自真实目录，最多 3 个，保留用户排序 |
| 底部操作 | 设置、账户、收起/展开 | 固定可达；设置保留文字，账户以头像为主并提供完整名称，收起控制用中性幽灵按钮 |

隐藏“概览 / 资源 / 应用”分组标题的可见文字，用适量间距保持分组；保留可访问的分组名称。应用区已有“应用”入口，不再重复显示同名标题。

不新增项目、资产、社区、快捷生成等入口；单任务和 CLI Agent 不因本轮视觉调整新增一级导航。

## 4. 几何候选

以下为 100% 布局缩放、默认界面字号下的原型起点，不是最终冻结尺寸。

| 对象 | 建议基线 | 约束 |
| --- | --- | --- |
| 默认图文栏 | 88px | 替代现有宽图文栏；按内容与缩放有界调整，不将所有尺寸机械等比放大 |
| 纯图标栏 | 56px | 保留手动收起与空间不足时自动收起；不新增第三种常驻导航模式 |
| 顶部品牌容器 | 约 32px | 服从现有圆角与主题令牌，不引入新 Logo |
| 导航图标 | 22px | 使用现有图标源、统一笔画与光学对齐 |
| 图标选中底板 | 约 44 × 36px | 图标与文字属于同一个点击目标，底板不是独立按钮 |
| 单项点击区域 | 约 72 × 68px | 最小交互区域 44 × 44px；字号增大时自然增高 |
| 图文间距 | 4px | 标签居中，使用界面字号角色，默认目标约 12px |
| 同组间距 / 组间距 | 4px / 12px | 使用最接近的既有间距令牌，原型中校准 |
| 右边界 | 1px | 细线保持固定，不随布局缩放变粗 |

88px 相对现有 188px 基准可以释放约 100px 主工作区宽度。最终栏宽由真实中英文标签、大字号和缩放验证确定，不能以缩小用户字体来强行保持 88px。

固定短标签优先单行。动态应用名可用两行，超长再截断；鼠标悬停、键盘聚焦可查看完整名称，应用操作菜单也展示完整名称。纯图标模式所有入口提供可访问名称与提示。

## 5. 视觉语言

颜色继续由当前主题内核派生，侧栏组件不硬编码色值。Studio 当前种子仅作为设计对照：浅色背景 `#f8f6ef`、文字 `#29323d`、强调 `#a46a24`；深色背景 `#242521`、文字 `#eae9e2`、强调 `#ddb576`。这些种子不是侧栏最终派生表面的固定值。

| 角色 | 复用方式 |
| --- | --- |
| 侧栏表面 | `--surface-rail`，继续适配实色/柔化偏好 |
| 普通文字与图标 | `--text-secondary`；悬停提升至 `--text-primary` |
| 选中图标底板 | `--surface-selected`，以当前主题强调色描绘图标 |
| 选中文字 | `--text-primary` 与适度字重变化，避免仅凭颜色识别 |
| 悬停 / 键盘焦点 | `--surface-hover` / `--border-focus`，焦点与选中态可以同时辨认 |
| 边界 / 圆角 | 复用 `--border-subtle` 与现有 radius 令牌 |

图标造型沿用项目现有体系。本轮建议弱化普通导航图标的分类彩底，让当前选中项成为主要视觉重心；系统真实状态色仍用于真实状态，不把分类装饰表现为错误或运行提示。

选中项采用“图标底板 + 加重标签”的组合，替代当前整行底色和左侧竖条的重复强调。不要使用参考图的荧光绿，不增加大面积渐变、投影或悬浮卡片。底部收起按钮移除当前渐变视觉，降低辅助操作权重。

## 6. 交互与边界

### 6.1 导航状态

- 图标与标签共同形成完整点击区域。重复点击工作面入口仍聚焦原有工作区标签，不创建重复标签或实例。
- 当前页面选中态、键盘焦点和弹层展开态分别表达。
- “应用”是打开启动台的动作，打开时表达展开状态，不伪装成路由页面；关闭后恢复背景页面选中态。
- 设置打开时突出设置入口，背景工作面保留上下文；关闭后恢复原入口选中态和焦点。
- Tab 顺序与视觉顺序一致。页面链接使用链接语义，启动台和收起等动作用按钮语义；不把主导航误设为工作区 Tab 控件。
- 动效沿用项目现有快速过渡与减少动效偏好，不引入导航宽度弹跳或额外动画库。

### 6.2 收起与空间不足

- 原展开状态对应新图文栏，原手动收起状态对应纯图标栏；复用现有 `sidebarCollapsed` 偏好，不新增宽栏/窄栏/迷你栏三态设置。
- 自动收起继续只由可用内容预算决定，不写用户偏好；宽度恢复后回到用户选择。
- 空间预算使用假设图文栏展开后的尺寸，避免收起和展开来回抖动。
- 字号增大先允许标签与单项增高，必要时在有界范围内加宽；内容空间不足再进入纯图标模式，不能缩小用户字号。
- 品牌区和底部操作区固定，中间导航独立纵向滚动；600px 高窗口、3 个固定应用和最大字号下末项仍可达，滚动项焦点不被底部遮挡。
- 专注模式和 full-bleed 应用继续遵循原有隐藏主栏规则；本次不改变应用生命周期。

### 6.3 固定应用

保留从启动台拖入固定、拖动排序、菜单取消固定和前后移动。窄栏中不沿用覆盖在图标上的 16px 微型操作按钮：菜单触发器使用可点击的独立区域，可在悬停或焦点进入时显露，但必须始终可被键盘发现；触控提供可达的菜单触发入口。选中、应用操作和拖拽目标不得互相遮挡。

## 7. 实施顺序与影响范围

1. 先用真实主壳做视觉原型，覆盖浅色/深色、图文/图标、完整导航与固定应用；验证 88px 候选和选中底板。
2. 方案确认后将最终尺寸和交互集中回写 FR-009 尺寸基线、外观分篇的辅助列预算及直接受影响的验收条目，再实施代码。
3. 集中验证导航、主题、缩放和窗口边界，通过后在现有实现状态文档记录证据。本稿保持设计工作稿身份，不兼作实现状态。

主要实现落点：

- `src/workspace/AppShell.tsx`：图文布局、分组语义、浮层状态和应用操作入口。
- `src/workspace/shell.css`：几何、选中/悬停/焦点、滚动区和底部布局。
- `src/workspace/navigation.tsx` 与中英文导航翻译：仅在需要独立短标签时补充显示映射，不替换页面完整标题。
- `src/ui/tokens/geometry.css`、`src/ui/layout/layoutBudgets.ts`：主栏尺寸与自动收起空间预算同步。
- `src/App.tsx`、`src/accounts/AccountMenu.tsx`：按实际需要适配浮层展开状态和账户呈现，保留原工作区与账户行为。

原则上不引入新依赖、宿主命令、数据库字段或偏好迁移。已有布尔收起偏好可映射新布局。

## 8. 后续验证清单

本轮仅完成设计规划，以下为实施后的验证要求，尚未执行：

- 1440×900、1280×800、800×600 下，侧栏、顶部标签和内容区不重叠；全部导航及底部操作可达。
- 五套主题的浅色/深色及自定义强调色生效；柔化、减少动效偏好继续生效。
- 十档布局缩放、12px 与 20px 界面字号、中英文和长应用名；文字不被裁切、不靠减小字号适配。
- 导航重复打开聚焦既有标签；切换不丢草稿或运行状态；设置/启动台关闭恢复正确上下文。
- 固定应用 0～3 个、拖放排序、键盘菜单与取消固定；满额反馈维持现有语义。
- 自动收起不覆盖用户偏好，连续缩放不抖动；专注和 full-bleed 隐藏/恢复保持一致。
- 鼠标、键盘与可达菜单入口，焦点可见；提示完整名称，选中不只依赖颜色。

原型方向建议采用本稿的竖向图文栏；88px 栏宽、图标选中底板强度和普通图标去彩底属于待视觉评审的候选值。
