# V3 应用市场：版本规划

> 状态：规划中。尚未通过[版本进入开发门禁](../版本进入开发门禁.md)，不分配正式功能编号，不代表任何实现状态。版本顺序和边界以[版本路线图](../版本路线图.md)为准；跨版本能力增量以[功能演进矩阵](../功能演进矩阵.md)为准。

## 版本目标

建立应用模块生态，让第三方开发者发布模块。

历史文档中的 V1.5 应用市场计划对应本版本。

## 交付范围

- 应用浏览：分类、搜索、筛选；应用详情含截图、描述、评分和评论。
- 从市场安装、更新（自动推送、手动确认）和卸载应用。
- 开发者提交表单、资料和截图；人工审核队列与审核标准。
- 版本管理（多版本共存、回滚）、评分评论系统和下载统计。

## 能力演进

| 能力主线 | 本版本增量 | 依赖 | 完成判定 |
| --- | --- | --- | --- |
| 模块系统 | 应用浏览、详情、安装、更新推送、卸载；开发者提交、人工审核、版本管理 | V1 模块系统稳定 | 可从市场安装至少 1 个第三方模块，评分评论系统正常 |
| 应用生态 | 分类、搜索、筛选；详情、安装、更新、卸载；开发者提交、人工审核、版本管理；评分评论、下载统计；中心化（官方服务器）、人工审核、全部免费 | V1 模块系统稳定 | 至少 10 个第三方应用，安装成功率 > 99%，更新成功率 > 98%，审核周期 < 3 天 |

## 依赖与进入条件

- V1 模块系统必须稳定。
- 模块加载不稳定会导致应用市场不可用。

## 明确不包含 / 边界说明

- 市场采用中心化（官方服务器）模式，必须登录云端账号。
- V3 采用人工审核；自动化检查在 V4+。
- V3 全部免费；付费能力在 V4+。
- 应用市场作为一个完整版本交付，不拆分子版本。
