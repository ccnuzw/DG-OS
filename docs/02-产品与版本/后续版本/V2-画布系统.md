# V2 画布系统：版本规划

> 状态：规划中。尚未通过[版本进入开发门禁](../版本进入开发门禁.md)，不分配正式功能编号，不代表任何实现状态。版本顺序和边界以[版本路线图](../版本路线图.md)为准；跨版本能力增量以[功能演进矩阵](../功能演进矩阵.md)为准。

## 版本目标

提供无限画布核心能力。画布是 DGOS 的核心价值功能，V2 以完整画布系统交付。

历史文档中的 V1.2–V1.5 画布计划对应本版本。

## 交付范围

- 画布视口：缩放、拖拽、平移。
- 完整节点类型（10+ 种），包括 Image、Prompt、LLM、Generator、Loop、Conditional、Transform、Function 等；LLM 节点可选择 Skills。
- 节点连线、实时执行、循环节点。
- 工作流 JSON 格式定义、导入导出、自动排版和模板库。

## 能力演进

| 能力主线 | 本版本增量 | 依赖 | 完成判定 |
| --- | --- | --- | --- |
| Skills 能力 | LLM 节点可选择 Skills；Skill 处理 Prompt 后再调用 LLM，或对 LLM 结果后处理；显示 Skills 处理进度 | V2 画布系统、V1 Skills 管理 | LLM 节点可选择 Skills，Skills 增强生成效果可见 |
| 设计系统 | 画布组件 | — | — |
| 无限画布 | 视口缩放、拖拽、平移；完整节点类型；连线、实时执行、错误处理、工作流导入导出、模板库 | V1 模块系统稳定 | 10 种节点可用，循环节点正常，实时执行及时，可保存加载，至少 3 个模板，交互流畅（60fps） |

## 依赖与进入条件

- V1 必须稳定，且模块系统验证通过。
- 模块系统不稳定会导致画布无法独立开发。

## 明确不包含 / 边界说明

- 画布系统作为一个完整版本交付，不拆分子版本；内部可以分阶段开发。
- 可选兼容老项目工作流格式以便用户迁移；不复制老项目单体架构或耦合设计，画布应为独立模块。
