# V7 AI Agent：版本规划

> 状态：规划中。尚未通过[版本进入开发门禁](../版本进入开发门禁.md)，不分配正式功能编号，不代表任何实现状态。版本顺序和边界以[版本路线图](../版本路线图.md)为准；跨版本能力增量以[功能演进矩阵](../功能演进矩阵.md)为准。

## 版本目标

提供 AI Agent 能力，包括自主任务执行、多 Agent 协作和工作流自动化。

## 交付范围

- 自主任务执行、多 Agent 协作、工作流自动化。
- 编程项目工作台：以 Codex 与 Claude Code 完成项目管理、代码修改、运行验证、变更审查和持续维护；优先方案见[编程项目工作台草案](V7-编程项目工作台方案草案.md)。Provider、Skills、MCP 按开发闭环需要同步完善；应用与模块接入方向保留。此项为方案讨论，不代表实现或正式契约已冻结。
- 绘画任务助手：按 [D132](../../06-决策记录/V7-冻结决策.md#d132-绘画agent的批次授权资料范围与作品归属) 提供受控实际生成；资料按任务授权，作品归属项目，版本与会话解耦。该项为已确认产品边界、待实现，不能作为当前绘画功能行为。

## 分阶段推进

下列阶段用于组织推进，不变更全局版本顺序或 V7 门禁。阶段一、二沿 D127 独立技术任务执行；业务集成和编排需各自满足进入条件。

| 阶段 | 任务 | 目标完成条件 |
| --- | --- | --- |
| 一：独立会话体验收口 | 两家完整工作区创建、发送、审批、中断、恢复与关闭；真实鼠标/键盘、焦点与辅助技术检查；修复阻断使用的问题 | 两家真实完整任务路径与关键失败恢复有证据，未覆盖的辅助技术范围明确 |
| 二：CLI与原生扩展兼容 | Claude完整桌面扩展路径；Skill/MCP/Hook/插件组合；同目录同配置的独立CLI对照；首轮与辅助模型定位 | 明确支持版本、通过组合与限制；未解决问题不伪装成功 |
| 三：安装与分发 | 资源打包、CLI发现与诊断、干净用户环境、签名公证、目标平台及第三方认证额度约束 | 无开发目录依赖，安装后运行、退出、恢复闭环通过；跨平台分别验证 |
| 四：绘画业务集成 | 依D132补技术设计，完成需求→方案确认→生成→项目保存→版本迭代 | 真实获准能力端到端执行，失败、部分成功、取消及资产归属可追踪 |
| 五：任务编排与多Agent | 先单Agent多步骤、依赖、确认点、失败恢复、预算并发，再多Agent与画布工作流 | 满足V7门禁与依赖，单Agent稳定后证明多Agent协作收益 |

当前讨论优先级（2026-11-04）：独立 CLI 接入与本机分发已有分层证据后，优先推进[编程项目工作台方案](V7-编程项目工作台方案草案.md)，再开展内部应用与模块的具体业务集成。上表阶段四绘画边界保留、暂不优先推进；签名公证、跨平台及兼容性剩余项仍独立跟踪。新增编程能力目前处于草案讨论，实施前须明确独立技术任务范围与授权，不提升 V7 整体门禁。


## 能力演进

| 能力主线 | 本版本增量 | 依赖 | 完成判定 |
| --- | --- | --- | --- |
| Skills 能力 | Agent 自动发现可用 Skills；按任务自动选择 Skills；链式调用多个 Skills | V7 AI Agent 系统 | Agent 可自动选择和调用 Skills |
| MCP 能力 | Agent 集成 | — | — |
| AI 工作台 | Agent | — | — |
| 无限画布 | Agent 根据任务自动生成工作流、自动执行，并自动调试和修复工作流 | V7 AI Agent 系统、V2 画布稳定 | Agent 可自动生成并执行工作流 |

## 依赖与进入条件

- V2 画布和 V4 云端必须稳定。
- 画布或云端不稳定会影响 Agent 执行。

## 预计周期

V7（4个月）（路线图估算，未排期）。
