# V7 AI Agent：版本规划

> 状态：规划中。尚未通过[版本进入开发门禁](../版本进入开发门禁.md)，不分配正式功能编号，不代表任何实现状态。版本顺序和边界以[版本路线图](../版本路线图.md)为准；跨版本能力增量以[功能演进矩阵](../功能演进矩阵.md)为准。

## 版本目标

提供 AI Agent 能力，包括自主任务执行、多 Agent 协作和工作流自动化。

## 交付范围

- 自主任务执行、多 Agent 协作、工作流自动化。

## 能力演进

| 能力主线 | 本版本增量 | 依赖 | 完成判定 |
| --- | --- | --- | --- |
| Skills 能力 | Agent 自动发现可用 Skills；按任务自动选择 Skills；链式调用多个 Skills | V7 AI Agent 系统 | Agent 可自动选择和调用 Skills |
| MCP 能力 | Agent 集成 | — | — |
| AI 工作台 | Agent | — | — |
| 无限画布 | Agent 根据任务自动生成工作流、自动执行，并自动调试和修复工作流 | V7 AI Agent 系统、V2 画布稳定 | Agent 可自动生成并执行工作流 |

## 依赖与进入条件

- V2 画布和 V4 云端必须稳定。
- 画布或云端不稳定会影响 Agent 执行。

## 预计周期

V7（4个月）（路线图估算，未排期）。
