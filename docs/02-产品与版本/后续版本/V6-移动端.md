# V6 移动端：版本规划

> 状态：规划中。尚未通过[版本进入开发门禁](../版本进入开发门禁.md)，不分配正式功能编号，不代表任何实现状态。版本顺序和边界以[版本路线图](../版本路线图.md)为准；跨版本能力增量以[功能演进矩阵](../功能演进矩阵.md)为准。

## 版本目标

将 DGOS 扩展到移动平台，交付 iOS 和 Android 应用。

历史文档中的 V3.0+ 移动端计划对应本版本。

## 交付范围

- iOS 应用（Swift/SwiftUI）和 Android 应用（Kotlin/Jetpack Compose）。
- 移动端 UI 适配、触摸手势优化、离线同步和推送通知。

## 依赖与进入条件

- V4 云端同步必须稳定，否则移动端数据无法同步。
