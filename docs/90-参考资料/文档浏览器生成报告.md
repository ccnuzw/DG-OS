| 文件 | 内容 |
| --- | --- |
| `产品文档浏览器.html` | 界面与脚本；内嵌 `DOCS`（66 份文档的元数据）、`DECISIONS`（D001–D040，40 条）、`FEATURE_TRACKS`（10 条能力主线）、`FEATURE_TIMELINE_VERSIONS`（V1、V1 门禁、V2–V8、后续）和 5 个 SVG 渲染函数 |

| `产品文档浏览器-单文件版.html` | 与 `产品文档浏览器.html` 相同的界面和脚本，把数据 JS 内联，可单独拷贝打开 |

### 数据来源

- **DOCS**：`docs/` 下全部 Markdown（不含隐藏文件）。`title` 取一级标题，归档文件加“历史：”前缀；`goal` 取首段（功能规格取 §2.1，版本规划取“版本目标”，归档文件取开头的历史说明），少数导航页使用固定说明。已发布条目的 `id` 按文件路径保留，移入归档的文件沿用原 `id`。
- **DECISIONS**：[V1 冻结决策](../06-决策记录/V1-冻结决策.md) 的各级 `## Dxxx` 标题；D003/D005 标注“Skills 部分由 D016 取代”。
- **功能数据**：`goal` 取各功能主文档 §2.1，`dependencies` 取元信息“依赖功能/依赖”行；`implementation` 逐字取自 [V1 实现状态](../02-产品与版本/当前版本/V1-实现状态.md) 第 3 节的状态与备注列，浏览器只展示、不推断状态。
- **时间线**：解析[功能演进矩阵](../02-产品与版本/功能演进矩阵.md)各能力主线详表；没有详表的能力（MCP、设计系统、工作台、系统设置、权限、局域网）按第 2 节“能力主线列表”的版本列生成“总览关联”条目。

### 生成方式

生成器是 `scripts/generate-doc-browser.mjs`（`npm run docs:browser` 生成，`npm run docs:browser:check` 检查产物是否过期）。`generate_browser_data.py` 只打印统计不写文件，`docs/.browser-config.json` 内容过期（全部功能“规划中”、版本 v1.1–v1.5）且未被浏览器读取；两者都不是当前产物的生成器。
