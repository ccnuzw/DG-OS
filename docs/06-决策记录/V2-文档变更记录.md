# V2 文档变更记录

记录 V2（画布系统）文档中影响实现输入与验收口径的变化（D100）。2026-11-01 之前的 V2 相关变更记在 [V1 文档变更记录](V1-文档变更记录.md)。

## 2026-11-03：V2-FR-010 图片生成与图片输入能力规格

- **新建**：[V2-FR-010 功能主文档](../03-功能规格/V2/01-底层能力/10-图片能力.md) 与[高风险技术设计](../03-功能规格/V2/01-底层能力/10-图片能力-技术设计.md)。
- **范围**：Provider 图片生成、LLM 图片输入、内容寻址资产引用、`providers.image_generate` 模块能力、超时/取消/未知结果、请求去重和脱敏审计；明确不做 Generator 图生图和图片生成 CLI。
- **状态**：规格为 Draft；V2 实现状态保持“规划中”，没有修改代码、migration、错误数字码或运行时契约。
- **静态核验**：确认现有 Provider 已有 `image-generation` 模型分类和视觉能力提示，但 `ProviderAdapter` 尚无图片生成接口，`ChatMessage` 尚不能承载图片内容；这些差距已写入功能规格。

## 2026-11-03：D125 画布本地创作平台入口

- **决策**：新增 [D125](V2-冻结决策.md#d125-画布应用入口本地创作平台首页--全屏编辑器)。画布应用先显示本地创作平台首页（全部项目、最近/回收站、项目卡片、新建/打开），再由项目进入全屏无限画布；编辑器隐藏主导航和平台首页，只保留左上角返回；云端/共享/协作不在本次范围。

- **原型**：新增本地创作平台首页、项目卡片/新建项目和全屏画布占位；画布标签与全屏返回已验证。
- **边界**：项目/资产隔离、共享协作和真实画布引擎不在原型/当前 V2 承诺内；不新增宿主接口或 migration。
