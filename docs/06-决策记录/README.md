# 决策记录导航

- [V1 冻结决策](V1-冻结决策.md)：当前版本的跨功能产品和工程决策。
- [V1 文档变更记录](V1-文档变更记录.md)：影响实现输入和验收口径的文档变化。
- [架构决策记录索引](ADR/README.md)：具有长期架构影响的选择、备选方案和后果。

普通实现状态不写入本目录，应更新[当前版本实现状态](../02-产品与版本/当前版本/V1-实现状态.md)。

## 决策类型说明

- **冻结决策**：影响多个功能或模块的产品和技术决策，一旦冻结需要通过变更流程修改
- **架构决策记录（ADR）**：具有长期影响的架构选择，采用 ADR 格式记录
- **文档变更记录**：追踪文档的重大变更，便于理解需求演进

## 查找决策

- 按编号查找：[V1 冻结决策](V1-冻结决策.md) 中的 D001-D015
- 按主题查找：使用 `rg "关键词" docs/06-决策记录`
- 按时间查找：查看 [V1 文档变更记录](V1-文档变更记录.md)
