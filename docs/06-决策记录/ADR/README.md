# 架构决策记录（ADR）索引

本目录存放有长期架构影响、需要完整记录备选方案和后果的决策，文件名格式为 `NNNN-主题.md`（例如 `0001-模块执行隔离边界.md`），编号一经分配不改变、不复用。

目前有 ADR-0001、ADR-0002。V1 的其余跨功能产品与工程决策记录在 [V1 冻结决策](../V1-冻结决策.md)（D001 起）中；冻结决策与 ADR 冲突时，以冻结决策为准（见[文档中心](../../README.md#文档权威性)）。

## 何时写 ADR

- 决策会跨多个版本生效，例如执行隔离方式、同步协议、存储引擎更换
- 需要并列比较多个备选方案，并长期保留取舍理由
- 冻结决策条目放不下完整的背景、方案对比和后果分析

ADR 结构可参考 spec-docs-pro skill 的 `templates/adr.md`：元信息、背景、决策、备选方案、后果、遵守规则、审批。
