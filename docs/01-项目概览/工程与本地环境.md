# 工程与本地环境

本文档说明 DGOS 项目的环境要求、本地开发环境搭建、项目结构和常用开发命令。

---

## 1. 环境要求

### 1.1 必需环境

| 工具 | 版本要求 | 说明 |
|------|---------|------|
| **Rust** | 1.75+ | 后端开发语言 |
| **Node.js** | 18+ | 前端构建工具 |
| **pnpm** | 8+ | 前端包管理器 |
| **操作系统** | macOS 12+ | V1.0 仅支持 macOS |

### 1.2 可选环境

| 工具 | 版本要求 | 用途 |
|------|---------|------|
| **Python** | 3.10+ | Skills 开发（可选） |
| **Docker** | 20+ | 容器化测试（可选） |
| **Git** | 2.30+ | 版本控制 |

### 1.3 推荐工具

- **IDE**: VS Code + Rust Analyzer
- **终端**: iTerm2 / Warp
- **Git 客户端**: GitHub Desktop / Tower

## 2. 本地开发环境搭建

### 2.1 安装 Rust

```bash
# 安装 Rust 工具链
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 验证安装
rustc --version
cargo --version
```

### 2.2 安装 Node.js 和 pnpm

```bash
# 使用 Homebrew 安装 Node.js
brew install node

# 安装 pnpm
npm install -g pnpm

# 验证安装
node --version
pnpm --version
```

### 2.3 克隆项目

```bash
# 克隆仓库
git clone https://github.com/your-org/DG-OS.git
cd DG-OS
```

### 2.4 安装依赖

```bash
# 安装后端依赖
cd server
cargo build

# 安装前端依赖
cd ../frontend
pnpm install
```

### 2.5 初始化数据库

```bash
# 运行数据库迁移
cd server
cargo run --bin migrate
```

### 2.6 启动开发环境

```bash
# 启动 Tauri 开发环境（会同时启动前端和后端）
cd frontend
pnpm tauri dev
```

应用会自动打开，默认监听：
- **前端开发服务器**: `http://localhost:5173`
- **后端 API**: `http://localhost:3000`

## 3. 项目结构

```

│   ├── crates/            # 功能模块

│   ├── migrations/        # 数据库迁移

│
├── frontend/              # React 前端
│   ├── src/
│   │   ├── components/   # 通用组件
│   │   ├── modules/      # 业务模块
│   │   ├── pages/        # 页面
│   │   └── ui/           # 设计系统组件
│   ├── public/           # 静态资源
│   └── package.json      # Node.js 项目配置
│
├── docs/                  # 项目文档
│   ├── 01-项目概览/
│   ├── 02-产品与版本/
│   ├── 03-功能规格/
│   ├── 04-技术架构/
│   └── 06-决策记录/
│
└── README.md             # 项目入口文档
```

### 3.1 后端模块说明

| 模块 | 说明 | 主要文件 |
|------|------|---------|
| `providers` | Provider 适配框架 | `adapters/openai.rs` |
| `skills` | Skills 管理系统 | `manager.rs`, `registry.rs` |
| `mcp` | MCP 管理系统 | `client.rs`, `connection.rs` |
| `modules` | 模块系统与热更新 | `loader.rs`, `registry.rs` |

| 目录 | 说明 |
|------|------|
| `src/components/` | 通用 UI 组件（Button、Input 等） |
| `src/modules/` | 业务模块（AI 工作台、系统设置等） |
| `src/pages/` | 页面路由 |
| `src/ui/` | 设计系统组件库 |

## 4. 常用开发命令

### 4.1 后端开发

```bash
# 编译
cd server
cargo build

# 运行（开发模式）
cargo run

# 运行测试
cargo test

# 运行特定包的测试
cargo test -p dgos-providers

# 代码检查
cargo clippy

# 格式化代码
cargo fmt

# 清理构建产物
cargo clean
```

### 4.2 前端开发

```bash
cd frontend

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 运行测试
pnpm test

# 运行 E2E 测试
pnpm test:e2e

# 代码检查
pnpm lint

# 格式化代码
pnpm format

# 类型检查
pnpm type-check
```

### 4.3 Tauri 开发

```bash
cd frontend

# 启动 Tauri 开发环境
pnpm tauri dev

# 构建桌面应用
pnpm tauri build

# 查看 Tauri 信息
pnpm tauri info
```

### 4.4 数据库操作

```bash
cd server

# 创建新迁移
cargo run --bin migrate create <migration_name>

# 运行所有迁移
cargo run --bin migrate up

# 回滚最后一次迁移
cargo run --bin migrate down

# 查看迁移状态
cargo run --bin migrate status
```

## 5. 开发工作流

### 5.1 功能开发流程

1. **创建分支**
   ```bash
   git checkout -b feature/provider-retry
   ```

2. **开发功能**
   - 后端：在对应 crate 中开发
   - 前端：在对应 module 中开发
   - 测试：编写单元测试和集成测试

3. **运行测试**
   ```bash
   # 后端测试
   cd server && cargo test
   
   # 前端测试
   cd frontend && pnpm test
   ```

4. **提交代码**
   ```bash
   git add .
   git commit -m "feat: add provider retry mechanism"
   ```

5. **推送并创建 PR**
   ```bash
   git push origin feature/provider-retry
   # 然后在 GitHub 创建 Pull Request
   ```

### 5.2 调试技巧

#### 后端调试

```bash
# 启用详细日志
RUST_LOG=debug cargo run

# 使用 rust-lldb 调试
rust-lldb target/debug/dgos
```

#### 前端调试

- 使用 Chrome DevTools
- React Developer Tools 扩展
- 查看 Network 面板的 API 请求

```bash
# 打开开发者工具

# 查看 Tauri 日志：查看终端输出
```

## 6. 常见问题

### 6.1 Rust 编译失败

**问题**：`cargo build` 失败

**解决**：
```bash
# 更新 Rust 工具链
rustup update

# 清理并重新编译
cargo clean
cargo build
```

### 6.2 前端依赖安装失败

**问题**：`pnpm install` 失败

**解决**：
```bash
# 清理缓存
rm -rf node_modules
pnpm store prune

# 重新安装
pnpm install
```

### 6.3 Tauri 启动失败

**问题**：`pnpm tauri dev` 失败

**解决**：
```bash
# 检查 Xcode Command Line Tools
xcode-select --install

# 检查 Rust 目标
rustup target add x86_64-apple-darwin
```

### 6.4 数据库迁移失败

**问题**：迁移运行失败

**解决**：
```bash
# 删除数据库文件（仅开发环境）
rm ~/.dgos/data.db

# 重新运行迁移
cd server && cargo run --bin migrate up
```

## 7. 性能优化

### 7.1 Rust 编译优化

在 `Cargo.toml` 中配置：

```toml
[profile.dev]
opt-level = 1        # 轻度优化，加快编译

[profile.release]
opt-level = 3        # 完全优化
lto = true          # 链接时优化
codegen-units = 1   # 更好的优化
```

### 7.2 前端构建优化

```bash
# 使用生产模式构建
pnpm build

# 分析构建产物
pnpm build --analyze
```

### 8.1 代码规范

详见 [Git 提交信息规范](Git提交信息规范.md)
