对应 [V2-FR-009 产品设计草案](../../docs/03-功能规格/V2/03-产品设计/09-产品设计与UI改版.md)。本目录是独立设计资产，不进入生产应用构建；无宿主调用、真实模型请求、安装、数据库或凭据存储。全部资源本地加载，刷新重置演示状态。

## 打开

直接打开 [index.html](index.html)，即可评审主窗口浮层与页面流程。进入“设置 → 外观与语言”体验完整主题编辑器。

最终渲染与源码初值不同，生产迁移取值见[FR-009阶段1基线](../../docs/03-功能规格/V2/03-产品设计/09-产品设计与UI改版.md#阶段1最终渲染基线与响应式推荐)，契约/差距见[整体方案§9～§12](../../docs/02-产品与版本/后续版本/V2/V2-FR-009-整体迁移方案与现状评审.md#9-阶段1交付页面与交互迁移矩阵)。本README仅说明设计资产，不是生产数值权威。在仓库根目录启动：

```sh
python3 -m http.server 4179 --bind 127.0.0.1 --directory prototypes/product-design
```

打开 `http://127.0.0.1:4179/`。生产目标按D119/D120默认桌面、AI独立工作面、两层标签及主窗口设置浮层。当前原型启动值实际为 `page:'workbench'`，用于会话评审；这是与“默认桌面”旧说明的差异，不改变已冻结的产品首页。可点击桌面入口开始评审。workspace-prototype.js/workspace.css仅叠加演示，不进入生产构建；右下角“评审场景”切换状态。

## 建议评审路线

1. **桌面与会话**：默认查看桌面图标、最近工作和可用能力；“整理桌面”切换入口/看板显隐。进入 AI 会话查看外层工作区标签、AI 会话内多标签和约33px工作区标签；发送后演示完成或离开确认。
2. **技能中心**：打开技能中心标签，切换浏览/我的技能，按官方/旧版、分类和搜索筛选；查看详情、版本、作者、许可与标签。添加官方技能，在“我的技能”启停并进入单任务标签；展开“从来源安装技能”预览 URL 来源；旧版归档只读。关闭技能标签后从左侧重新打开，观察单例标签行为。
3. **MCP 管理**：在技能中心下方打开 MCP 管理标签；切换服务查看状态、工具、最近使用和连接历史；添加/编辑 stdio 或 HTTP 服务，连接/断开与启停；检查工具、填写参数并走审核→确认→结果的演示调用。技能和 MCP 标签在切回 AI 后保留。
4. **设置**：查看模型服务的分类—资源—详情布局；修改名称，尝试关闭或切换分类，再保存或放弃。关闭后检查工作草稿仍在。工具连接页已收敛为摘要和“打开 MCP 管理”兼容入口。
   **CLI 路径**：查看 Codex / Claude Code / Gemini CLI / Node.js 的检测状态与可执行文件路径；点“自动检测”观察检测中状态与结果回填；修改或清空路径验证“留空按 PATH 查找”的提示；自动管理的 CLI 只读。
   **存储**：查看用量条、分类图例与对话/消息/会话文件统计；切换保留期限；对“清理旧对话”“清理会话文件”等项点“清理”后先出现行内确认，确认后数值与用量条按演示数据收敛，并出现“已清理/已优化”标记。
5. **应用与工作区**：从左侧“应用”打开 OS 式悬浮图标网格；点击面板外空白或按 Esc 关闭，面板没有右上角关闭按钮。搜索并打开模型调试台；把“工具连接”图标拖到左侧导航，或聚焦图标按 `P`、触屏长按，观察落点/固定提示和“应用”分组新增项；查看应用标签、最大化/退出专注和关闭标签。应用与扩展中查看三个模块状态，切换全部/已启用/待处理筛选；安装示例模块后模拟更新失败、重试、撤销权限和模拟崩溃。撤销权限、打开应用查看拒绝状态，再授予；停用时固定应用入口消失，启动台中显示降低饱和度的不可用图标。应用运行后关闭应用标签会提示“应用仍在运行”，可选择继续查看或关闭标签。按 `⌘K`/`Ctrl+K` 或标签栏放大镜打开命令面板，搜索应用、资源或动作。标签栏右侧的标签列表按钮可查看、切换和关闭当前打开的标签。
6. **画布创作平台**：从启动台打开“画布”，先进入本地创作平台首页；查看全部项目、最近使用、回收站和项目卡片。新建项目，填写名称后进入全屏画布；确认主导航和平台首页隐藏，只有左上角“← 全部项目”返回；返回后项目出现在列表。把项目移到回收站、恢复、彻底删除，观察空状态；回收站不提供新建入口。编辑器中有未保存标记时关闭画布标签，会先询问“继续编辑/放弃并关闭”。画布标签可关闭，重新打开仍从平台首页开始。
7. **首次使用及失败**：评审面板切换首次使用、连接失败、任务结果未知、登录、启动失败、404；登录演示口令为 `demo`。
8. **局域网**：设置中开启访问、预览远程访问、配对码 `demo`；评审面板返回桌面后，在设置中撤销，再进入远程场景观察重新配对提示。
9. **账户**：切换账户检查草稿清除；查看改密、注销、删除的反馈。改密的当前和新口令均为 `demo`。
10. **显示与作用域**：按下一节评审套装、覆盖、字体和恢复，在800px及最大字号检查布局。当前800px最终渲染的设置分类仍为124px纵列，外观编辑器只有一个底部操作栏；早期“横向分类”说明已撤下。

## 外观主题评审路线

对应 [主题与作用域设计](../../docs/03-功能规格/V2/03-产品设计/外观主题与作用域设计.md)，运行逻辑在 `appearance.js`，样式在 `appearance.css`。

1. 选择暖纸琥珀：主窗口即时显示临时效果；取消预览、按 Esc 或关闭设置后检查恢复。
2. 改强调色，再换套装：覆盖保留，显示“自定义 · 恢复”；点击恢复后继承新套装。
3. “调整区域”切为阅读，单改背景；再切代码，它仍继承操作界面。每个区域支持独立覆盖与恢复。
4. 分别改变界面/内容/代码字体与字号、内容行高和密度；在实际工作区观察消息、代码和控件变化。
5. 编辑深色配置不会改变运行模式；明暗可选不同套装。“跟随系统”响应浏览器/OS 的颜色偏好变化。
6. 输入文字与背景相同的颜色，检查应用被阻止；无效 HEX 有提示。原型只检查区域文字与界面强调色基础配对，不等于完整语义对比度验收。
7. 应用后关闭再打开，值在本次浏览保留；取消、Esc、关闭、切分类均放弃未应用草稿。“恢复默认”菜单支持当前明暗配置或全部外观，仍需应用。

五套候选均有明暗配置，当前默认studio；字体使用本机回退栈，不枚举或安装字体，侧栏柔化只模拟叠色。没有主题导入导出、磁盘持久化或宿主并发同步；远程场景共用原型文档，不证明真实设备偏好隔离。语言控件为中文占位。原型reset-variant仍重置precision，与defaults的studio矛盾；生产按外观分篇统一恢复映射，不复制该差异。

## 设计取值与参考

- 以用户最新的对话与设置截图为视觉输入：暖白底、细边界、蓝色主要操作、淡色图标底、设置分类/资源/详情层次。
- 最终默认studio由appearance.js派生表面与强调色，旧静态precision色值只是早期输入；当前生产tokens描述已实现状态，目标主题规则见外观分篇。
- 系统无衬线字体与中文回退；技术值使用系统等宽。内容左对齐，对话区域限制阅读宽度。
- 设置只采用主窗口浮层，已由用户确定（D119）。
- 最终默认UI变量12px、导航13px、阅读13px、代码变量12px；约28px控件、33px工作区标签、会话内层实际38px。几何/角色和生产14px换算关系只在FR-009/外观分篇维护，不按原型rem原样搬运。
- `compact.css` 明确候选UI与阅读域：界面尺寸跟随rem、内容使用独立字号；1px细边线、视口约束、原始图像和未来画布坐标不按UI同比缩放。正式迁移评估见主规格“尺寸与缩放作用范围”。
- 图标为原型内嵌 SVG；正式图标与组件仍须按 D096 及 `@dgos/ui` 映射。
