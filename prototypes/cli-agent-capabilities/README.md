# CLI Agent Skills / MCP 独立管理设计

> 设计草案，2026-11-10。本轮响应“先进行设计”，不改生产路由、IPC、原生配置或正式冻结决策。可交互原型使用明确标注的演示数据；不联网、不启动 CLI、不写入任何用户配置。本文是本轮唯一设计工作稿，不提升实现状态。

## 1. 设计结论

采用 **CLI Agent 插件抽屉 + Skills 管理器 + MCP 管理器**。运行时归属由入口确定，不让用户在一个共享管理页里来回选择“AI 助手 / CLI Agent”。

- Provider 继续全局共用；不在新抽屉复制一套 Provider 管理。
- CLI Agent 左侧现有工具栏增加“插件”；抽屉先显示 MCP 服务，再显示 Skills。每区有数量、短列表和“管理”。技能只显示名称、用途、来源/状态；不要把目录和诊断长文堆到抽屉。
- 点击管理，打开 CLI Agent 所属的大管理层。保留对话、项目和滚动上下文，关闭回到原触发器；打开或关闭管理器不停止运行中的 CLI。
- 管理器内仅提供 **Codex / Claude Code** 切换，用于管理另一个原生平台；没有 AI 助手选项。默认取当前会话的引擎与实际 workspace，而非全局固定 Codex。
- AI 助手原有 Skills/MCP 页面保留 DG-OS 自己的资源管理，移除 Native 切换和跨运行时菜单。其自身入口整合不在本轮重做。
- 工作区切换、账户切换和引擎切换不串草稿、选择、请求结果或操作回执。

## 2. 打开原型

打开 [index.html](index.html)，或运行：

```sh
python3 -m http.server 4187 --bind 127.0.0.1 --directory prototypes/cli-agent-capabilities
```

访问 `http://127.0.0.1:4187/`。顶栏是评审场景切换，不属于生产 UI。支持 `?scene=drawer`、`skills`、`discover`、`mcp`、`market`、`manual`。

原型覆盖：抽屉入口、列表搜索、范围与平台、Skill 详情与启停、查找与安装预览、仓库添加/刷新/移除、MCP 空态、市场模板→表单→预览→配置、临时测试及工具 Schema 样例、活动会话工具名观测、编辑和移除。所有变更仅在当前页面内存中；刷新重置。

## 4. Skills 管理

### 4.1 已安装

列表显示名称、用途、来源、版本/提交（仅来源可提供时）、范围、配置状态及会话状态。无版本字段不制造 semver。默认过滤当前 workspace；用户级单独查看，并可显示其对当前项目的适用提示。只读插件/内置/链接资源带所有者标记，不给可写开关和卸载按钮。

点击行进入右侧详情：元数据、宿主投影的真实目标路径、来源链接、文件清单、依赖检查、配置规则、活动会话观测和更新/移除。正常路径只显示短状态，限制说明放详情，不常驻塞满主列表。

- Codex 开关绑定精确已发现实例，不按名称匹配一批资源。
- Claude 用“名称规则”，提供继承、显示名称与描述、仅名称、仅用户调用、关闭；说明当前及未来同名范围、插件排除、更高层未求值、可能触发 ConfigChange Hook。不能用统一布尔开关假装单实例启停。
- 只展示被宿主允许的操作。某 CLI 不支持即时刷新则提示“新会话生效”，不悄悄重启已有会话。
- “检查依赖”先做不执行扫描；“检测版本”另预览可执行程序及 argv，显式确认、有界执行。不把 found/unprobed 说成满足依赖。

### 4.2 查找、导入与安装

查找分为 **目录搜索、GitHub 仓库、ZIP/本地目录**。目录由用户显式配置的来源提供；不把 DG-OS 的内容技能市场直接当作 CLI 市场。GitHub 来源限定已支持 HTTPS 语法及受控下载；不假设私有仓库、任意 Git 主机或带 `/` 的 ref 已支持。

标准流程：选择来源 → 获取元数据/扫描多 Skill → 选中 Skill → 目标平台与范围 → 宿主预览 → 确认安装 → 回到已安装，标记待会话加载。

预览必须显示：仓库及子目录、解析后的不可变提交/哈希、实际目标目录、文件/脚本数量、执行位或动态内容提示、同名冲突、依赖声明与生效方式。不运行包内脚本。ZIP/目录选择由宿主生成受信来源句柄，不接受 renderer 任意路径作为权限。原型的文件选择为明确的样例选择，绝不读取本机文件。

更新绑定原来源和当前实例修订；外部修改时停止并提供“保留本地 / 重新预览”，不自动覆盖。移除只作用于目标实例并保留恢复材料，不删另一个范围的同名 Skill，也不声称清除了已有会话上下文。

### 4.3 技能来源

以仓库行为单位显示 URL、ref 提示、技能数、最近索引时间和错误状态；支持添加、手动刷新、移除。保存来源不安装资源；移除来源不卸载已安装 Skill。来源与实际安装的不可变 commit 分开存储。未登录、离线、限流或格式不支持保留已有结果并标“上次结果”，不显示虚假空库。生产不预置原型里的 `acme/*` 演示仓库。

## 5. MCP 管理

### 5.1 已配置与抽屉

已配置列表以服务为单位：名称、传输、精确范围、配置启用、当前会话连接、可核实工具数、需处理问题。统计采用已配置/当前会话已观测/需处理；token 只有在完整工具 Schema 和适用 tokenizer 均可用时显示有来源的估算，不能从工具数量推算固定 1.5k。

条目详情分三层：

1. **配置**：命令/URL、范围、来源、认证方式，仅脱敏白名单字段。
2. **当前会话**：session/generation/观测时间，连接状态、工具名、认证需要、失败/未知。无会话时显示“尚无活动会话”，不为了读取状态启动 CLI。
3. **临时测试**：独立探针的握手结果、工具说明/Schema、时间和配置摘要；明确不是当前 CLI 连接，也不是宿主工具执行审计。

Codex 配置 `enabled` 与 Claude 的原生会话启停不同。Claude 只有在准确版本、会话状态和能力允许时提供“本会话停用/启用/重连”，否则显示实际不可用原因；不写入并不存在的通用 enabled 字段。插件所有的 MCP 跟随插件管理。删除配置不杀外部服务；刷新不自动重放工具操作。

### 5.2 MCP 市场

目标来源为官方 MCP Registry（参考入口：<https://registry.modelcontextprotocol.io/docs>）；本轮仅确认该官方文档入口，不宣称已验证 API 字段或实时目录。实施前核对版本化 API、分页、缓存和条目结构。保留名称、描述、命名空间、版本、来源、可选 remote/package 部署方式；分类只能来自可验证元数据，不能前端编造分类数量。

选择条目后按可用部署方式进入配置向导，预填非敏感字段；显示 npm/uvx/docker 等依赖及是否会下载/执行代码。点击“配置”不执行包管理器，不隐式安装解释器。Registry 上架不等于可信、兼容或已连接。搜索/刷新必须由显式动作触发；离线显示缓存时间及错误，安装前仍需重新校验来源和目标。

### 5.3 手动添加 / 编辑

- stdio：服务名、程序、argv 列表、工作目录、转发环境变量名。参数不做 Shell 字符串拆分。
- HTTP：服务名、URL、Bearer 环境变量名、Header→环境变量名映射。Claude 的 SSE 仅按兼容能力显示；WebSocket 发现项当前只读。
- 原生 OAuth 登录/登出继续复用独立原生认证，不继承 DG-OS Provider 凭据或 MCP token。
- 编辑遵循 keep/set/remove 三态，保留未知字段。表单不能回填敏感原文；清空字段的含义必须明确。
- 保存前给目标配置与差异预览，确认后走现有事务。冲突保留表单并重新读取，不强制覆盖。unknown 只核实原 operation，不创建新写请求。
- 未保存草稿按账户、平台、scope、workspace 隔离。切换管理视图保留；关闭提示保存/放弃；保存中不能重复提交；账户结束清空敏感表单。

### 5.4 临时连接测试与工具列表（新增设计，不缩减为配置检查）

这是参考图要求的新能力，**现有 Native IPC 尚不支持，仍保留在本次目标里**。不能把“接口缺失”实现成永远不可用的测试按钮。

建议独立宿主 probe 生命周期：预览确切命令/参数/目录/目标与凭据引用 → 用户明确开始 → 有界 initialize + tools/list → 返回带来源的结果 → 关闭临时连接并回收自己启动的进程。只读取工具定义，不调用工具，不写入运行会话或生产连接池。HTTP 200 不足以证明 MCP 握手成功。

- 总期限建议 15 秒，最多一个探针；用户取消立即请求关闭，结束清理建议 2 秒。最终值在正式技术契约中冻结。
- stdio `npx/uvx/docker` 可能下载、启动代码；预览明确提示，不在打开页面或保存表单时执行。凭据由宿主以可信路径提供，不返回 renderer/日志。
- 输入绑定配置摘要、平台版本和目录身份；变更后旧测试标“已过期”。失败显示阶段（定位程序/启动/握手/认证/工具读取/清理）及修复入口，不自动重试。
- 未确认进程回收或外部结果保留 unknown 及核实入口，不能显示已清理成功。
- 临时工具 Schema 标记探针来源；当前会话只提供名称时明确“参数 Schema 不可读取”。不得用探针结果伪造原生会话已批准的工具。
- “断开”只关闭该探针自己拥有的连接或原生支持的自有会话目标；不停止外部共享 MCP 服务。

## 6. 状态、错误与并发

| 情况 | UI 行为 |
| --- | --- |
| 正在扫描 / 请求来源 | 局部 loading，保留已有列表，不展示空态 |
| 真正空集合 | 明确所选平台与范围，给添加/浏览入口 |
| 权限拒绝 / 配置损坏 / 扫描不完整 | 标为不可读取或部分结果，不覆盖为默认配置 |
| 写入成功 | “已保存/已安装，待加载”，不是“已连接/已执行” |
| 会话观测成功 | 显示时间及精确会话；仅代表该次观察 |
| 外部文件修改 | 拒绝覆盖，保留草稿，重新读取与预览 |
| 事务 unknown | 保留 operation 核实入口；禁止自动重放 |
| 平台、workspace、账户在异步期间变化 | 迟到结果丢弃，不能串到新上下文 |
| 被插件、内置或外部管理器所有 | 显示只读与管理归属，不假装可直接编辑 |

| 能力 | 当前证据 | 实施要求 |
| --- | --- | --- |
| 原生 Skills 安装/更新/移除 | GitHub/ZIP 类型与文件事务存在；UI 当前主要接 GitHub | 复用预览/提交/取消/核实，不另建写文件实现 |
| Skills 正文、文件查看 | 当前摘要不返回正文 | 新增绑定实例修订、受限相对路径、有界只读内容契约 |
| ZIP/本地目录 UI | ZIP IPC 有；目录安全包内核有，宿主来源授权缺 | 接文件选择器和宿主句柄，补目录授权契约 |

| Skills 依赖 | 静态解析/定位内核有；原生 IPC/UI闭环缺 | 绑定真实 CLI 环境，不执行扫描；版本探测单独授权 |
| Native MCP CRUD | 发现、字段 patch、CAS、预览事务已有 | 在新管理器复用；只允许目标真实支持的传输与范围 |
| 原生活动会话/认证 | 原生观测、刷新及认证 IPC 已有 | 保留 session/generation 和能力门控；不要用 DG-OS MCP 连接代替 |
| MCP Registry | 原生市场缺 | 新增目录适配，输入验证、缓存及部署选择 |
| 临时连接/完整工具 Schema | 独立测试 IPC 缺，原生观测只有工具名 | 按 §5.4 新建受控 probe；不复用权限不匹配的宿主调用通道 |

## 8. 验收目标

1. 从 CLI 抽屉完成 Skills/MCP 管理，不经过 AI 助手管理页；AI 助手不会列出、启停或卸载原生资源；Provider 仍共用。
2. 范围由宿主工作区/用户根派生；UI 显示真实目标路径和共享影响，worktree 不被偷换成项目根；不支持的范围不伪造支持。
3. Skills 来源查找、GitHub/ZIP/目录预览、安装、更新冲突、移除恢复、依赖与会话生效按上述流程闭环；插件资源不可直接写。
4. MCP 市场→部署选择→配置→预览→保存完成；stdio/HTTP及受支持 SSE 路径各自验证；密钥不入普通 DTO/配置预览/日志。
